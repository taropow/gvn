# ファイル操作の設定と検証

GVN 0.11.0。参照はMassiGraヘルプの[ファイル操作設定](http://www.massigra.net/massigrahelp/currentver/d_prop_fope.htm)、[保存](http://www.massigra.net/massigrahelp/currentver/d_save.htm)、[コピー・移動](http://www.massigra.net/massigrahelp/currentver/d_cpymovex.htm)。設定名だけで完了にせず、ダイアログの選択、実ファイル、表示中のRGBA、一覧の順番を分けて検査する。

## 設定

ファイル操作タブは縦スクロール式。0.14.0では[コピー10件・移動10件を別管理](gvn-destinations.md)し、下部のリストで編集する。保存していない画像の確認は、ユーザー指定により既定OFFを維持する。参照の基本/10件登録を切り替える専用のコピー・移動画面等は引き続き補完する。

| 項目 | 既定 | 実行時の動作 |
| --- | --- | --- |
| 上書き保存でも保存ダイアログを開く | ON | 通常の保存でもWindowsの保存画面を開く。OFFでは現在の対応保存形式へ直接保存 |
| 上書き保存する前に確認する | ON | 通常保存の上書きを確認。名前を付けて保存はこの設定によらず既存ファイルを確認 |
| 名前を付けて保存のパスを保持する | ON | 成功した別名保存のフォルダを次回の初期フォルダにする。失敗・キャンセルでは更新しない |
| ファイル名変更後に表示順を整理する | ON | 改名後に現在の並び順で再ソート。OFFではその位置を保つ |
| ファイルを削除する前に確認する | ON | ごみ箱/完全削除の説明を選択した処理に合わせて確認 |
| 削除したファイルはごみ箱へ送る | ON | ONはWindows Shell、OFFは直接削除。失敗時は表示と一覧を保持 |
| 削除や移動したら次のファイルを表示する | OFF | ONは元の一覧の次、末尾なら残る最後を表示。残り0枚なら画像を閉じる |
| 移動先の同名ファイルを上書きする前に確認する | ON | フォルダ選択と登録先の両経路に適用。コピーの設定と独立 |
| コピー先の同名ファイルを上書きする前に確認する | ON | フォルダ選択と登録先の両経路に適用。移動の設定と独立 |
| 保存していない画像の変更を確認する | OFF | ONで保存/破棄/キャンセルを確認する |

前回保存先がなくなった場合は現在の画像のフォルダを使う。保持をOFFにしている間は記憶した保存先を使わず更新もしない。設定は通常のINIに保存する。0.12.0では[形式別保存オプション](gvn-saving-options.md)、前回の保存形式、日時保持を追加し、保存成功後にだけ確定する。入力の元パレット/色番号の保持は残り、S079は部分対応のままとする。

## 表示と一覧

改名と、自動移動OFFでのファイル移動は、現在の画素・倍率・パン・編集状態・Undoを保ってパスを更新する。非同期の画像再読み込みを起こさないことを統合試験で確認する。キャッシュの共有画像を直接書き換えず、ファイル情報を更新したコピーへ切り替えるため、操作中の一時的なRGBA複製は残る。

自動移動OFFで削除した場合は、メモリの画像を保持する。画像の実ファイルパスを外し、透明度付きコピーや別名保存を続けられる。一覧の順位は「—」とし、手動の次は削除位置の次、前はその前の画像を開く。最後の1枚を削除しても表示は保持する。自動移動ONで残り0枚になった場合は暗い市松へ戻る。

移動後の自動移動OFFでは移動先の画像を保持し、移動先フォルダを一覧にする。ONでは移動元の一覧を保持して次へ進む。次画像のデコードに失敗した場合は、残していた画像と一覧位置へ戻る。削除したファイルそのものを復元する機能ではない。

登録先の相対パスは元画像のフォルダを基準にする。コピーは画像の編集結果ではなく元ファイルをコピーする。保存していない編集内容の確認は別の設定で管理する。スライドショーはモーダルなファイル操作の前に停止し、保存は現在のアニメーションフレームで一時停止する。アニメの同じファイルへの静止画上書きは禁止する。

## ファイルの更新

コピーは保存先と同じディレクトリのGUID一時ファイルへコピーした後で確定する。既存の保存先の他のハードリンクを途中で切り詰めず、読み取り専用やロックによる失敗では元画像と保存先を保つ。同一ファイル・同一ハードリンクへのコピー/移動を拒否する。

画像保存も一時ファイルから確定する。存在しない保存先に決定した後で同名ファイルが現れた場合は、再確認せず上書きしない。移動ではWindowsのドライブ間コピー許可を利用し、成功後も元ファイルが消えたことを検査する。コピーできても元の削除を確認できない場合はエラーとして元の表示を保持する。[MoveFileExの条件](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-movefileexw)に従う。

ごみ箱処理は[Windows IFileOperation](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifileoperation-setoperationflags)を使用する。Shellへ渡すパスを正規化し、処理の中断と元ファイルの消失を検査する。Shellやドライブの設定による直接削除の可能性を、ごみ箱から必ず復元できるという保証に置き換えない。

## 検証と境界

- `tests/file_operations_tests.cpp`: 元/既存先の保持、ハードリンク、読み取り専用・ロック、一時ファイルの解放、G側/C側の専用領域間の移動、直接削除、保存時の上書き禁止。
- `tests/app_tests.cpp`: 保存画面ON/OFF、通常保存と別名保存の確認、保存先保持、改名の順番・画素・倍率・Undo、コピー/移動の独立確認と相対パス、削除後の透明度・一覧の欠番・末尾・読み込み失敗。
- `tests/autopilot/26-file-operations.gvn`: 実設定画面の全追加項目、スクロール、適用・キャンセル・ページリセット、実Windows保存画面の決定、保存RGBA、削除後のコピーと次画像、空表示、INI保存。
- `tools/recycle_probe.cpp`: 自分で生成したGUID専用画像だけを実際のShellごみ箱へ送る。削除元のフルパスがその専用フォルダと一致する項目だけを復元し、バイト一致と後始末を検査する。ごみ箱を空にしない。[記録](verification/0.11.0-recycle.json)。

統合試験では確認メッセージの回答とファイル選択の境界を差し替える。実保存画面は別の専用自動操縦で操作し、ごみ箱は実Shell専用プローブで検証する。Explorerや外部編集ソフトの手動操作、物理入力、全ネットワークドライブの確認まで済んだとは扱わない。

参照側は公式EXEの隔離コピーと専用画像を使い、削除後の画像保持・コピー・手動の次画像、移動後の保持を確認した。[実行結果と実行したソース](verification/0.11.0-fileops-reference/result.json)を保存する。参照側の起動速度の追加比較は行っていない。形式別保存オプション、全体の残作業は[設定対応表](gvn-settings-matrix.md)と[継続計画](gvn-goal-plan.md)に残す。
