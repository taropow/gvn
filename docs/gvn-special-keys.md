# 特殊キーの登録可否

0.43開発時に、既存の登録処理を[公式のキー割り当て説明](http://www.massigra.net/massigrahelp/currentver/d_keyset.htm)と照合した。本体の変更は不要だった。[確認記録](verification/0.43.0-special-keys-related.json)を参照。0.43へ配布反映済み。

音量操作などの特殊キーは登録できない。対応しているキー名だけをパーサーと入力用の表に持ち、それ以外の仮想キーには登録候補を作らない。入力欄へ直接VolumeUpなどと書いて追加する経路も拒否する。

専用の非表示デスクトップで、実際のキー入力欄と取込みボタンを操作した。音量ミュート・下げる・上げる、メディア再生/一時停止、メール起動の5キーを取り込もうとすると、登録不可の通知となり、既存のF12は保持された。Ctrl+Altとの組合せも含む。VolumeUpの文字列による追加も拒否した。その後は通常のCtrl+Alt+F12の取込み・追加・適用・保存が成功し、2つの有効な割り当てが実リストとINIに残った。

47操作・1画面が成功した。試験用のcapture_vkは対象をマルチメディア/アプリ用の仮想キーと、入力待ちになっている所有する入力欄に限定する。WM_KEYDOWN/UPはその欄だけへ送る。グローバル入力やWM_APPCOMMANDは発行しないため、音量や他のアプリの操作には使わない。物理キーボードやOSの入力変換までを確認した意味ではない。

S115を実装済みへ更新した。登録処理・設定データ・本体210ケースの本文とGVN/Appバイナリは、先のキャプション確認と同一である。自動操縦に今回の入力方法とシナリオだけを追加し、本体テストやキャプションの確認を繰り返していない。
