# バージョン情報

0.37.0へ配布反映済み。[配布の確認範囲](verification/0.37.0-daily-use.json)を参照。

「その他 → バージョン情報」で、GVNの版番号、実行形式（x64等）、同梱ライセンスの案内を表示する。画像を開いていないときにも使える。キー・マウスへ割り当てられ、初期状態のショートカットは設定しない。

WindowsでGVN.exeの「プロパティ → 詳細」を開く場合も、ファイルと製品の版番号を確認できる。画面の文字列とEXEのVERSIONINFOは、CMakeの同じPROJECT_VERSIONから生成する。更新時はCMakeの版番号を変更する。既存のコマンドIDを変更せず、画像の加工・Undo・保存確認の設定も変えない。

[今回の証拠](verification/0.37.0-about-version-related.json)では、新しい本体ケース1件と、実際の標準ダイアログを操作する専用1本54操作・2画面を確認した。画像なし、透過画像の加工とUndo、現在コマの保持、キー登録、メニューとキーからの開閉を含む。Windows APIからEXEの固定版番号と文字列も読み取り、画面の0.37.0と一致した。

初回は新規テストの再生状態の参照先を取り違えてビルドが止まった。修正後、本体ケースと版情報は成功した。自動操縦は、標準ダイアログのボタンを直接のIDOKとして探して失敗したため、所有するダイアログ内の唯一の可視ボタンを列挙して実クリックする方法へ変更した。所有プロセスと可視性の制約は維持した。

その後の54操作はすべて成功した。記録画像が339×192pxの標準ダイアログであるため、後処理だけが従来の高さ200pxという一般画面の基準で止まった。新しいabout_snapshotをコンパクトなダイアログに分類し、既存の小型ダイアログと同じ高さ100px以上の条件で保存済み2画像を再検証した。他画面の200px条件、幅300px、色数の条件は維持した。この後処理では画面操作を再実行していない。

既存の本体190件、設定全体、全68本の専用自動操縦、性能測定は今回繰り返していない。配布0.36.0とユーザー設定を保持し、他の有用な修正とまとめて次版へ反映する。
