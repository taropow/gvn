# 普段の操作の待ち時間を減らす（0.77.0）

専用ブランチ`codex/interactive-hotpaths`で次の3項目を順に実装する。画質やAlphaを落として処理時間を短縮しない。GPU化とUndoの差分化は今回の対象に含めない。

- [x] 高画質表示の非同期化を、入力画素数の固定条件から可視領域とフィルタ計算量の目安へ変更。小画像の拡大も対象にし、原寸・軽い表示にはワーカーを作らない。最終画素、連続要求、リサイズ、取消・終了を確認する。
- [x] 復号・ファイル読み込みの区切りで古い要求を取り消す。表示したい画像を重い先読みより優先し、同じ画像への先読みは活用する。外部ライブラリ内部の単一呼び出しは強制終了しない。
- [x] 大画像のコピーは、押した時点の画像・コマ・選択・メタデータを保って別スレッドで準備する。公開はUIスレッドで行い、Alpha・位置形式・連続コピー・直後の貼り付け・外部のクリップボード変更・終了を確認する。Cutと外部アプリへの受け渡しは順序を保つ同期経路を残す。
- [x] 関連テストと専用自動操縦で確認し、応答時間と完了時間を分けて記録する。最後に配布ZIPの主要10経路を一度確認し、起動中の普段使い用ウィンドウを保持して更新する。

変更前の実行ファイルは`.cache/interactive-0.77-baseline/`へ保持する。ユーザーの画像・設定・クリップボードは試験に使用せず、ComputerUseも使わない。

## 実装と確認結果

高画質の処理量は、可視領域の出力画素数、参照する元画像の行数、Lanczosのタップ数から見積もる。従来の入力画素数だけの条件を外し、拡大や強い縮小も対象にする。画像・フレーム・倍率・位置が一致する既存の最終表示は再計算しない。軽い表示と原寸の直接描画は従来の同期経路を使う。

読み込みは1MiB単位、WICのRGBA取得は256行単位、GIF/APNGはコマ単位、PSDはチャンネルや変換ブロック単位、ZIPは展開出力のコールバックで取消を確認する。既に始まった外部ライブラリ内部の1回の呼び出しやOSの読み取り自体は強制終了しない。先読みと要求された画像が同じなら中断せず、同じ復号結果を表示に使う。

コピーは1,048,576画素以上の領域だけ必要時に1本のワーカーを作り、PNG生成・選択領域の抽出・DIBV5の準備を行う。PNGは従来と同じ可逆の圧縮設定で、Alphaと透明画素のRGBを保つ。PNG・DIBV5・位置情報は遅延形式として先に宣言するため、他ソフトがすぐにデータを要求しても前の画像を返さない。WM_RENDERFORMATではクリップボードを開かず要求された形式を渡し、終了時のWM_RENDERALLFORMATSでは所有者を確認して残りを渡す。他ソフトが内容を置き換えたら古いコピーを中止する。再試行タイマーは選択線用のタイマーと分離し、コピー処理がない間は停止する。

表示34件は最初の実装段階で成功。最終候補で読み込み29件、画像形式14件、転送7件、PNG/DIBV5と12エイリアスの実クリップボード経路、関連App操作13件を確認した。実クリップボードは非対話の専用ウィンドウステーションで使い、別スレッドから準備中のPNGをGetClipboardDataで要求する実際のWM_RENDERFORMAT経路も確認した。実CLIP STUDIO PAINTの操作や、物理モニターへの提示遅延を測定した意味ではない。

## 操作を返す時間の試料

2048×1536 RGBAを使い、同じApp内の同期経路と非同期経路を比較した最終1試行。高画質拡大は125%、ウィンドウは1800×1400。Direct2Dの描画先は先に初期化している。

| 操作 | 同期経路の待ち | 非同期経路で操作を返すまで |
| --- | ---: | ---: |
| 高画質表示 | 144.82ms | 0.61ms |
| コピー | 53.44ms | 5.39ms |

同じ試行のコピー完了は約62.8ms。非同期中に表示コマンドも実行しているため純粋なエンコード速度の比較ではない。フィルタ計算・圧縮そのものをこの比率で高速化した意味ではなく、UIスレッドの待ちを減らす変更である。全体起動時間・画像送り速度や全形式の高速化率には換算しない。

先読みの優先制御は、制御したデコーダーで旧先読みを止めたまま新要求が完了することと、同じ画像への要求では復号をやり直さないことを確認した。実ファイルのPNG/JPEG/BMP/TIFF/GIF/APNG/PSDとZIPについて、取消なしの経路と全画素が一致すること、取消が安全な区切りで返ることも確認した。

参照したWindowsの契約：[CopyPixels](https://learn.microsoft.com/en-us/windows/win32/api/wincodec/nf-wincodec-iwicbitmapsource-copypixels)、[WM_RENDERFORMAT](https://learn.microsoft.com/en-us/windows/win32/dataxchg/wm-renderformat)、[WM_RENDERALLFORMATS](https://learn.microsoft.com/en-us/windows/win32/dataxchg/wm-renderallformats)。

最終の16ファイル配布ZIPでも主要10経路が成功。普段使い用へ0.77.0を反映し、既存ウィンドウを保持した。[確認記録](verification/0.77.0-interactive-hotpaths-related.json)。
