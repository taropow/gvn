# 数値による選択範囲

0.41.0へ配布反映済み。[確認記録](verification/0.41.0-selection-rectangle-related.json)を参照。

「編集 → 範囲を数値で指定」で、左・上・右・下・幅・高さの6欄を表示する。選択範囲がある時はその範囲、ない時は画像全体を初期表示する。画像の大きさも表示する。

座標は0から数え、右・下の画素も範囲に含む。左0・右0は幅1になる。各座標欄を変更すると、反対側の座標は保ち、幅・高さを更新する。左が右より大きい場合や、上が下より大きい場合も指定でき、幅・高さには両端を含む大きさを表示する。OKで確定する時に、実際の選択を通常の左上・幅・高さへ整える。

幅を変更すると左から右へ、高さを変更すると上から下へ範囲を広げる。そのサイズが画像端からはみ出す場合は、指定サイズを保持したまま画像内へ移す。96×80画像で左8・幅90と指定すると左6・右95になり、上8・高さ75なら上5・下79になる。

左・右・幅には横向きの増減ボタンを付ける。上・下・高さは、参照アプリと同じく上矢印で減少、下矢印で増加する。座標は画像内、幅と高さは1〜画像の大きさに制限する。空欄や範囲外の値はエラーとしてOKを無効にする。

入力中や取消では、現在の選択や画像を変更しない。OKは選択範囲だけを変更する。[選択単位](gvn-selection-units.md)の格子では丸めず、指定した画素範囲をそのまま使う。元RGBA、Undo、変更済み状態、表示中のアニメのコマは保持する。画面を開いている間に読み込みが終わって別画像へ切り替わった場合、古い画像用の結果は新しい画像へ適用しない。

MassiGra0.45の所有プロセスと合成画像だけを使い、6欄の連動10例、逆になった端点を確定して再表示する2例、6個の増減ボタンの範囲と向きを取得した。GVNは関連単体/UI5件、本体3経路、専用80の85操作・2画面が成功した。実際のコントロールの増減、入力エラー、取消、再表示、画像端への移動を確認し、コピー・切り出し・Undoでは透明部のRGBと半透明も含む全RGBAを照合した。

従来の4値入力を使う本体テストの本文・判定は維持し、入力境界を新しい画面へ接続した。自動操縦の既存`prompt_text`も、実際の左・上・幅・高さの欄へ入力し、到達した範囲を確認する。旧5本のシナリオを今回すべて再実行したという意味ではない。全体のテスト・性能測定は繰り返していない。

実装: [専用画面](../src/selection_rect_dialog.cpp)、[本体の選択処理](../src/viewer.cpp)。参照: [MassiGra選択範囲画面](http://www.massigra.net/massigrahelp/currentver/d_selection.htm)。[別ウィンドウのDPI引継ぎ](gvn-new-window.md)も関連確認を完了した。設定の細部、実プリンタとクリスタの受信確認は残項目として継続する。
