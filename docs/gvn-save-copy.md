## GVNの契約

新規設定では、異なるファイルへの保存は表示元を維持するコピー保存とする。表示画像、選択、Undo、元のフォルダと一覧を保持する。原本に書き込んでいない加工は変更済みのまま保ち、コピーやOLEドラッグが古い原本の画素へ戻らないようにする。未保存確認は従来どおり既定OFFであり、この設定によって有効にはしない。

同じ表示元ファイルへ実際に上書きした時は保存済みとし、Undoで保存前へ戻した画像は変更済みとして扱う。GIF/APNG等のコマを書き出しても元のアニメを静止画に置き換えない。クリップボード画像はAlphaと元のUndo先を保持する。

ファイル操作タブに「静止画の別名保存後、保存先のファイルへ切り替える」を追加する。ONでは静止画の従来のGVN方式を選べる。新しいINIキーは `Viewer.save_as_retarget`。キーがなく既存の `save_dialog` キーがあるプロファイルはONへ移行し、従来の使い方を維持する。明示したOFFは再読込後も保持する。アニメの現在フレーム保存は、この指定にかかわらず元のアニメを保持する。
