# ジャンプ画面（0.17.0）

参照はMassiGraの[ジャンプ画面](http://www.massigra.net/massigrahelp/currentver/d_jump.htm)と[移動設定](http://www.massigra.net/massigrahelp/currentver/d_prop_move.htm)。0.16.0の数値入力だけの実装を、専用画面へ置き換える。プレビュー、ファイル名、1から始まる順番、総数、連動する水平スクロールバー、縮小画質を備え、漫画の右から左と独立した方向設定を反映する。

## 参照の確認

公式0.45の隔離した自分用コピーと合成画像だけで確認した。プレビューの既定はON、縮小画質は低・中・高の3段階で既定は中。順番を2から3へ変えるとスクロール位置も3になり、左へ1個動かすと順番と位置が2になる。プレビューOFFと低画質へ変更してキャンセルした後に開き直すと、元のON・中へ戻る。

ファイル名の表示仕様は公式ヘルプを根拠とする。参照本体の名前欄はWM_GETTEXTでは文字列を取得できなかったため、名前やプレビュー画素をこのプローブで照合したとは扱わない。失敗した初期プローブも`.cache/jump-reference`へ分けて保持する。[保存した参照結果](verification/0.17.0-jump-reference.json)を参照。ユーザーのウィンドウや現在のクリップボードは使わず、追加の起動速度比較は行っていない。

## 実装する契約

- 開いた時の一覧を保持し、名前・総数・選択先を途中の別一覧で置き換えない。ZIP内はファイル名だけでなく内部パスを表示する。長い名前は読み取り専用欄をスクロールして末尾まで確認できる。
- 順番は1から総数までの整数。空欄、範囲外、小数、符号、不正文字や整数オーバーフローでは決定を無効にする。正常な入力へ戻せば、名前とバーとプレビューを再び連動させる。
- バーの位置と範囲は32bit。漫画の右から左かつ反転設定ONの時だけ、左右の先頭/末尾を逆にする。入力欄の番号自体とファイルの並び順は変えない。
- プレビューだけの読み込みを画面スレッドへ載せない。選択が短時間に変わる間は60msまとめてから要求し、古い要求番号の結果を採用しない。読み込み中、OFF、表示失敗を区別する。
- 専用の既存Loaderは、プレビューを最初に要求した時だけ生成する。追加の先読みや一覧走査をせず、キャッシュ予算は0。プレビュー用スレッドをアプリ起動時や通常表示中に常駐させない。
- 透明度は通常の読み込み設定に従い、保持時は市松へ重ねる。プレビューは静止1コマとし、受け取ったアニメの残りのコマを解放する。低・中・高はGVNのSimple・Linear・Integraの縮小描画へ接続し、画質の変更だけでは再デコードしない。
- OK時だけ選択先とプレビュー/画質の設定を確定する。キャンセルや閉じる操作は表示先と設定を変更しない。移動設定ページの初期化は、ジャンプの左右反転も既定へ戻す。

## 現時点の範囲

本体コマンドへ接続し、設定26ケース・App70ケースの関連検査、新画面の実コントロール8ケースと専用33の196操作・12画面が成功した。キャンセル時の編集中画像の保持、古い結果、全3方向条件、設定往復とページ初期化、PNG/GIF/APNG/PSDとZIP内部の日本語パス、透過RGBAを照合した。S077/S078はこの証跡で実装済みへ進めた。最終全28項目・70統合ケース・33本5,657操作・130画面と配布本体10経路が成功した。この段階は0.17.0として配布した。0.18.0以降は[終了待ちの分離](gvn-preview-lifetime.md)も追加した。[最終範囲](verification/0.17.0-jump-stage.json)を保存する。

プレビューの元画像は既存デコーダの上限256MiB以内で展開する。縮小専用デコードや巨大アニメのストリーミングを実装した意味ではない。読み込みの中止は要求番号による破棄であり、実行中のOS APIやデコーダを強制中断しない。0.17.0では画面を閉じた時に実行中処理の完了を待っていた。0.18.0では画面終了を待機から分離し、Appが処理後に回収する。アプリ全体の最終終了では待機が残る。この境界を含め、大素材での軽量性や応答性は引き続き検査・改善する。

最初の専用キャプチャでは標準コンボの選択文字が隔離DCへ描かれず、厳密な文字画素チェックで失敗した。設定/保存画面と同じ実owner-draw/print経路へ揃え、チェックを弱めずに再検査した。[修正前の範囲](verification/0.17.0-before-jump-combo-print-fix/scope.json)を保存する。ZIP素材の項目数と最後のテスト操作名の訂正も、製品の不具合修正とは区別する。

専用33の[大きめの透過プレビュー](verification/0.17.0-autopilot/33-jump-dialog/jump-large-alpha.png)も保存する。これは合成素材と隔離した実クライアント描画で、実モニタの外観確認とは区別する。
