# 画像の拡大縮小

0.39.0へ配布反映済み。[今回の配布確認](verification/0.39.0-daily-use.json)を参照。以下には開発時点と旧版の記録も含む。

0.39.0では[解像度と実寸指定](gvn-resolution.md)を追加し、関連確認が成功した。DPIの保存も関連確認済み。以下の0.38とメタデータ基盤の記録は当時の範囲として保持する。

0.38.0へ配布反映済み。11補間方式と縮小後シャープを含む。[配布の確認範囲](verification/0.38.0-daily-use.json)、[補間の関連確認](verification/0.38.0-resize-filters-related.json)を参照。

「画像 → リサイズ」で、幅・高さをピクセルまたは元画像に対する倍率で指定する。「元の縦横比を保つ」がONなら、編集した側に合わせて他方を元画像の比率で調整する。画素寸法は四捨五入し、比率の計算で1未満になる他方の寸法は1にする。「今の半分」「今の2倍」は入力中の幅と高さに適用し、半分の端数は切り上げる。

元の寸法と新しい寸法、出力RGBAのデータ量を表示する。各辺1～65,535px、画素データ1GiB、一般設定の物理メモリ制限を確認し、不正入力ではOKを無効にする。入力中は画素の確保や画像処理をしない。キャンセルでは画像・Undo・設定を保持する。

0.38では、縮小と拡大それぞれSimple、Linear、Integra、Hermite、Bell、B-Spline、Mitchell、Cubic-0.5、Lan2+0.25、Lan2+0.50、Lanczos3を選ぶ。初期値は両方Linear。一方を縮小し他方を拡大する場合は各軸の方式を使い、同じ寸法の軸は変更しない。「補間方法を使う」がOFFなら両軸Simpleとし、方式とシャープの操作を無効にする。選択は残すのでONで戻る。表示ズームとは独立した設定。

成功時だけ比率固定・補間ON/OFF・縮小方法・拡大方法・縮小後シャープを保存する。取消や失敗では保存しない。従来のINIにリサイズ補間ON/OFFがなければ以前の表示補間を引き継ぎ、方式がなければLinear、シャープはOFFで初期化する。

透明画像はRGB×AlphaとAlphaを浮動小数点で計算し、最終画素でRGBAへ戻す。途中で8bitの乗算済み色へ丸めず、Alpha1の元の色も保持する。Alpha0の隠れたRGBは混色に使わない。補間でAlpha0になった出力のRGBは0とする。不透明で両軸の方式が同じ場合は既存の参照確認済みの計算を使う。透明画像・異なる軸方式では専用の経路を使い、フルサイズの浮動小数点中間画像を作らず行バッファで処理する。Hermite以降で1/100未満の縮小は既存の表示処理に合わせてIntegraへ切り替える。

「縮小した後にシャープ加工」は既定OFF。少なくとも一方を縮小し、縮小方法がSimple以外の場合に適用する。GVNでは3×3の重み付きぼかしとの差を25％加える穏やかな加工で、近傍色はAlphaで重み付けする。Alphaを変えず、透明画素の隠れた色を使わない。拡大のみ・同寸法・Simple縮小では適用しない。MassiGraのシャープ加工と画素完全一致するとは扱わない。

同じ寸法に確定した場合はRGBA全値と元パレットを維持する。Simpleによる整数倍拡大でも、透明・半透明・透明画素内のRGBとパレットを保持する。変更後はUndoできる。アニメはダイアログ中に表示コマを止め、キャンセルなら再生状態を戻す。確定時は確認のうえ現在コマを静止画像にし、Undoでアニメと元の再生状態へ戻す。元のアニメを直接上書きしない。

## 確認範囲と残差分

[0.38の記録](verification/0.38.0-resize-filters-related.json)は単体/UI10件（既存4件＋追加6件）、本体関連3件、実コントロールの自動操縦2本116操作・4画面。方式の独立選択・11項目・有効/無効・保存・取消・Undo・再コピーを確認した。不透明の10方式×拡大/縮小は既存のMassiGra参照の対応ページ20組と照合し、最大RGB差はLinearの1階調、ほかは0。全11方式でAlpha1のRGBと透明な隠れ色の除外、混合軸と行バッファの経路を確認した。Alpha重み付き平均の独立した数値例、シャープがRGBを変えAlphaを変えないこと、同寸法・Simple・拡大のみでは加工しないこと、無効な方式とメモリ制限による確保前の拒否も確認した。

[0.37の基盤確認](verification/0.37.0-resize-related.json)も別の日付で保持する。比率、倍率、半分/2倍、不正値とメモリ、取消、Undo、アニメの現在コマと再生状態を確認した。最近傍6×4は別実装PillowによるRGBA期待画像と全値が一致し、今回の専用69でも確認した。同寸法ではAlpha0・1・128・255を含むRGBも一致した。

[MassiGra公式の拡大縮小](http://www.massigra.net/massigrahelp/currentver/d_resize.htm)にある印刷サイズ・解像度、画像を変更しない解像度だけの変更は未実装で、F045は一部対応を維持する。元の作業表にあったプレビューの未実装記載は、個別ヘルプに項目がないため必須項目と区別する。入力中プレビューは今回追加していない。
