# 画像情報と色数の計算

0.40.0へ配布反映済み。[確認記録](verification/0.40.0-image-info-related.json)と[メタデータの基盤](gvn-image-metadata.md)を参照。

「その他 → 画像情報」は専用画面で開く。ファイル名、場所、フルパス、形式、読み込み時の寸法と元色深度、現在の寸法とRGBA32、水平/垂直DPI、印刷サイズ、ICC有無、コマ数、ディスク上/メモリ上のサイズ、フォルダ内の順番/対応ファイル数、更新日時、読み込み時間を表示する。値は読み取り専用の欄から選択・コピーでき、長いパスは横へスクロールできる。各欄でCtrl+Aを使える。

未保存の画像はパスとフォルダ内の順番を未保存/なしとして表示する。順番は表示中の画像のパスから求め、別のファイルを読み込み中の対象インデックスだけでは決めない。読み込み時のサイズと現在のサイズを区別し、DPIだけの変更も情報画面へ反映する。

「自動的に計算」は初期値OFF。ONで使われている色数を計算し、選択を設定へ保存する。計算が済んだ後にOFFにしても、その画面の結果は残す。アニメは計算を無効にし、結果欄を空にする。アニメで情報画面を開いても、静止画像用に保存したON/OFFの設定は消さない。

MassiGra0.45を専用の非表示デスクトップに起動し、合成画像だけで数え方を確認した。透明度の違いも含む表示色を数える。RGBをAlphaで乗算して8bitへ四捨五入した色とAlphaの組を比較するので、Alpha0の隠れたRGBは同じ透明色として数える。低いAlphaで表示値が同じになる色もまとめる。元のストレートRGBA、パレット、コピーする画素は変更しない。RGB3色、同RGBの4透明度、透明部の異なるRGB、低Alpha、重複パレット、未使用パレット、アニメの7例を参照した。

計算は画面とは別の処理で行う。通常の不透明画像には2MiBの色表を使い、画像全体の複製を作らない。半透明のある画像は半透明画素の表示色だけをキーとして持ち、区切って並べ替え、重複をまとめる。計算用メモリを確保する前に上限を確認する。大きな画像では時間や作業領域が必要になる場合があるが、欄の選択、OFF、画面を閉じる操作は受け付ける。OFFや閉じる操作で中止を要求する。計算失敗は情報画面に表示し、画像・Undo・変更状態を保って再試行できる。

関連単体/UI8件、最新本体1件、専用72/75の85操作・4画面を確認した。情報とDPI/Undoの本体3件は先行する同じモデル実装の記録として区別する。使われている色数は参照した6枚の合成静止画と一致し、コマと再生状態、設定保存、未保存画像、メモリ不足、中止、計算中の欄操作、再試行、閉じる操作を確認した。

画面レビューで、ファイル名の値は存在するのに文字が描かれない状態を見つけた。MassiGraのダイアログと同じくOKを最初のタブ位置にし、読み取り専用欄の初期スクロールが残る問題を修正した。現在はファイル名の先頭が表示され、実際の描画にも文字があることを自動確認する。値の照合だけで画面の確認を済ませない。

元の色タイプ（パレット/RGB/ビットフィールド/グレースケール/CMYK）も追加した。読み込み元のヘッダまたはWICの元画素形式を使い、画素編集やDPI変更・Undoでも保持する。DIBと新規ウィンドウ用RGBAスナップショットは受け取った形式を表示する。15試料、単体7+9件、本体2件、専用76の34操作2画面、実際のCtrl+AとUnicodeコピーを確認した。[追加確認](verification/0.40.0-color-type-related.json)。

画面レビューで見つけた、編集後に形式がRGBA・容量と時間が0になる問題を補完した。読み込み元の形式・データ量・時間を小さなメタデータとして保持する。通常ファイルのディスク量は現在のファイル属性を使い、別形式で保存して表示先を切り替えた時は、現在画像とUndo側の保存形式も更新する。元のキャッシュ画像は変更しない。最新の本体試験でSaveAs BMP・Undo・redo・DPIの保持を確認し、専用77で編集後のPNG/294bytesを実表示で確認した。[追加確認](verification/0.40.0-print-related.json)。F044は実装済みへ更新した。印刷画面、設定の細部、実際の編集ソフトへの受け渡しも別の残項目で、全体GOALは完了していない。全体198件・CTest全体・専用75本全体・性能測定は繰り返していない。

参照は保存済みの[MassiGra画像の情報](http://www.massigra.net/massigrahelp/currentver/d_imginfo.htm)と、公式0.45のダイアログ定義。参照用の実行ファイルやユーザーのクリップボード画像は配布物へ同梱しない。
