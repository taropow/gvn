## 0.67.0 共通UIと設定ナビゲーション

閲覧の軽さを保つため、Win32の既存コントロールとGDIの描画を使う。新しいGUIランタイムや常駐監視は追加しない。設定「基本 → 全般」で外観をOS追従／ライト／ダークから選び、操作部の密度をコンパクト／ゆったりから選べる。単色アイコン、選択色、フォント、枠と余白をそろえ、DPIとWindowsの高コントラストに対応する。OS標準のファイル・色・フォント選択はOSの表示に従う。

閲覧時は画像を中心にし、鉛筆ボタンで編集ツール列を出す。ペン・文字のフチと影は基本のオン／オフを常に出し、細かい数値は「詳細」で開閉する。折りたたんでも入力値と編集中の画像を保つ。使用していない編集オプション行は場所を取らない。幅が狭い場合、主ツールバーの補助機能を「…」のその他メニューに収める。キー割り当て、有効／無効、チェック状態もメニューへ引き継ぎ、「表示バー」で従来の折り返しに戻せる。

設定は既存の16ページを残し、基本・表示・操作・ファイル・再生・編集・連携の7カテゴリに整理する。検索で項目名と関連語を絞り、Enterまたはダブルクリックで目的のページと項目へ移動する。例は「ホイール」「透明」「wheel zoom」「dark」。Escで検索を消す。変更した一般項目には●を付け、ダイアログ名にも変更中と表示する。「項目を標準に戻す」は最後に選択した項目を戻し、ページ全体の初期化も従来どおり使える。「関連設定」から近いページ、キー、マウス割り当てへ進める。OK／適用／取消と既存設定の保存方式は維持する。新しい外観設定はINIのInterfaceセクションへ分け、更新前から起動中の版によるViewerセクションの保存で失われないようにする。

編集状態は選択・ペン・文字・自由変形・トリミングで共通化し、短い操作案内、適用／キャンセル、コマンドの有効状態を合わせる。ステータスバーの画像情報をクリックすると詳細情報を開き、倍率をクリックすると数値ズームを開く。保存名の欄は「ドラッグ・ファイル名・拡張子」の順とし、リサイズ用の右下角からドラッグ領域を離す。狭い窓ではドラッグをアイコンだけにし、名前と形式を保持する。

キャンバスサイズの基準点は3×3の正方形とする。矢印・中央の●は描かず、選択したマスを青で塗る。9方向と既定の中央は従来どおり。矢印キーで上下左右へ選び、Tab／Spaceでも操作できる。各マスには読み上げ用の方向名と標準のラジオボタン選択状態を残す。画像配置、透明余白、RGBA、単位、縦横比、取消の仕様は変わらない。

内部は画像と画面の座標変換、編集状態、コマンド名・ショートカット表示を共有する。コマンド処理と選択処理を別ファイルへ取り出した。画像の表示・選択線・ペンプレビュー・自由変形のハンドルは同じ変換を使い、選択線の画面上1pxは維持する。テーマのフォントとブラシを再利用し、通常の再配置では再生成しない。リサイズ中の高速表示と終了後の指定画質への復帰も維持する。

[確認記録](verification/0.67.0-modern-ui-related.json)。専用の非対話デスクトップと独立クリップボードで、変更箇所と影響する日常操作を確認する。ComputerUseは使わない。既に通った変更のない描画・設定テストはハッシュ照合で結果を引き継ぎ、無関係な全体試験は繰り返さない。実ディスプレイごとのDPI、Windowsのテーマ切り替え表示、外部アプリの受信までを今回の自動検証だけで確認済みとはしない。

## 0.66.0 編集欄・ステータスバー・ペン位置

ファイル名・拡張子・フラットな「ドラッグ」はステータスバーの右側へ組み込む。独立した書き出し行を廃止し、画像表示中のステータスバーは30論理px、空表示時は22論理pxとする。画像情報は左側へ表示し、窓幅に応じて表示項目を減らす。極端に狭い場合のドラッグはアイコンだけにする。ステータスバーの非表示設定・全画面の自動表示に従い、書き出し欄も一緒に表示／非表示となる。アニメーションのプレイヤーはステータスバーの直上に配置する。手入力した名前と形式はリサイズや表示切り替えで保持する。

ペンと文字の設定は、基本設定・フチ・影を横にまとめ、幅が足りない場合はまとまりごとに折り返す。色は小さなスウォッチ、数値は薄い枠の入力欄で表示する。文字入力は複数行のまま横幅を最大960論理pxに抑える。1648論理px幅では文字欄は78px、ペン欄は38px。フチ・影がオフの間はそれぞれの詳細入力を無効にする。適用とキャンセルは右上に配置し、文字の仮置き開始時にレイアウトを動かさない。

ペンのドラッグ中に左ツール列の幅だけ左へずれる不具合を修正した。プレビューの線・フチ・影を描く座標変換は、元のキャンバス変換に追加し、描画後も元の変換へ戻す。確定前と確定後の位置は同じ画像座標を使用する。プレビューのぼかし表現は軽量な近似を継続する。

[確認記録](verification/0.66.0-status-editor-related.json)。ComputerUseを使わず、専用の非対話デスクトップと独立クリップボードで変更部分を確認する。

## 0.65.1 リサイズ、ツールバー、影

ドロップシャドウは、指定したぼかし幅を3つの処理に分配する方式へ修正した。以前の3px指定は最大9pxまで広がっていたが、現在は最大3pxの範囲となる。既定の3pxでも輪郭が締まる。ぼかし0は従来どおり硬い影、色・濃さ・ずれの操作も維持する。ペンの操作中プレビューも広がりを抑える。

ウィンドウのサイズをドラッグで変更している間は、通常サイズの元画像を一度だけAlpha付きビットマップへ変換し、Direct2Dで表示倍率を変える。選択画質が無補正なら無補正、それ以外は一時的にLinearを使う。確定／キャンセル後の描画では、設定したLanczos3などの補間を再計算する。通常のフィット表示やズームの画質設定は変更しない。元画像が描画先の最大ビットマップ寸法を超える場合は、既存の表示タイル処理へ戻す。

非常に狭いウィンドウでは、下部のドラッグをアイコンのみの表示に切り替え、拡張子の文字が読める幅を確保する。画像に合わせるウィンドウ調整では、編集オプションとステータスバーも必要な高さに含める。

主ツールバーの高さは表示ボタンの実矩形から計算し、折り返し後に広げても余分な空白行を残さない。ボタン文字・有効状態・チェック状態が同じ場合はネイティブUIへの変更要求を出さない。編集オプションは配置の変わった部品だけを移動し、使い続ける入力欄を毎回隠して表示し直さない。IME抑制は新しい子ウィンドウや関連付け変更を追跡し、既に解除した関連付けへの同じ変更を繰り返さない。

## 0.65.0 フチ・影、編集履歴、ファイルドラッグ

文字とペンに「フチ」「影」の独立したチェックを追加した。既定は両方オフ。フチは色と太さ1〜16px、影は色・斜めのずれ−64〜64px・ぼかし0〜32px・濃さ0〜100%を変更できる。文字の仮置き中も変更を反映し、適用／キャンセルで確定する。ペンのドラッグ中は軽量な線による効果プレビュー、確定時は画素単位の縁取りとぼかしを合成する。選択範囲がある場合は影・フチを含めて範囲内に限定する。Alphaを保持し、背景に焼き付けない。

元に戻すはCtrl+Zで最大32段階、やり直しはCtrl+Shift+Z。従来のトリミングCtrl+Yは維持した。新しい編集はやり直し履歴を破棄する。履歴は画像参照を共有し、履歴追加のための画素コピーはしない。保持量は物理メモリの1/8を目安に16〜256MiBの範囲で制限し、超える場合は古いものから減らす。上限を超える大画像でも直前1段階は残す。ファイルを開き直す／閉じる／Undo無効化時には履歴を破棄する。保存後も履歴を残し、戻した内容は未保存として扱う。閲覧だけでは履歴を作らない。

0.65.0では下部を独立した1行（36論理px）とした。0.66.0からはステータスバー右側へ統合し、左からファイル名、拡張子、ファイルアイコン＋「ドラッグ」を並べる。ドラッグは隆起枠のないフラット表示で、ホバーとキーボードフォーカスを示す。ファイル名は従来どおり開く／貼り付け時点のimage年月日_時分秒。PNG/JPEG/BMP/GIFの実ファイルとOLE形式は維持する。別ウィンドウや常時監視タイマーは作らない。

# GVN 0.64.1: 画像編集モード

## ペン・文字・トリミング

左の「ペン」は丸い線を画像へ描く。上部で色、太さ1～512px、不透明度0～100%を指定する。描画中は軽量な表示だけを更新し、ボタンを離した時に1回の編集として確定する。Esc・キャプチャ喪失・ツール切り替えでは描画を取り消す。選択範囲があればその内部だけを変更し、半透明の線の交差部分にも同じ不透明度を使う。

「文字入れ」は上部へ文字・フォント・サイズを入力して、画像上をクリックすると透明な文字画像を仮置きする。日本語と複数行に対応し、仮置き中も入力内容を変更できる。枠内で移動、8ハンドルで拡縮、枠外で回転してから「✓ 適用」で画像へ合成する。「× キャンセル」で取り消す。確定後は画像の画素となり、元に戻す操作で確定前へ戻せる。色と太さなどは現在のウィンドウ内で保持する。

「トリミング」は選択矩形、選択がなければ画像全体に白い8ハンドル付きの枠を表示し、枠外を暗くする。枠内で移動、ハンドルで拡縮、枠外で回転できる。Shiftは比率を保つ拡縮または15°単位の回転。上部のX/Y・幅/高さ・角度・出力倍率と枠を同期する。X/Yは回転前の矩形の左上位置を示す。9つの基準位置は数値による拡縮・角度変更の固定点として使う。表示ズームと出力倍率は独立する。

トリミングと選択画像の自由変形には、上部右側に文字付きの「✓ 適用」「× キャンセル」ボタンを置く。キャンバスへフォーカスがある時はEnter/Escでも確定・取消できる。数値欄でのEnterは数値の反映だけを行う。適用前は元画像とUndoを変えず、適用時にAlphaを保って画像を生成する。回転して画像外へ出た部分は透明となる。従来のCtrl+Y「選択範囲を切り出す」は即時の切り出しとして維持する。

## ステータスバーのファイルドラッグ

画像表示中はステータスバー右側にファイル名欄・拡張子の選択欄、その右にファイルアイコン付きのフラットな「ドラッグ」を表示する。ステータスバー左端にあったドラッグアイコンはこの操作へ移動した。全画面でもステータスバーの表示状態に従う。

0.64.1以降、ファイル名の初期値は端末のローカル時刻を使った `imageYYYYMMDD_HHmmss`（例：`image20261023_132405`）。ファイル読み込み成功、新規画像、画像の貼り付け成功時に一度生成する。同じファイルを開き直した場合、同じクリップボード画像を繰り返し貼り付けた場合にも初期化する。ズーム・描画・アニメのコマ送り・通常の編集では再生成せず、手入力した名前を維持する。これは下部の書き出し名で、読み込んだ実ファイルを改名する操作ではない。

名前とPNG/JPEG/BMP/GIFを選び、ボタンをドラッグすると、指定名の一時ファイルをExplorerと同じCF_HDROPのOLEデータで渡す。既定のPNGは保存ダイアログの透明設定に関係なくAlphaを維持する。JPEG/BMPは保存設定の背景色、GIFは保存設定のパレット・透明色の制約を使う。出力対象は現在のコマで、元画像の保存先や画素を変更しない。受信ソフトが遅れて読み込む場合に備え、渡した一時ファイルはドラッグ終了時に削除しない。

上部の従来のファイルドラッグとF6は、未編集の静止画なら元ファイルを渡す従来動作を維持する。下部の新しいボタンは、選択したファイル名・形式で書き出す操作である。

## モードの切り替え

通常起動時は閲覧UIを表示する。上のツールバーの鉛筆付き画像アイコン「画像編集モードに切り替え」を押すと、左端に縦のツール列を表示する。上のアイコンは押された表示となり、ツールチップは「画像編集モードを終了」に変わる。同じアイコンをもう一度押すと閲覧UIへ戻る。編集メニューの「画像編集モード」でも切り替えられる。

最初は矩形選択。以後は同じウィンドウ内で最後に使ったツールを再選択する。次の起動には編集モードを引き継がない。モード切り替えだけでは画素・保存済み設定・Undoを変更しない。

閲覧へ戻る時は、描画中の選択を中止して開始前の選択へ戻し、未確定の仮置きも中止する。確定済みの画像編集と選択範囲は保持する。閲覧中の左ドラッグは既存のマウス設定に戻る。

## 左ツール列

上のツールバーと同じWindows標準の平面ボタンと、既存のベクター描画アイコンを使う。ラベルはツールチップに表示する。21個の操作ボタンと4個の区切りがあり、縦1列で配置する。現在のツールは押された表示とし、画像や選択範囲が必要な操作は対象がない時に無効化する。

| グループ | ボタンと動作 |
| --- | --- |
| ツール | 手のひら（表示を移動）、ペン、文字入れ、選択画像の移動・変形、矩形選択、自由選択、折れ線選択 |
| 画像の形 | 選択範囲でペースト、トリミング、画像サイズ変更、キャンバスサイズ変更 |
| 向き | 右90度回転、左右反転、上下反転 |
| 色調整 | 明るさ、色合い、レベル調整 |
| 選択操作 | すべて選択、選択範囲を反転、選択を解除、選択範囲を削除 |

手のひらは画像の表示位置を動かす。移動・変形は選択した画像の画素を仮置きし、ハンドルや枠外のドラッグで拡縮・回転して確定／中止する。両者は別の操作として表示する。仮置きの確定・中止・位置／サイズ／角度の数値入力は、これまでどおり上のツールバーに出す。

小さいウィンドウではツール列だけを縦スクロールする。スクロールバーまたはツール列上のホイールを使う。ツール列は上のツールバーからステータス／アニメ操作バーの手前までに収め、下のアニメ用シークバーと重ねない。

追加したのは既存機能への操作入口。新しい描画ブラシ・レイヤー・回転付きトリミング専用機能は含まない。後者は[別の計画](gvn-interactive-crop-plan.md)のまま。

## 選択範囲の統合

選択するツールは1つの状態で管理し、旧来のON/OFF用の状態変数を廃止した。矩形・自由・折れ線は、同じ`SelectionRegion`と同じ開始・確定・中止処理を使う。コピー・切り取り・削除・反転・加工・仮置きは、この1つの範囲を参照する。

旧「範囲選択モード」という重複メニューを取り除き、「画像編集モード」と各ツールに整理した。既存設定のコマンドIDは変えない。Sキー／旧`SelectMode`は矩形選択と閲覧への切り替えとして扱う。自由・折れ線中にSを押すと矩形選択に切り替える。

左ツール列やメニューで選択したツールを、編集モードの左ドラッグで使う。マウス設定の「範囲を選択」は「選択ツールで範囲を選択（閲覧時は矩形）」と表示する。この割り当てでも同じ処理へ進み、閲覧時は矩形、ツール選択中はそのツールを使う。Xボタン等へ割り当てた場合も同じ範囲モデルを使う。閲覧時の既存のスクロール・OLE・ホイール設定は維持する。

追加はShift、除外はAlt、交差はCtrlを選択開始時に判定する。矩形のドラッグ終点は従来どおりその画素を含める。フリー単位なら(10,12)から(50,40)の画素をドラッグすると41×29px。自由・折れ線は画素中心によるポリゴンの内外判定を使う。

## 動く黒白の1px破線

0.62.0の指定に従い、選択線をPhotoshopのように黒白の破線が流れる表示へ変更した。画像倍率やDPIによらず1物理px。矩形・自由・折れ線・作成中・仮置きで共通。画像やコピー・保存には焼き込まない。選択がなければ、または最小化中は表示更新を止める。

選択範囲内の素の左ドラッグは移動・自由変形を開始する。クリック・微小移動・追加／除外／交差操作は区別する。Spaceを押している間の一時手のひらと、小画像の手のひら移動も実装した。[操作と設定の仕様](gvn-selection-interaction-0.62.md)を参照。

## キャンバスと座標

ツール列の幅をキャンバス幅から差し引いてフィット、ズーム、表示スクロール、画像座標を計算する。キャンバスの横スクロールバーもツール列の右へ寄せる。下のアニメ操作バーとステータスはウィンドウ全幅を使う。

描画時だけ描画ターゲットをツール列の幅だけ平行移動し、表示画像のサンプリング用座標はキャンバス内で維持する。入力時には左余白を差し引く。原寸表示では、画像を描く時と同じ切り下げ済みの原点を、選択・仮置きの両方に使う。奇数サイズの表示領域で0.5pxずれていた選択座標を修正した。専用自動操縦の画像座標入力とスクロールバー検査も同じ左余白を考慮する。
