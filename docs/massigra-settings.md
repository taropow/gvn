# MassiGra 0.45 設定とカスタマイズ

[全体仕様](massigra-spec.md)の設定詳細。公式ヘルプにある設定11ページ、キー設定、マウス設定2ページ、プラグイン設定、外部アプリ設定を整理する。設定名を参照しやすいよう、公式の語句を基本とし、空白や表記を一部統一した。

チェック項目の存在と動作は、初期状態で有効であることを意味しない。本文や履歴で初期状態が明記される場合を除き、初期値は実機確認の対象とする。一般設定の「標準の設定に戻す」は、そのページ内の項目を戻す操作である。[設定の目次](http://www.massigra.net/massigrahelp/currentver/d_prop.htm)

## 1 全般

| 設定項目 | 動作と条件 |
| --- | --- |
| 多重起動を許可 | 複数起動を許す。無効なら、再起動時に指定されたファイルを既存ウィンドウで開く |
| 多重起動しない場合ウィンドウをアクティブ | 既存ウィンドウに処理を渡すとき、アクティブにする |
| ファイルドロップされたらアクティブ | ドロップを受けたウィンドウをアクティブにする |
| 物理メモリを超えるサイズの画像を扱う | 拡大縮小・画像サイズで物理メモリを超える画像の作成を許す。画像の読み込み時には関係しない |
| 元に戻すを利用する | 1段階のUndoを有効にする。無効なら元画像保持の処理とメモリを節約 |
| 切り取りの背景色 | 切り取り後の塗り潰し色 |
| 選択範囲が無い時の貼り付けは新規画像に貼り付け | 有効なら新規画像に貼る。無効なら現在画像の全体が選択されている扱いで貼る |
| 最近開いたフォルダを保存する | 履歴を次回へ引き継ぐ |
| 起動時に前回終了時に開いていたファイルを開く | 起動引数のファイル指定がなければ前回画像を開く。見つからなければそのフォルダの先頭を開く |
| IMEを無効化する | 日本語入力中にキー操作が効かなくなることを防ぐ |
| 標準の設定に戻す | 全般ページだけを標準状態に戻す |

物理メモリ超過の許可は、1 GBの画像データ上限を解除する機能ではない。[全般](http://www.massigra.net/massigrahelp/currentver/d_prop_gene.htm)、[仕様と制限](http://www.massigra.net/massigrahelp/currentver/specifi.htm)

## 2 背景

| 設定項目 | 動作と条件 |
| --- | --- |
| 背景をタイル状にする | 表示ウィンドウの背景に2色のパターンを使う |
| 背景パターンのサイズ | タイルのサイズ。小さくするほど描画の負荷が増える |
| 背景色1 | 単色背景の場合も使用する色 |
| 背景色2 | タイル用のもう1色 |
| 背景プレビュー | 現在の配色とパターンを表示 |
| 標準の設定に戻す | 背景ページを戻す |

透過画像の読み込み時に合成する背景色は、ファイル読み込みページの別設定である。[背景](http://www.massigra.net/massigrahelp/currentver/d_prop_bg.htm)

## 3 ウィンドウ

| 設定項目 | 動作と条件 |
| --- | --- |
| ウィンドウを画面の中央に置く | 起動時に中央配置。自動サイズ調整もウィンドウ中央を基準にする |
| サイズ自動調整時にツールバーより小さくしない | ツールバーが収まる横幅を下回らないようにする |
| 起動時の位置 | 起動位置の指定方法を選ぶ |
| ユーザー指定位置のX / Y | 起動位置を数値指定 |
| ユーザー指定位置の幅 / 高さ | 起動サイズを数値指定 |
| 現在の位置とサイズ | 現在値をユーザー指定欄へ取り込む |
| 起動時の表示状態 | 起動時のウィンドウ状態を選ぶ |
| 前回終了時に最大化していたら最大化 | 起動状態が通常の場合に適用 |
| 前回終了時に全画面表示していたら全画面表示 | 起動状態が通常の場合に適用。スライドの全画面オプションとは別 |
| 標準の設定に戻す | ウィンドウページを戻す |

位置の指定方法と表示状態のコンボボックスについて、全選択肢は公式の文章には列挙されていない。[ウィンドウ](http://www.massigra.net/massigrahelp/currentver/d_prop_wnd.htm)

## 4 表示

### 4.1 基本表示とフィット画質

| 設定項目 | 動作と条件 |
| --- | --- |
| 画像をウィンドウの中央に表示 | 無効なら左上。ただし全画面中は中央 |
| アニメGIFの速度制限 | ブラウザに似せた遅延、ループ回数解釈、異常な背景処理の扱い |
| 拡大の最大倍率 | ウィンドウに合わせる場合の拡大上限。手動ズームとは別 |
| %以上は単純拡大 | 指定倍率以上を単純拡大にする。100未満ならこの条件を無効化 |
| 縮小方法 | 通常ウィンドウのフィット用縮小アルゴリズム |
| 拡大方法 | 通常ウィンドウのフィット用拡大アルゴリズム |

### 4.2 漫画モード

| 設定項目 | 動作と条件 |
| --- | --- |
| 連結する前に回転オプションの処理をする | 有効なら各画像を回転後に連結。無効なら連結後に回転 |
| 左右の縦サイズが違う場合 | 指定色で差分を塗り潰す、小さい方に合わせる、大きい方に合わせる |
| 塗り潰しの色 | 指定色による埋め合わせ時だけ表示 |
| 縮小方法 | 小さい方に合わせる場合だけ表示 |
| 拡大方法 | 大きい方に合わせる場合だけ表示 |
| 標準の設定に戻す | 表示ページ全体を戻す |

フィットのアルゴリズムは全画面用と別設定。手動ズームの補間設定とも別である。[表示](http://www.massigra.net/massigrahelp/currentver/d_prop_view.htm)

## 5 ズーム

| 設定項目 | 動作と条件 |
| --- | --- |
| 縮小時に補間する | 無効なら単純縮小。選択モード中は常に単純縮小 |
| 拡大時に補間する | 無効なら単純拡大。選択モード中の低画質化も適用 |
| %以上は単純拡大 | 大倍率で補間によるぼけを避ける。100未満ならこの条件を無効化 |
| ドラッグズームの最中は低画質 | 操作中の処理負荷を下げる |
| ズーム倍率の変更方式 | 倍率ステップの方式を選ぶ |
| 100%未満 | 「指定%ずつ」方式で、100%未満のステップ幅 |
| 100%以上 | 同方式で、100%以上のステップ幅 |
| 標準の設定に戻す | ズームページを戻す |

倍率変更方式の全選択肢、各初期値、数値欄の最小・最大は文章では確認できない。[ズーム](http://www.massigra.net/massigrahelp/currentver/d_prop_zoom.htm)

| 設定項目 | 動作と条件 |
| --- | --- |
| 全画面時に表示する | キャプションと同じ内容を画面内に表示 |
| 全画面ではない時にキャプション非表示なら表示する | 通常ウィンドウでもタイトルバーを消した場合に表示。選択モード中は表示しない |
| アニメーション表示中も表示する | GIF再生中にも重ねる。アニメーションが滑らかでなくなる場合あり |

画像のスクロール中、ドラッグズーム中はファイル名を表示しない。フルパスを出すかはバー設定のキャプション表示方法で決める。[全画面表示](http://www.massigra.net/massigrahelp/currentver/d_prop_full.htm)

公式0.45のリソースで、位置は上下左右と中央の9方向、背景は透明・塗り潰す・影を表示の3方式と照合した。[抽出記録](massigra-native-reference.md)を参照。長い文字列の末尾表示は公式変更履歴でも確認する。

## 8 移動

| 設定項目 | 動作と条件 |
| --- | --- |
| スキップ数 | 前後スキップで移動するファイル数 |
| 次の / 前のフォルダ等で開いたフォルダも履歴に追加 | フォルダ移動による訪問も履歴へ逐次登録 |
| 前のフォルダでフォルダの先頭へ移動 | 無効なら末尾。終端通知ダイアログの「前のフォルダへ」とは別の設定 |
| 前隣のフォルダでフォルダの先頭へ移動 | 無効なら末尾 |
| 親フォルダでフォルダの先頭へ移動 | 無効なら末尾 |
| 最後 / 最初に到達した時 | 終端での動作を選ぶ。全選択肢は文章に列挙されていない |
| 最後 / 最初に到達した時に音を鳴らす | 通知ダイアログを出さない設定でも音を鳴らせる |
| 右から左の漫画モードでツールバーの前 / 次を逆にする | 機能は反転するがボタン画像はそのまま |
| 右から左の漫画モードでジャンプのスクロールバーを逆にする | 先頭と末尾の対応を反転 |
| 標準の設定に戻す | 移動ページを戻す |

訪問履歴の追加を無効にしても、新規のファイルを開く操作の直前と終了時のフォルダは履歴へ追加される。[移動](http://www.massigra.net/massigrahelp/currentver/d_prop_move.htm)、[0.44の変更](http://www.massigra.net/massigrahelp/currentver/history.htm)

## 9 ファイル操作

保存、名前変更、削除、移動、コピーに関する確認と継続動作を設定する。[ファイル操作](http://www.massigra.net/massigrahelp/currentver/d_prop_fope.htm)

| 設定項目 | 動作と条件 |
| --- | --- |
| 上書き保存でもダイアログを開く | 保存形式ごとの設定を表示。プラグイン画像ではこの設定に関係なく別名保存となる |
| 上書き保存の前に上書き確認する | 通常の上書き時の確認。別名保存の同名確認は設定によらず行う |
| 名前を付けて保存のパスを保持する | 前回保存したフォルダを次回の基点にする |
| ファイル名変更後に表示順を整理 | リネーム後に一覧を並べ直す |
| 削除する前に確認する | 削除確認。Windowsのごみ箱設定によって表示されない場合あり |
| 削除したファイルはごみ箱へ | 無効なら直接削除。OS設定により有効でも直接削除になる場合あり |
| 削除や移動したら次のファイルを表示 | ファイル整理後に次の画像へ進む |
| ファイルを移動する時に上書き確認する | 移動ダイアログと、登録先への直接移動に共通 |
| ファイルをコピーする時に上書き確認する | コピーダイアログと、登録先への直接コピーに共通 |
| 標準の設定に戻す | ファイル操作ページを戻す |

## 10 ファイル読み込み

| 設定項目 | 動作と条件 |
| --- | --- |
| 透過BMPを透過表示 | V4 / V5ヘッダの、アルファマスクが有効なビットフィールドBMPを対象とする |
| 透過GIFを透過表示 | アニメーション表示中は設定によらず透明情報を利用 |
| GIF背景色を利用 | ファイルに背景色があれば透過表示の背景に使う |
| 透過PNGを透過表示 | 透明色情報付き、ビット深度16のPNGは対象外 |
| PNG背景色を利用 | ファイル内の背景色を利用 |
| 透過表示の背景色 | 読み込み時の合成先背景色 |
| アニメGIFをアニメーション表示 | 無効なら最初のフレームだけを表示 |
| JPEGのExif情報に従い回転して表示 | 方向情報を使って表示。ファイルを書き換えない |
| ビットフィールド画像を読み込んだら自動的に24 BPP化 | 表示品質のための内部変換。ファイルを書き換えない。True Color画面以外では意味がないとされる |
| 隠しファイルも読み込む | ファイルリストへ隠し属性のファイルも含める |
| システムファイルも読み込む | システム属性のファイルも含める |
| 保護されたオペレーティングシステムファイルも読み込む | 隠し属性とシステム属性の両方を持つファイルも含める |
| 標準の設定に戻す | ファイル読み込みページを戻す |

透明画像は読み込み時点で背景色と合成する。プラグイン優先を有効にしている場合は、対応プラグインの読み込みが優先され、標準ローダ用の設定だけでは結果を決められない。[ファイル読み込み](http://www.massigra.net/massigrahelp/currentver/d_prop_fload.htm)

## 12 キー設定

### 12.1 機能の選択

機能と割り当てキーの一覧から、項目をダブルクリック、またはSpaceで選んで割り当てダイアログを開く。「▼ファイル」のようなカテゴリ見出しへは割り当てできない。サブメニューを直接開く場合は、別に用意されたポップアップメニューの機能を選ぶ。

標準設定への復元は、全ショートカットを対象にする。[キー設定](http://www.massigra.net/massigrahelp/currentver/d_keycstm.htm)

### 12.2 割り当ての編集

1機能に最大8個。現在のキー一覧、先頭へ移動、削除、新しいキーの入力、登録を備える。先頭のキーがメニュー項目へ表示される。

キー入力欄ではTabも割り当て対象となるため、通常のTabによるフォーカス移動ができない。特別にCtrl + Alt + Shift + Tabで移動し、この組み合わせ自体は登録できない。[キー割り当て](http://www.massigra.net/massigrahelp/currentver/d_keyset.htm)

### 12.3 登録上の制限

| 分類 | 制限 |
| --- | --- |
| 記号キー | 英数字以外の文字キーとCtrlの組み合わせは不可 |
| テンキーとShift | Shift併用で別のキーとして認識される場合あり |
| 日本語入力キー | 半角 / 全角、カタカナ / ひらがなは登録不可 |
| Lock系 | CapsLockなどは登録不可 |
| 特殊キー | 音量操作などは登録不可 |
| OS予約 | Alt + Tab、Alt + Shift + Tab、Alt + Esc、Ctrl + Esc、Ctrl + Alt + Delete、PrintScreen、Windowsキーは不可 |
| 無変換 | 単独は登録可能。Ctrl + Alt、またはCtrl + Alt + Shiftとの組み合わせは登録できない可能性あり |
| 変換 | 0.44の更新で登録可能になったと記載 |

0.43ではWM_APPCOMMANDへの対応に伴い、Back、Forward、Refresh、Stopの旧キー項目が削除されている。古い設定の「??」は削除するよう案内される。[キー割り当て](http://www.massigra.net/massigrahelp/currentver/d_keyset.htm)、[更新履歴](http://www.massigra.net/massigrahelp/currentver/history.htm)

## 13 マウス設定

### 13.1 オプション

| 設定項目 | 動作と条件 |
| --- | --- |
| ホイールのスクロール量 | ボタンを押しながらのホイール等による移動量 |
| ドラッグのスクロール量 | ドラッグによる移動量 |
| ドラッグのズーム速度 | ドラッグ量に対する倍率変化 |
| ドラッグのズーム方向 | ズームを判定するドラッグ方向 |
| ドラッグ開始までの余裕 | 移動量が閾値を超えたらドラッグ、以内で離せばクリック |
| ホバースクロールの余白 | 上下左右の判定領域の余白。50%なら全面が余白となる |
| ホバースクロールの最小移動量 | カーソル移動に対する画像スクロールの最小値。0で遅すぎる場合は1が案内される |
| クリックによるアクティブ化時はクリックの機能を無効化 | 非アクティブ画面の最初のクリックで割り当て機能を発動させない |
| ホイールの反応を鈍くする | 緩いホイール等による反応を抑える |
| 標準の設定に戻す | オプションページを戻す |

「ドラッグ開始までの余裕」は、システム標準のウィンドウ移動と範囲選択ドラッグには適用されない。[マウスオプション](http://www.massigra.net/massigrahelp/currentver/d_mous_op.htm)

### 13.2 カスタマイズ

まず操作を選び、その操作単独、または左・右・中・X1・X2を押しながら行った場合の機能を選ぶ。たとえば左クリックを選択し「右ボタン押しながら」へ機能を割り当てると、右を押しながら左クリックした場合の機能になる。

| 規則 | 内容 |
| --- | --- |
| 単独の機能 | 他ボタンを押していない場合。操作の種類により表示位置が変わる |
| ボタン併用 | 左・右・中・X1・X2を押しながらの操作を設定 |
| ドラッグ | 「単独」の欄はなく、ボタン別のドラッグ機能を設定 |
| 重複割り当て | ドラッグでは同じ機能を複数ボタンに設定できない |
| システム標準のウィンドウ移動 | 左ドラッグ専用。これを選ぶと左クリックと、他操作の「左を押しながら」が使えない |
| クリックとダブルクリック | 1回目のクリックが先に実行され、ダブルクリック機能が発動できない場合あり |
| ウィンドウ枠上のX1 / X2 | カスタマイズを無視して前 / 次のファイル |
| 標準の設定に戻す | カスタマイズページ全体を戻す |

この仕様は、単一ボタンへのコマンド登録だけでなく、複数ボタンの組み合わせを扱う。ドラッグ方向を使う任意形状のマウスジェスチャ機能があるという意味ではない。[マウスカスタマイズ](http://www.massigra.net/massigrahelp/currentver/d_mous_cs.htm)

## 14 メニュー以外の割り当て可能な機能

| 機能群 | 内容 |
| --- | --- |
| 直接削除 | ごみ箱を経由しない |
| ランダムジャンプ | フォルダ内からランダムに1件を表示 |
| ダイアログなしの自動スライド | 開始・停止を直接切り替える |
| 原寸とフィットの切り替え | 原寸ならフィット、それ以外なら原寸 |
| フィットと原寸の切り替え | フィットなら原寸、それ以外ならフィット |
| ポップアップメニュー | 親メニュー、子メニュー、孫メニューを直接開く |
| スクロール | 上下左右へ移動 |
| 位置指定スクロール | 右上、左上等へ移動 |
| 右から左の漫画モードに対応した機能 | 前後や左右を読み方向に応じて反転 |

原寸・フィットの2種類の切り替えは、手動ズームなど第三の状態から実行したときの到着先が異なる。登録送り先は移動用とコピー用で別管理。送り先未設定なら登録ダイアログを開き、上書き確認は直接実行にも適用する。[割り当て可能な機能](http://www.massigra.net/massigrahelp/currentver/custom.htm)

## 15 プラグイン設定

### 15.1 設定画面の項目

| 項目 | 動作 |
| --- | --- |
| プラグインがあるフォルダ | 絶対・相対パスの入力、フォルダのドロップに対応 |
| 参照 | フォルダ選択ダイアログ |
| 画像用 / 書庫用プラグイン | 一覧の表示切り替え。どちらか一方しか使えないという制約ではない |
| プラグイン一覧 | ファイル名と対応拡張子。利用するものをチェック |
| 設定 | 選択プラグイン自身の設定画面を開く。設定画面がないものもある |
| 情報 | プラグインの情報を表示 |
| 標準のローダよりプラグインを優先する | 重複する形式をプラグインで読む |

相対パスの基準は本体の所在フォルダ。空欄はプラグイン無効、`.`は本体と同じフォルダ。プラグインを更新したり設定を変えたりした後は、この画面を開いてOKで確定し、対応状態を再認識させる。

プラグイン自身の設定はレジストリやiniに記録され、他のソフトから同じプラグインを使う場合にも影響する。ポータブル運用ではこの保存場所も別途考える必要がある。

GIFプラグインを標準ローダより優先するとアニメGIFは再生できない。JPEGでも内部形式への変換が必要なため、プラグインを使う方が常に速いわけではない。[プラグイン設定](http://www.massigra.net/massigrahelp/currentver/d_plugset.htm)、[FAQ](http://www.massigra.net/massigrahelp/currentver/faq.htm#q0018)

### 15.2 公式の個別注意事項

以下はヘルプが特定の版について記載した相性情報であり、同名プラグインの現在の全バージョンに一般化しない。

| プラグインと版 | 公式記載の状況 |
| --- | --- |
| ifTEXT.spi 0.7 | 読み込み後にプラグイン設定を開くとエラー。利用しないよう警告 |
| マンガミーヤ同梱DLL 7.3 | spiへ拡張子変更したpng.dllでエラー、jpg.dllで幅の誤認や読み込み失敗。利用しないよう警告 |
| ifpsd.spi / axpsd.spi 1.0.2.1 | 設定画面を閉じると「設定ダイアログはありません」と表示するが問題なし |
| tar32.dll 2.39 | spiへ変更して使用可能。内部フォルダ単位で整列できない |
| ifmm.spi 1.3.6 | プラグインの「登録アプリ」にMassiGraを登録すると使用可能 |

プラグインのフォルダや本体フォルダに外国の文字を含む場合、または保護領域に配置する場合には動作上の制限がある。[Susie Plug-in対応状況](http://www.massigra.net/massigrahelp/currentver/spiinfo.htm)

## 16 他のアプリの設定

### 16.1 登録項目

| 項目 | 動作 |
| --- | --- |
| リスト | 1〜9の登録枠を選ぶ |
| 順番を1つ上 / 下に | 登録の順序を変更 |
| メニュー項目名 | 最大50文字。空欄ならその登録枠はメニューに表示しない |
| 実行ファイル名 | ドロップでフルパスを入力。相対パスはMassiGra本体が基準 |
| 送る | 起動先へ渡す対象を指定。現在ファイルやフォルダのパス等 |
| 起動後MassiGraを終了 | 外部アプリの起動後に終了 |
| ウィンドウ | 最大化等の起動状態。ただし相手アプリが従わない場合あり |
| アクション | 通常は空欄。システムの関連付けを使う場合、`edit`等の動詞を指定可能 |
| メニュー項目の下に区切りを表示 | 区切り線を追加 |
| 書庫内でファイルパスを送る時、書庫内パスを含める | 無効なら書庫ファイル自体のパス |
| 書庫内でフォルダパスを送る時、書庫ファイルのパスを送る | 無効なら書庫が所在するフォルダ |
| 初期状態に戻す | 選択している番号だけを戻す |

実行ファイルが空欄でも、現在ファイルまたはフォルダのパスを送る設定なら、システムの関連付けで開ける。初期状態の8番は現在ファイル、9番は現在フォルダを開く。[外部アプリ設定](http://www.massigra.net/massigrahelp/currentver/d_otherapp.htm)

### 16.2 コマンドラインの指定

実行ファイル欄へ引数も入力できる。実行ファイルパスを引用符で囲み、その後に引数を付ける。この方式では「送る」のファイル・フォルダパス指定を使わず、引数内の置換記号を使う。

| 記号 | 置換対象 |
| --- | --- |
| `($f)` | 現在ファイルのパス |
| `($d)` | 現在フォルダのパス |

空白を含むパスに対応する例：

```text
"C:\sample\app.exe" /option "($f)"
```

これは設定欄へ記載する構文例であり、MassiGraの起動オプションではない。表示中の画像データと、保存済みファイルのパスも区別する必要がある。[コマンドライン指定](http://www.massigra.net/massigrahelp/currentver/d_otherapp.htm)
