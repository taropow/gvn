# MassiGra 0.45 全メニュー一覧

[全体仕様](massigra-spec.md)の機能照合用付録。公式の[全メニューリスト](http://www.massigra.net/massigrahelp/currentver/menulist.htm)から階層と項目名を整理した。各項目のリンクは公式説明へ移動する。

最上位はファイル、編集、画像、リスト、表示、その他の6種類。動的な履歴一覧は展開せず、外部アプリの1〜9は公式と同じ1行表記とした。メニューの存在と、現在の画像で実行可能かは別である。
