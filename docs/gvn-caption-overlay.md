# ファイル名の重ね表示の実装契約（0.7.0）

[元の全画面設定](http://www.massigra.net/massigrahelp/currentver/d_prop_full.htm)と、[公式配布リソース](massigra-native-reference.md)に合わせる。

表示内容はWindowsへ設定するキャプション文字列と同じ1つの値を使う。ファイル名方式、編集済み印、Fit/倍率、ステータス非表示時のファイル順序等の変更を反映する。長いパスが幅に収まらないときは、ファイル名を含む末尾側を見せる。

全画面での有効/無効と、通常表示でキャプション非表示の場合の有効/無効を分離する。通常表示の選択モード中は隠す。アニメーション画像は再生/停止によらず、アニメ用のチェックが有効な場合だけ重ねる。画像がない場合は表示しない。

画像のドラッグ移動・ドラッグズーム・スクロールバー追跡中は隠し、操作終了で復帰する。ホイール・キー・ホバーなどのスクロールは、最後の移動から150msの静止後に復帰する。タイマーと捕捉解除で状態を復元し、アニメ再生時計やシークのタイマーと分離する。

位置は上下左右と中央の9方向、背景は透明・塗り潰す・影の3方式。文字色と背景色を指定できる。Windows標準フォントダイアログで、フォント名・サイズ・太字等のウェイト・斜体・下線・取り消し線・文字色を選ぶ。0.44では独自サイズ上限を撤廃し、Windows標準の選択範囲を使う。文字セットも選択・保存する。内部では0.1pt単位で保存し、ウィンドウのDPIから描画ピクセルへ変換する。既定はMS UI Gothic 10pt、白文字と黒い影、左上、通常/全画面有効、アニメ無効とする。元アプリの既定値と同じだとする確認はまだ行っていない。

文字と背景は画像用ビューポート内へクリップし、ツールバー・画像スクロールバー・下部プレイヤー・ステータスへは描かない。配置で長い文字や大きなフォントが画面外へはみ出すことを防ぐ。DirectWriteのレイアウトを再利用し、同じキャプションのアニメフレームごとに作り直さない。透明背景上の文字はグレースケールでアンチエイリアスし、色の縁を避ける。

元のRGBA、クリップボード、保存、OLE一時PNGへは文字を焼き込まない。表示時と画面取得時は同じ描画処理を使う。全画面設定のリセットはフォントと色を含むこのページの項目を戻し、他ページの未適用値を保持する。フォントダイアログのキャンセルも変更を残さない。

0.44では旧ラスタ/＠字体をGDIの表示用マスクで補い、通常字体のDirectWriteとキャッシュを維持する。[字体とサイズの実装契約](gvn-fonts.md)を参照。非対話ステーションで取得したWindows標準ダイアログは入力欄とオーナー描画の選択欄を含むが、色面とフォント見本の描画領域は取得できない。実入力、標準APIの戻り値、本体で描いた文字と色を照合し、取得できない部分の外観確認と区別する。

検証対象は、配置の境界、実描画の3背景×9位置、レイアウト再利用、長い名前、設定往復と破損値、通常/全画面/選択/アニメ、操作中の抑止と復帰、実標準フォントダイアログ、コピーしたRGBAの一致。証跡は専用シナリオ13と統合・描画・設定試験へ対応付ける。
