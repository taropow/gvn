# 普段使い用の固定フォルダ

起動先は **`G:\gvn\app\gvd.exe`**。製品名はGVNのまま、ユーザー指定に合わせて日常用のファイル名を`gvd.exe`とする。バージョン番号付きのdistフォルダと分け、更新後もこのパスを使う。

0.59.0ではEXEに固有アイコンを追加し、既存のタスクバー固定項目も対象パスを照合してアイコン参照を更新する。配布`app.ico`からハッシュ付きファイルを作るため、旧EXEのアイコンキャッシュを使い続けない。[仕様](gvn-app-icon-and-empty-tap.md)。

設定は既存の`%LOCALAPPDATA%\GVN\settings.ini`をそのまま使う。EXEの名前を変えても設定フォルダは変わらない。更新処理はユーザーの設定・画像・その他のファイルを削除しない。

## 起動中の画面を保持した更新（0.67.0）

```powershell
.\tools\update_daily.ps1 -SourceDirectory .\dist\GVN-0.67.0-light -PreserveRunning
```

起動中のEXEを一意な `app\.previous\gvd-running-<ID>.exe` に退避してから、検証済みの本体を固定パスへ置く。既存ウィンドウを閉じず、画像とクリップボードに触れない。既存の画面は起動時の版を使い続け、新規起動から更新版になる。候補と退避本体のハッシュ、インストール結果を確認し、置換途中に失敗した場合は退避本体を戻す。更新処理はインストール先ごとのミューテックスで直列化する。OSのロック状態で退避できない場合はエラーとして残し、強制終了しない。

スイッチなしの終了待ち更新も引き続き利用できる。

## 配布更新時の手順

新しい製品の変更範囲と配布版の主要経路を確認した後、次を実行する。

```powershell
.\tools\update_daily.ps1 -SourceDirectory .\dist\GVN-<バージョン>-light
```

通常版の配布フォルダも指定できる。SHA256とEXEの製品名・版、ライセンスを確認し、一時領域でコピーを照合してから同じ`gvd.exe`へ差し替える。更新前の本体は`app\.previous\gvd.exe`へ残す。ライセンスと`installed.json`、固定名の`SHA256.txt`も更新する。製品本体の再ビルドはこのコピー操作だけのためには不要。

`tools/package.ps1`による通常の製品パッケージ作成では、最後にこの固定先も更新する。`-DocsOnly`では更新しない。パッケージを作るだけの場合は`-SkipDailyUpdate`を指定する。専用の配布最終化スクリプトを使う場合にも、確認に成功した配布フォルダから上のコマンドを実行する。

固定先のアプリが使用中で本体を差し替える必要がある場合、強制終了せず`Deferred`を返す。閉じてから同じ更新コマンドを再実行する。既に同じ本体なら`AlreadyCurrent`で本体を再置換しない。

0.60.0から、使用中のアプリが閉じられた時に更新する場合は次を使える。

```powershell
.\tools\update_daily_when_closed.ps1 -SourceDirectory .\dist\GVN-0.60.0-light
```

パッケージを照合し、`app/.pending-update.json`へ更新予定を保存する。画面を出さない一度限りの補助プロセスが、固定先と完全一致する`gvd.exe`だけの終了を待ち、既存の検証付き更新処理を呼ぶ。画像や設定、開いている文書を操作せず、アプリを強制終了しない。結果は`app/last-pending-update.json`、更新後の版は`app/installed.json`へ記録する。成功後に待機を終了する。待機中に新しい版を予約した場合は最後の予約を読む。失敗時は更新予定とエラー記録を残す。

インターネット監視、自動起動登録、定期実行は追加しない。使用中でなければ通常の`update_daily.ps1`ですぐ更新できる。

2026年10月21日に0.58.0を配置し、同じ版での再更新、実際に起動した旧版を終了せず保留する動作、終了後の差し替えと旧EXE退避、設定/利用者ファイル保持、破損配布の拒否を確認した。固定名の本体から透明PNGと空画面を専用デスクトップで実際に描画する2経路も成功した。[確認記録](verification/0.59.0-daily-installation.json)。製品の再ビルドや全体試験は行っていない。
