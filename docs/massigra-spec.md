# MassiGra 0.45 仕様と機能

MassiGraをベースに画像ビューアを設計するための、操作と動作仕様の整理。対象は、指定された[基本的な使い方](http://www.massigra.net/massigrahelp/currentver/basic.htm)を起点とする公式ヘルプのVersion 0.45である。

MassiGraの中心は、フォルダ内の画像を軽快に送って見る単画面ビューアである。閲覧に加え、画像加工、ファイルの振り分け、Susie Plug-inによる形式拡張、キーとマウス操作の変更を備える。新しいビューアの機能範囲を決める際は、これらを個別に比較できる。

調査日：2026年10月18日。基準版：0.45、公開日：2013年4月23日。以下の動作環境と制限は当該版の仕様であり、現在のWindowsでの実測結果ではない。仕様として記載する範囲は公式ヘルプで確認できる内容とし、実機での確認が必要な事項は末尾にまとめた。[更新履歴](http://www.massigra.net/massigrahelp/currentver/history.htm)

## 2 画面構成と情報表示

### 2.1 画面の構成要素

画像表示領域に加え、キャプション、外側の枠、内側の枠、メニューバー、ツールバー、ステータスバー、スクロールバーがある。各要素の表示は「表示 → ウィンドウ」から変更できる。メニューバーと右クリックのポップアップメニューは同じ項目を持つ。

| 要素 | 主な役割と挙動 |
| --- | --- |
| キャプション | ファイル名と表示状態を表示。非表示にできる |
| 外側の枠 | キャプション非表示時に切り替え可能。枠を非表示にすると通常の枠によるサイズ変更ができない |
| 内側の枠 | 画像表示領域の内側の枠を切り替え |
| メニューバー | 全機能への入口。右クリックメニューと同一内容 |
| ツールバー | 日常の閲覧操作。右クリックでもポップアップメニューを表示 |
| ステータスバー | 画像、ファイル、リスト内位置の情報 |
| スクロールバー | 画像が表示領域に収まらないときの移動に使用。非表示にもできる |
| 背景 | 単色、または2色のタイル状パターン。色とパターンサイズを変更可能 |

キャプションを消した状態でも、Ctrlを押しながら表示領域を左ドラッグするとウィンドウを移動できる。マウス設定でウィンドウ移動を割り当てれば、Ctrlなしの操作にも変更できる。[ウィンドウメニュー](http://www.massigra.net/massigrahelp/currentver/m_v_wnd.htm)、[背景設定](http://www.massigra.net/massigrahelp/currentver/d_prop_bg.htm)

### 2.2 キャプションに表示する状態

| 表示 | 意味 |
| --- | --- |
| ファイル名 | 表示中のファイル。表示方法は設定可能 |
| `<Zoom>`、`<Fit>`と倍率 | ズーム表示中、またはウィンドウに合わせた表示中 |
| `Lock` | ズーム倍率を固定中 |
| `<見開き>` | 漫画モードで見開き表示中 |
| `<書庫>` | 圧縮ファイル内の画像を閲覧中 |
| `<自動>` | 自動スライド中 |
| `<透明>` | 透明情報を利用して読み込んだ画像 |
| `<アニメ>` | アニメGIFをアニメーション表示中 |

ステータスバーを非表示にした場合、フォルダ内での順番と対応ファイル総数をキャプションにも表示する。書庫内では、ファイル名だけを表示する設定でも書庫内パスを含む。[基本的な使い方](http://www.massigra.net/massigrahelp/currentver/basic.htm)、[表示](http://www.massigra.net/massigrahelp/currentver/m_view.htm)、[仕様と制限](http://www.massigra.net/massigrahelp/currentver/specifi.htm)

### 2.3 ステータスバー

通常時は左から、次の情報を表示する。

1. 画像の幅 × 高さ × BPP。
2. フォルダ内の順番 / フォルダ内の対応ファイル総数。
3. 表示倍率。
4. ディスク上のファイルサイズ / メモリ上の画像データサイズ。
5. ファイルの更新日時。

BPPは1画素あたりのビット数であり、圧縮されたファイルサイズとは別の指標である。選択モードでは表示内容が変わり、選択単位、始点、終点、範囲サイズ、カーソル座標、カーソル位置の画素色を表示する。[基本的な使い方](http://www.massigra.net/massigrahelp/currentver/basic.htm#sttb)、[編集メニュー](http://www.massigra.net/massigrahelp/currentver/m_edit.htm#selmode)

### 2.4 バーの自動表示

全画面表示では、有効なツールバーとステータスバーはカーソル位置によって自動表示・非表示になる。通常ウィンドウでも設定で同じ挙動にできる。メニューで当該バー自体を無効にしている場合は常に非表示となる。

自動表示するバーがスクロールバーの操作を妨げる場合、CtrlまたはShiftを押している間は自動表示を抑制できる。大きいツールバーボタンとツールバー上部の横線の変更は、次回起動時に反映する。[バー設定](http://www.massigra.net/massigrahelp/currentver/d_prop_bar.htm)

## 3 画像を開く方法

| 入口 | 動作 |
| --- | --- |
| ファイルのドラッグ＆ドロップ | ウィンドウに落としたファイルを開く |
| ファイル → 開く | プレビュー付きのファイル選択ダイアログ |
| 拡張子の関連付け | エクスプローラでのダブルクリックから起動 |
| コマンドライン | ファイルパスを受け付ける。書庫内パスを含む指定にも対応 |
| 最近開いたフォルダ | 選択したフォルダで最後に表示したファイルを開く |
| 前回ファイルの復元 | 設定で前回終了時のファイルを起動時に開く |
| 再読み込み | 現在、または直前に表示していたファイルを読み直す |
| クリップボード | 画像を新規画像として開ける |

ファイルを開くダイアログはWindowsのコモンダイアログを拡張したもの。選択中画像の縮小プレビュー、幅・高さ・BPP、ファイルサイズ、更新日時を表示でき、プレビューの有効・無効と縮小画質を選べる。

対応拡張子がプラグインによって多くなりすぎると、「対応している全てのファイル」では一覧が表示されない場合があり、「全てのファイル」への切り替えが回避策となる。プラグイン経由のプレビュー情報は正確でない場合がある。[開くダイアログ](http://www.massigra.net/massigrahelp/currentver/d_open.htm)、[ファイルメニュー](http://www.massigra.net/massigrahelp/currentver/m_file.htm)

## 4 標準のマウス操作

以下は基本操作として明記された割り当て。マウス設定で変更できるため、固定仕様とは分けて考える。

| 操作 | 標準の機能 |
| --- | --- |
| 左ドラッグ | 画像をスクロール |
| ホイール回転 | フォルダ内の前後のファイルへ移動 |
| 左ボタンを押しながらホイール | 縦スクロール |
| 右ボタンを押しながらホイール | 横スクロール |
| 中ボタンのクリック | MassiGraを終了 |
| X1を押しながら左右ドラッグ | ドラッグズーム |
| X2クリック | 原寸表示とウィンドウへのフィットを切り替え |
| 左ダブルクリック | 全画面表示を開始、または解除 |
| 右クリック | ポップアップメニュー |
| Ctrlと左ドラッグ | キャプションがないときのウィンドウ移動 |

マウスメーカーのドライバ設定によってはX1、X2が認識されない、あるいは前後移動として扱われる場合がある。ウィンドウ枠上でのX1、X2は、カスタマイズにかかわらず前後のファイル移動として機能する。[基本的な使い方](http://www.massigra.net/massigrahelp/currentver/basic.htm)、[マウスカスタマイズ](http://www.massigra.net/massigrahelp/currentver/d_mous_cs.htm)

## 5 キーボード操作

| キー | 公式ヘルプに明記された機能 |
| --- | --- |
| → / ← | 次 / 前のファイル。右から左の漫画モードでは逆になる |

| Shift + Delete | ごみ箱を使わず直接削除 |
| A | 自動スライドの開始ダイアログ。実行中なら停止 |
| Shift + A | ダイアログなしで自動スライドを開始・停止 |
| Ctrl + M | フォルダ内のランダムなファイルへ移動 |
| アプリケーションキー / Shift + F10 | ポップアップメニュー |
| Shift + 矢印キー | 画像を少しずつスクロール |
| PageUp / PageDown | 表示領域の半分の量だけ縦スクロール |
| Shift + PageUp / PageDown | 表示領域の半分の量だけ横スクロール |
| Home / End | 縦方向の先頭・末尾へスクロール |
| Shift + Home / End | 横方向の先頭・末尾へスクロール |
| NumLock中のテンキー数字 | 数字の位置に対応する画像部分へ移動。9は右上、1は左下など |

キーは変更可能で、1機能につき最大8個まで登録できる。先頭のキーをメニューに表示する。この表は公式の文章に記載された標準操作の整理であり、実行ファイルの全初期割り当てを採取した一覧ではない。[キーボード操作](http://www.massigra.net/massigrahelp/currentver/keyboard.htm)、[キー割り当て](http://www.massigra.net/massigrahelp/currentver/d_keyset.htm)

## 6 表示サイズとスクロール

### 6.1 ズームとフィットの区別

| 操作 | 意味 |
| --- | --- |
| 元のサイズで表示 | 画像本来のピクセルサイズで表示 |
| ズーム イン / アウト | 表示倍率を段階的に変更 |
| ズーム ダイアログ | 任意の表示倍率を数値で指定 |
| ズーム 固定 | 次の画像に進んでも同じズーム倍率を維持 |
| ウィンドウに合わせる | 現在の表示領域とフィット条件から倍率を決める |
| 画像 → 拡大縮小 | 画像データ自体のピクセルサイズを変更する加工 |

ズームとフィットは異なる表示系統で、画質設定も別。どちらも画像加工としてのリサイズとは異なる。ズームの数値指定は最大5000%、小数点以下5桁まで。ウィンドウへのフィットも最大5000%で、設定で拡大上限を変更できる。

アニメーション中や表示サイズが極端に大きい場合、フィットの画質はズーム側と同等になる。選択モード中のズームも低画質になる。[表示メニュー](http://www.massigra.net/massigrahelp/currentver/m_view.htm)、[ズームダイアログ](http://www.massigra.net/massigrahelp/currentver/d_zoom.htm)

### 6.2 読み込み時の表示オプション

| オプション | 読み込み直後の動作 |
| --- | --- |
| ウィンドウを画像に合わせる | 画像サイズに応じてウィンドウを調整 |
| 画像をウィンドウに合わせる | 表示領域に合わせて画像を拡大・縮小 |
| 大きい画像だけウィンドウに合わせる | 収まらない画像だけ縮小 |
| 画像をデスクトップに合わせる | ウィンドウをデスクトップに合わせ、その領域に画像を拡大・縮小 |
| 大きい画像だけデスクトップに合わせる | 収まる画像はウィンドウを画像に合わせ、収まらなければデスクトップに合わせる |
| そのままのサイズで表示 | 画像とウィンドウのサイズを自動調整しない |

通常表示と全画面表示で選択を別々に持つ。自動サイズ調整でツールバーより小さくするか、ウィンドウを中央基準で移動するかも設定できる。基本操作の説明では、標準は画像をウィンドウに合わせた縮小表示となっている。[表示オプション](http://www.massigra.net/massigrahelp/currentver/m_v_disp.htm)、[基本的な使い方](http://www.massigra.net/massigrahelp/currentver/basic.htm)

### 6.3 フィットオプション

選択肢は「ウィンドウ内に収める」「ウィンドウの幅に合わせる」「ウィンドウの高さに合わせる」「幅 高さ どちらかに合わせる」の4種類。通常表示と全画面表示は別設定で、読み込み時の表示オプションにも影響する。

スクロールバーが現れると表示領域が変わり、バーの必要性が再び変化するため、幅や高さに厳密に一致しない場合がある。「幅 高さ どちらか」の具体的な倍率計算式はヘルプに記載されていない。[全メニュー](http://www.massigra.net/massigrahelp/currentver/menulist.htm)、[フィットオプション](http://www.massigra.net/massigrahelp/currentver/m_v_fit.htm)

### 6.4 表示用の自動回転

回転なし、左90度、右90度、縦長画像だけ左・右、横長画像だけ左・右、180度の8種類。読み込み時の表示方向を変える機能で、元ファイルを書き換えない。

JPEGのExif方向情報による回転は、このメニューとは別の読み込み設定である。漫画モードでは、表示回転を画像連結の前に行うか後に行うかも選べる。[回転オプション](http://www.massigra.net/massigrahelp/currentver/m_v_rotate.htm)、[全メニュー](http://www.massigra.net/massigrahelp/currentver/menulist.htm)、[表示設定](http://www.massigra.net/massigrahelp/currentver/d_prop_view.htm)

### 6.5 スクロールの方式

スクロールバー、左ドラッグ、ボタンを押しながらのホイール、キーボード、テンキーの位置指定、ホバースクロールに対応する。

ホバースクロールは、ボタンを押さずにカーソルを動かすと、ウィンドウ内のカーソル位置に対応する画像部分を表示する方式。判定領域の余白と最小移動量を設定でき、選択モード中は無効となる。[表示メニュー](http://www.massigra.net/massigrahelp/currentver/m_view.htm#hoverscroll)、[マウスオプション](http://www.massigra.net/massigrahelp/currentver/d_mous_op.htm)

## 7 全画面表示

左ダブルクリック、または表示メニューで切り替える。設定によりタスクバーを隠すか、タスクバーを残す範囲で最大化するかを選べる。

| 通常表示と別々に管理することが明記された項目 | 内容 |
| --- | --- |
| 表示オプション | 読み込み直後のサイズ調整方法 |
| フィットオプション | 収め方、幅合わせ、高さ合わせなど |
| 常に手前に表示 | 最前面状態 |
| 各種バー表示 | ツールバー、ステータスバー、スクロールバーなど |
| フィット時の縮小・拡大方法 | 通常表示用と全画面表示用を独立に設定 |

カーソルを隠す設定と処理待ちカーソルも隠す設定がある。通常カーソルを隠す場合でも、ボタンを押している間は表示する。ファイル名を画面内に重ねて表示でき、位置、背景、文字色、背景色、フォントを設定できる。

ファイル名はスクロールやドラッグズームの最中には表示しない。アニメーション中も重ねるかを選べるが、表示が滑らかでなくなる場合がある。

全画面表示中は選択モードにできず、選択範囲も解除される。選択モード中は左ダブルクリックによる全画面切り替えが無効となる。[表示メニュー](http://www.massigra.net/massigrahelp/currentver/m_view.htm#full)、[全画面表示設定](http://www.massigra.net/massigrahelp/currentver/d_prop_full.htm)、[編集メニュー](http://www.massigra.net/massigrahelp/currentver/m_edit.htm#selmode)

## 8 ファイルリストとフォルダの移動

### 8.1 ファイル単位の移動

| 機能 | 動作 |
| --- | --- |
| 前 / 次のファイル | 対応拡張子のファイルを順に表示し、非対応拡張子は無視 |
| 前 / 次へスキップ | 標準では10個前後。スキップ数を変更可能 |
| 最初 / 最後のファイル | 現在フォルダの先頭・末尾へ移動 |
| ジャンプ | フォルダ内の順番を指定して移動 |
| ランダムジャンプ | 現在フォルダからランダムに1件を選択 |
| ファイルリストを更新 | 他アプリによる移動などを一覧に反映 |

通常はウィンドウがアクティブになる際にもリストを自動更新する。ランダム順のときは並び順を保持するため、この自動更新を行わない。末尾や先頭でさらに移動すると「次へ / 前へ」ダイアログが現れるが、設定で表示を省略したり、到達時に音を鳴らしたりできる。[リストメニュー](http://www.massigra.net/massigrahelp/currentver/m_list.htm)、[並び順](http://www.massigra.net/massigrahelp/currentver/m_l_sort.htm)

### 8.2 フォルダ単位の移動

| 機能 | 到着位置 | 対応画像のないフォルダ |
| --- | --- | --- |
| 次のフォルダ | 次のフォルダの先頭 | 無視する |
| 前のフォルダ | 前のフォルダの末尾。設定で先頭に変更可能 | 無視する |
| 次隣のフォルダ | 同じ階層の次のフォルダの先頭 | 無視しない |
| 前隣のフォルダ | 同じ階層の前のフォルダの末尾。先頭にも変更可能 | 無視しない |
| 親フォルダ | 親フォルダの末尾。先頭にも変更可能 | 無視しない |

「次のフォルダ」と「次隣のフォルダ」は異なるコマンドである。前者について、ヘルプは全条件を含むディレクトリ走査アルゴリズムまでは説明していないため、同階層移動と同一視しない。

これらのコマンドで訪れたフォルダは通常、逐次履歴に追加しない。設定で追加できる。ただし設定にかかわらず、新たにファイルを開く操作の直前のフォルダと、終了時のフォルダは履歴に追加する。[リストメニュー](http://www.massigra.net/massigrahelp/currentver/m_list.htm)、[移動設定](http://www.massigra.net/massigrahelp/currentver/d_prop_move.htm)

### 8.3 並び順

名前、更新日時、ファイルサイズ、拡張子、ランダムの5系統に、逆順と名前の数値順比較を組み合わせる。数値順では例として`1.jpg、2.jpg、3.jpg、10.jpg`の順になり、文字列順では`1.jpg、10.jpg、2.jpg、3.jpg`となる。

Windows XP以降では数値順が標準で有効。ただしエクスプローラと完全に同じ結果になる保証はない。ランダム順では、プラグイン設定を開いて閉じる操作によって並べ直される点も明記されている。[並び順](http://www.massigra.net/massigrahelp/currentver/m_l_sort.htm)

### 8.4 ジャンプダイアログ

ファイル名、フォルダ内の順番、総数、プレビュー、縮小画質を扱う。順番を数値または連動するスクロールバーで選べる。対応ファイルがないフォルダでは利用できない。

右から左の漫画モードでは、スクロールバーの先頭と末尾が逆になる。これは設定で解除可能。書庫内では内部パスを含む名前を表示し、長い名前は末尾側が見える。[ジャンプ](http://www.massigra.net/massigrahelp/currentver/d_jump.htm)

### 8.5 最近開いたフォルダ

最大20件。選ぶと、そのフォルダで最後に開いたファイルを表示する。終了時に履歴を保存し、次回に引き継ぐかを設定できる。長いパスは途中を省略して表示する。ブックマークとは別の機能である。[最近開いたフォルダ](http://www.massigra.net/massigrahelp/currentver/m_f_mrud.htm)

## 9 自動スライド

一定時間ごとに次の画像へ進む機能。実行中に同じコマンドを呼ぶとダイアログを出さずに停止する。自動スライド中は画像読み込み時の処理待ちカーソルを表示しない。

| 設定 | 動作 |
| --- | --- |
| 全画面表示 | 開始時に全画面へ移り、停止時に元の状態へ戻す |
| ランダムな並び順 | 開始時にランダム順へ変え、停止時に元の順序へ戻す |
| ループする | 終端で繰り返す。無効なら最後のファイルで停止 |
| 次のフォルダも表示 | 現在フォルダの後も閲覧を続ける |
| 開始フォルダと下位フォルダだけ表示 | 開始位置以下に範囲を限定してループまたは停止 |
| 時間 | 秒単位の送り間隔 |

開始フォルダ以下への限定を外した場合、親フォルダなども進み、ドライブ内の最後のファイルで停止する。ランダム順のループでは、周回時にリストをシャッフルし直す。

指定時間は画像の読み込み時間を補正しないため、正確な一定周期を保証しない。開始・停止はA、ダイアログを出さない切り替えはShift + A、起動直後の開始は`/slide`で行える。[自動スライド](http://www.massigra.net/massigrahelp/currentver/d_autonext.htm)、[リストメニュー](http://www.massigra.net/massigrahelp/currentver/m_list.htm#auto)

## 10 漫画モード

現在の画像と次の画像を連結し、1枚の画像を作って表示する見開き機能。2枚をそれぞれ独立に描画する方式ではない。作者は汎用ビューアへの補助的な機能として位置付けている。

| 機能 | 詳細 |
| --- | --- |
| 読み方向 | 右から左、左から右 |
| 単ページ調整 | 「1つだけ戻る / 進む」で組み合わせを1画像分ずらす |
| 横長画像 | 横長は見開きにせず単ページにする設定 |
| 高さが異なる2枚 | 指定色で差分を埋める、小さい方へ合わせる、大きい方へ合わせる設定 |
| 高さを合わせる画質 | 縮小用、拡大用のアルゴリズムを指定 |
| 表示用回転 | 連結前に回転するか、連結後に回転するかを指定 |
| ナビゲーション | 右から左では左右キーとツールバーの前後移動が反転 |
| ジャンプ | 右から左ではスクロールバーの方向も反転可能 |

ツールバー反転は、機能だけが反転しボタン画像は変わらない。キーの反転を避けたい場合は、方向反転付きの機能ではなく通常の前後移動を割り当てる。ツールバーとジャンプの反転は設定で解除できる。

連結結果が極端に大きい場合は連結できない。表紙の扱い、ページ数が奇数の場合、アニメGIFと見開きの組み合わせなどの全条件は実機確認項目とする。[表示メニュー](http://www.massigra.net/massigrahelp/currentver/m_view.htm#comicmode)、[漫画オプション](http://www.massigra.net/massigrahelp/currentver/m_v_cmcopt.htm)、[表示設定](http://www.massigra.net/massigrahelp/currentver/d_prop_view.htm)、[FAQ](http://www.massigra.net/massigrahelp/currentver/faq.htm#q0019)

## 11 アニメGIFと透明画像

### 11.1 アニメGIF

標準ローダでアニメーション表示できる。読み込み設定で再生を無効にすると最初のフレームだけを表示する。アニメーション中は、通常の透過GIF表示設定にかかわらず透明情報を使用する。

速度制限設定は、ブラウザに似せた表示を選ぶもので、遅延時間の扱いに加えて、ループ回数の解釈と背景処理が異常な場合の扱いにも影響する。更新履歴では0.43で「Chrome風」が追加され、旧Safari用の選択肢が削除された。

アニメGIFは24 BPPとして表示され、使用色数の集計はできない。フィット中の画質もズーム側と同じになる。GIF対応プラグインを標準ローダより優先すると、アニメーション表示ができなくなる。アニメGIFの保存はできない。[読み込み設定](http://www.massigra.net/massigrahelp/currentver/d_prop_fload.htm)、[表示設定](http://www.massigra.net/massigrahelp/currentver/d_prop_view.htm)、[GIF保存](http://www.massigra.net/massigrahelp/currentver/d_save_gif.htm)、[プラグイン設定](http://www.massigra.net/massigrahelp/currentver/d_plugset.htm)

### 11.2 透明画像の読み込み

| 形式 | 透明表示の条件と設定 |
| --- | --- |
| BMP | BITMAPV4HEADER / BITMAPV5HEADERで、アルファマスクが有効なビットフィールドBMP |
| GIF | 透過表示の有効・無効と、ファイル内の背景色を利用するかを設定 |
| PNG | 透過表示の有効・無効と、ファイル内の背景色を利用するかを設定 |
| PNGの例外 | 透明色情報付きでビット深度が16のPNGは透過表示不可 |

透過表示の背景色も設定できる。透明情報は読み込み時に背景色へ合成されるため、読み込んだ画像を保存すると合成後の画像になる。元のアルファをそのまま保持する編集モデルとは扱いが異なる。

また、画像表示ウィンドウの背景パターンと、透過画像を読み込むときの合成背景色は、設定項目として区別されている。[読み込み設定](http://www.massigra.net/massigrahelp/currentver/d_prop_fload.htm)、[仕様と制限](http://www.massigra.net/massigrahelp/currentver/specifi.htm)

## 12 ファイル操作と振り分け

### 12.1 名前の変更

新しい名前と拡張子を分けて入力し、「新しい名前.拡張子」の形で変更する。拡張子だけ変えても画像形式は変換されない。変更後に表示順を整理するかを設定できる。書庫内では使用不可。[名前変更](http://www.massigra.net/massigrahelp/currentver/d_rename.htm)

### 12.2 移動とコピー

基本ダイアログは送り先フォルダ、フォルダ参照、同名ファイルへの上書き確認を備える。フォルダのドラッグ＆ドロップ入力も可能。相対パスの基準は現在の画像ファイルがあるフォルダ。

「10個登録」に切り替えると、10個の送り先と対応する実行ボタンを扱える。ボタンは送り先を選択するだけでなく、その場所への移動・コピーを実行する。入力欄のフォーカスはホイールで変更できる。

登録先へダイアログなしで移動・コピーする機能を、キーやマウスへ割り当てられる。移動用とコピー用の登録先は別々に管理する。送り先未登録の場合はダイアログを表示し、10個登録モードが固定される。上書き確認設定は直接実行にも適用される。

移動は書庫内では不可。コピーはファイルメニューにその制限が付されていないが、内部画像の出力先や属性などの細部は実機確認が必要。[基本ダイアログ](http://www.massigra.net/massigrahelp/currentver/d_cpymov.htm)、[10個登録](http://www.massigra.net/massigrahelp/currentver/d_cpymovex.htm)、[割り当て可能な機能](http://www.massigra.net/massigrahelp/currentver/custom.htm)

### 12.3 削除

通常はごみ箱へ送り、Shift + Deleteは直接削除する。設定により確認の有無、ごみ箱の利用、削除や移動後に次の画像を表示するかを変更できる。

実際のごみ箱利用と確認メッセージはWindows側のごみ箱設定にも左右される。MassiGra側で確認やごみ箱を有効にしても、OS設定によっては確認なしの削除、または直接削除になる。書庫内では削除不可。[ファイルメニュー](http://www.massigra.net/massigrahelp/currentver/m_file.htm#delete)、[ファイル操作設定](http://www.massigra.net/massigrahelp/currentver/d_prop_fope.htm)

### 12.4 名前やパスをコピー

現在のファイル名、ファイルのフルパス、フォルダ名、フォルダのパス、DOS形式のショートパスをクリップボードにコピーできる。ショートパスは環境によって利用不可。[パスのコピー](http://www.massigra.net/massigrahelp/currentver/m_e_clip.htm)

## 13 保存と形式変換

### 13.1 共通の保存動作

| 項目 | 仕様 |
| --- | --- |
| 上書き保存 | 保存設定ダイアログを表示するか、事前確認するかを設定可能 |
| プラグインで読んだファイル | 上書き保存不可。「名前を付けて保存」へ切り替える |
| 名前を付けて保存 | 前回使用した保存形式を選択。前回フォルダを保持する設定あり |
| 同名ファイル | 「名前を付けて保存」では上書き確認を行う |
| 拡張子 | 未入力なら自動付加。自動付加時に大文字を使う設定あり |
| 日時 | 元ファイルの日時で保存する設定あり |
| メタデータ | コメント、Exifなどを引き継がない |
| 透明情報 | 読み込み時の背景合成が反映される。保存設定での透過色指定とは別 |

「元ファイルの日時で保存」と「Exifを保持」は異なる。前者が有効でも撮影情報の継承を意味しない。[保存ダイアログ](http://www.massigra.net/massigrahelp/currentver/d_save.htm)、[ファイル操作設定](http://www.massigra.net/massigrahelp/currentver/d_prop_fope.htm)、[仕様と制限](http://www.massigra.net/massigrahelp/currentver/specifi.htm)

### 13.2 形式別の設定

| 形式 | 設定 | 制限と変換 |
| --- | --- | --- |
| BMP | トップダウン、4 / 8 BPPのRLE圧縮 | RLE時はトップダウン不可。RLEで大きくなるなら通常BMPへ戻す。拡張子はBMP |
| JPEG | プログレッシブ、品質 | サブサンプリングは4:4:4。保存時は24 BPP。品質100も不可逆。ヘルプの推奨値は90〜95 |
| GIF | インターレース、非圧縮、透過色、透過色番号 | 8 BPP以下。16 BPP以上は自動減色。アニメGIFは保存不可 |
| PNG | インターレース、圧縮レベル、圧縮フィルタ、透過色 | 圧縮フィルタは画質加工ではなく圧縮効率用。パレット画像では「なし」の方が効率的な場合あり |

16 BPPはMassiGraではBMP形式でのみ保存できる。JPEG再保存を無劣化変換やロスレス回転とみなさない。PNGは符号化自体が可逆でも、読み込み時に背景合成済みなら元の透明データには戻らない。[BMP保存](http://www.massigra.net/massigrahelp/currentver/d_save_bmp.htm)、[JPEG保存](http://www.massigra.net/massigrahelp/currentver/d_save_jpeg.htm)、[GIF保存](http://www.massigra.net/massigrahelp/currentver/d_save_gif.htm)、[PNG保存](http://www.massigra.net/massigrahelp/currentver/d_save_png.htm)、[減色と増色](http://www.massigra.net/massigrahelp/currentver/d_coldepth.htm)

## 14 画像情報

「画像の情報」には次の項目がある。

| 分類 | 項目 |
| --- | --- |
| ファイル | 名前、所在フォルダ、フルパス、形式、更新日時 |
| 画像 | 読み込み当初の幅・高さ・BPP・色タイプ、加工後の幅・高さ・BPP・色タイプ |
| 印刷 | 水平・垂直DPI、そこから算出した印刷サイズ |
| 色 | 使用色数、自動計算の有効・無効 |
| 容量 | ディスク上のファイルサイズ、メモリ上のデータサイズ |
| リスト | フォルダ内の順番、対応ファイル総数 |
| 性能 | 読み込みにかかった時間をミリ秒で表示 |

解像度未指定の場合の印刷サイズは72 DPIで計算する。片方だけ0の場合はもう一方のDPIを用いる。アニメーション表示中は使用色数を表示・計算しない。

読み込み当初のサイズは、ファイル内での元の格納状態と同じとは限らない。プラグインが複数形式を扱う場合などは、ファイル形式欄が空になることもある。Exif項目を一覧表示する機能はなく、ヘルプでは外部アプリの登録を案内している。[画像情報](http://www.massigra.net/massigrahelp/currentver/d_imginfo.htm)、[FAQ](http://www.massigra.net/massigrahelp/currentver/faq.htm#q0020)

## 15 Susie Plug-inと書庫

### 15.1 追加機能の仕組み

画像読み込み用と書庫読み込み用のプラグインを利用できる。プラグインフォルダを指定し、一覧から使用するものをチェックする。標準ローダとプラグインのどちらを優先するかを選べる。

プラグインの更新や設定変更後は、プラグイン設定を開いてOKを押すことで状態を再認識する。相対パスはMassiGra本体フォルダが基準で、空欄は無効、`.`は本体と同じフォルダを意味する。詳細と既知の相性は[設定のプラグイン節](massigra-settings.md#15-プラグイン設定)に整理した。[プラグイン設定](http://www.massigra.net/massigrahelp/currentver/d_plugset.htm)

### 15.2 書庫閲覧の仕様

| 項目 | 仕様と制限 |
| --- | --- |
| 対応形式 | 導入プラグインによる。本体が書庫を標準解凍する仕様ではない |
| 書庫内書庫 | 開けない |
| 内部フォルダ | 書庫全体を1つのフォルダのように扱う |
| 並び順 | 原則として内部の各フォルダ単位で整列。プラグインによる例外あり |
| 日時順とサイズ順 | プラグインが日時やサイズを0で返すと、名前順になる場合あり |
| ファイル名 | 外国の文字で文字化けや読み込み不可が起きる場合あり |
| キャプション | 内部パスを含む名前を表示 |
| 種別の判定 | 書庫かどうかは拡張子で判断 |
| 画像との競合 | 同じ拡張子が書庫と画像の両方に登録されている場合、画像として扱う |
| 名前変更・移動・削除 | 書庫内では利用不可 |

書庫を編集して内部ファイルを削除・改名する機能と、書庫から画像を読み出して閲覧する機能を混同しない。[仕様と制限](http://www.massigra.net/massigrahelp/currentver/specifi.htm#archive)、[ファイルメニュー](http://www.massigra.net/massigrahelp/currentver/m_file.htm)

## 16 他のアプリと複数ウィンドウ

### 16.1 別ウィンドウの起動

「もう1つ起動」には、空のウィンドウ、現在のファイルを開く、現在画像をクリップボード経由で送る、クリップボード画像を貼り付ける、の4種類がある。多重起動を禁止していても`/newwnd`による明示起動は可能。

比較表示は別プロセスを並べる使い方として案内される。同一ウィンドウ内の連動比較、ズーム同期、タブの仕様は確認できない。[もう1つ起動](http://www.massigra.net/massigrahelp/currentver/m_f_newwnd.htm)、[起動オプション](http://www.massigra.net/massigrahelp/currentver/cmndline.htm)

### 16.2 外部アプリの登録

最大9枠。標準では8番が現在ファイル、9番が現在フォルダをシステムの関連付けで開く。表示名、実行ファイル、引数、送る対象、起動ウィンドウ状態、起動後にMassiGraを終了するかなどを指定できる。

引数に含めるパスは`($f)`がファイル、`($d)`がフォルダへの置換記号。空白を含むパスを渡す場合は引用符が必要。書庫内では内部パスを含めるか、書庫そのものや書庫の親フォルダを送るかも設定できる。全設定項目は[外部アプリ設定](massigra-settings.md#16-他のアプリの設定)を参照。[他のアプリ](http://www.massigra.net/massigrahelp/currentver/m_f_app.htm)、[他のアプリの設定](http://www.massigra.net/massigrahelp/currentver/d_otherapp.htm)

### 16.3 多重起動の制御

多重起動を無効にしている場合、再起動時にファイルが指定されていれば既存ウィンドウでそのファイルを開く。既存ウィンドウをアクティブにするかは別設定。ドロップ時にアクティブにするかも選べる。[全般設定](http://www.massigra.net/massigrahelp/currentver/d_prop_gene.htm)

## 17 起動オプション

| 引数 | 効果 | 優先関係 |
| --- | --- | --- |
| ファイルパス | 起動時にファイルを表示 | 通常は前回ファイル復元より優先 |
| `/slide` | 起動後に自動スライド開始 | スライドの設定に従う |
| `/getclip` | クリップボード画像を新規画像へ貼り付け | 同時指定のファイル名を無視 |
| `/blank` | ファイルを開かずに起動 | ファイル名、前回ファイル復元、`/getclip`を無効化 |
| `/newwnd` | 明示的に新たなMassiGraを起動 | 多重起動禁止を上書き |
| `/user=名前` | 指定ユーザー名の設定フォルダを利用 | `SingleU.cfg`より優先 |
| `/user=` | 全ユーザー共用設定と同様の扱い | ユーザー名を空にする指定 |

空白を含む設定名は`/user="user name"`のように記述する。起動オプションは他ソフトの引数と互換ではない。ファイルパスには書庫内パスを含めることもできるが、対応する具体的なパス文法の全容はヘルプに記載されていない。[起動オプション](http://www.massigra.net/massigrahelp/currentver/cmndline.htm)

## 18 印刷と壁紙

### 18.1 印刷

プリンタ、用紙と方向、部数、上下左右の余白、画像の配置、画像サイズ、縦横比、長さの単位、色の濃さ、用紙に合わせた回転を指定できる。プレビューは印刷レイアウトの確認用で、実際の印刷画質とは異なる。[印刷ダイアログ](http://www.massigra.net/massigrahelp/currentver/d_print.htm)

| 項目 | 詳細 |
| --- | --- |
| 余白 | プリンタが許容する最小値より小さくならない |
| DPIによるサイズ | 画像にDPIがなければ72 DPIとして扱う |
| 指定サイズ | 幅・高さを直接指定。最大100000 cm、39370.08インチ |
| 印刷領域超過 | はみ出した部分は切り取られる |
| 配置 | マウスで指定。ヘルプではキーボード指定不可とされる |
| 色の濃さ | 真っ黒や原色は変わらない。プリンタとの調整用 |
| プリンタ設定 | ダイアログ内の設定は次回起動で元に戻る。常用設定はOS側で設定 |

### 18.2 壁紙

中央、タイル、伸縮、横幅合わせ、縦幅合わせを選べる。横幅と縦幅への合わせはWindows 7以降。

実行時にApplication Data側のMassiGraフォルダへ`MassiGraWall.bmp`を作成する。「壁紙ファイルを削除」はこの生成ファイルを消す操作で、元画像の削除ではない。[壁紙メニュー](http://www.massigra.net/massigrahelp/currentver/m_o_wall.htm)

## 19 インストールと設定の保存

### 19.1 配置と更新

アーカイブを専用フォルダに展開し、`MassiGra.exe`を起動する。ショートカットは必要に応じて手動作成。更新は配布ファイルをすべて上書きする方式。

Program Files、Windows、ProgramData配下への配置は、書き込み権限などにより正常動作しない場合があるとヘルプに記載される。関連付けを行わない通常利用では、設定のためにレジストリを書き換えない。壁紙の変更は別途OSの設定を変更する。[インストール](http://www.massigra.net/massigrahelp/currentver/install.htm)

### 19.2 配布ファイル

| 場所 | ファイルと用途 |
| --- | --- |
| 本体フォルダ | `MassiGra.exe`、`Readme.txt` |
| `data` | `imgctl.dll`、`imgctl98.dll`、Meko用乱数表`mekorand.dat` |
| `data` | 大きいツールバーボタン画像`tb_24_n.bmp`、`tb_32_n.bmp`、`tb32_24_n.bmp`、`tb32_32_n.bmp` |
| `win98` | `MassiGra98.exe` |

Windows 98 / MEでは`MassiGra98.exe`を本体と同じフォルダへ移して利用する。これはUnicodeに対応しない版で、それ以外の機能は同じとされる。通常版は`user`、98版は`user98`へ設定を保存する。[構成ファイル](http://www.massigra.net/massigrahelp/currentver/install.htm#kousei)

### 19.3 ユーザー別と共用の設定

通常は本体フォルダに`user`を作り、その中のユーザー名フォルダへ保存する。31文字を超えるユーザー名はハッシュ値を付けた省略名となり、名前が衝突する可能性がある。

Program Files内の場合はユーザー別AppDataのMassiGraフォルダへ保存先が変わる。この場合は複数ユーザー間での共有ができない。

`user`直下に`SingleU.cfg`を置くと、ユーザー名サブフォルダを分けずに共用する。ファイル内容は任意で、0 byteでもよい。USBメモリ等で同じ設定を使う方法として案内される。プラグインフォルダも相対パスにできるが、プラグイン自身の設定はレジストリ等に保存される場合がある。

起動時の`/user=`によって設定を使い分けられる。実際の保存先はバージョン情報で確認・開くことができる。設定保存のため、OSのシャットダウンやログオフ前にアプリを通常終了することが案内されている。[設定の保存](http://www.massigra.net/massigrahelp/currentver/install.htm)、[FAQ](http://www.massigra.net/massigrahelp/currentver/faq.htm#q0031)、[バージョン情報](http://www.massigra.net/massigrahelp/currentver/d_version.htm)

### 19.4 アンインストールと関連付け

壁紙生成ファイルが不要なら削除し、アプリで行った関連付けを解除し、実行中なら終了してから本体フォルダを削除する。AppDataに設定がある場合は別途残る。ショートカットも手動で削除する。

関連付けダイアログは管理者権限を必要とし、Vista以降は管理者としての実行が案内されている。解除時は従前の関連付けへ戻すが、XP以降のユーザー個別関連付けは復元しない。これらは当該版のOS連携仕様で、現行Windowsでの設定方法の案内とは区別する。[関連付け](http://www.massigra.net/massigrahelp/currentver/d_assoc.htm)、[アンインストール](http://www.massigra.net/massigrahelp/currentver/install.htm)

## 20 形式と容量の制限

| 分類 | 公式ヘルプに明記された制限 |
| --- | --- |
| パス長 | 260文字を超えるパスは非対応 |
| 文字 | プラグイン経由では外国の文字を含むファイル名や配置パスで問題が出る場合あり |
| Macバイナリ | 付加されたファイルは読み込み不可 |
| グレースケールJPEG | 8 BPPのファイルも24 BPPとして読み込む |
| JPEGの色空間 | CMYK、YCCKを正しい色合いで表示できない |
| PNGガンマ | ガンマ情報を使って読み込み時に補正するため、他ソフトと色が違う場合あり |
| PNG透明 | 透明色情報付き、ビット深度16の画像は透過表示不可 |
| 透明画像の編集 | 読み込み時に背景と合成する |
| メタデータ | 保存時にコメント、Exifなどを引き継がない |
| メモリ | 物理メモリ超過を許可しても、メモリ上で1 GBを超える画像は作成不可 |
| 新規作成とサイズ入力 | 幅・高さそれぞれ最大65535。ただしこの寸法まで必ず作れるという意味ではない |
| 保存先 | OSルートやProgram Files等の保護領域に保存・移動・コピーできない場合あり |
| 入力状態 | 環境によってボタン押下状態を誤認する場合あり |

BPP、行境界への詰め方、作業用メモリなどによって必要メモリは変わる。65535という寸法上限と、1 GBという画像データ側の制限は別々に満たす必要がある。[仕様と制限](http://www.massigra.net/massigrahelp/currentver/specifi.htm)、[新規作成](http://www.massigra.net/massigrahelp/currentver/d_newimg.htm)、[拡大縮小](http://www.massigra.net/massigrahelp/currentver/d_resize.htm)

## 22 実装の参考になる技術情報

公式の謝辞では、開発にVisual C++ 6.0 Pro SP6、Visual C++ 2005 Express SP1、Windows Server 2003 R2用Platform SDKを使用し、MFCと.NET Frameworkは使っていないと記載する。

画像処理には改変したimgctl.dllのソース、JPEGにはIJG系のx86 SIMD拡張1.02、PNGにはlibpng 1.2.50とzlib 1.2.3を使用する。その他にmasksrc、vectorもどき1.15等が挙げられている。参考にしたソフトはIrfanView、GMask、BTJ32、D-Pixed、TabFolder。

これはMassiGra当時の構成であり、新ビューアの技術選定を指定するものではない。独自エンジンのソース一式や、各補間アルゴリズムの厳密な実装式は、ヘルプだけでは得られない。[謝辞と参考資料](http://www.massigra.net/massigrahelp/currentver/thanks.htm)

## 25 実機で確認する必要がある細部

公式ヘルプは機能範囲を十分に確認できる一方、同じ操作感を再現するには次の観察が必要になる。

| 論点 | 確認する内容 |
| --- | --- |
| 初期設定 | 全チェック状態、標準キー割り当て、背景色、倍率ステップ、スクロール量 |
| 非公開の選択肢 | 設定コンボボックスの全選択肢、数値欄の全上下限、入力単位 |
| フィット | 「幅 高さ どちらか」の倍率式、端数処理、スクロールバー発生時の収束 |
| ズーム | 倍率段階の全列、カーソル位置との関係、画像切り替え時のスクロール位置 |
| フォルダ走査 | 下位・親・隣接フォルダの順序、空フォルダ、アクセス不能、循環リンク等の扱い |
| 終端操作 | 「次へ / 前へ」のボタン構成と、表示省略時に選べる全動作 |
| 漫画 | 画像高さが違う場合の位置、横長判定、表紙、奇数枚、GIFとの組み合わせ |
| 編集状態 | 未保存の変更がある画像の切り替え、終了、再読み込み時の確認 |
| クリップボード | 対応するデータ形式、透過の扱い、貼り付けの拡縮・位置規則 |
| 書庫 | コピーの実体、パス表記、入れ子階層のソート、プラグインの異常系 |
| 表示品質 | 独自補間の係数、同名アルゴリズムとの差、ガンマと透明合成の厳密な順序 |
| レベル調整 | 出力黒点・白点と反転条件の説明を、実際の数値動作で照合 |
| 現行環境 | Windows 11、DPI倍率、複数モニタ、長いパス、IME、関連付けの実動作 |
| 性能 | コールド起動、初回読み込み、連続送り、巨大画像、書庫、GIF、メモリ消費 |
