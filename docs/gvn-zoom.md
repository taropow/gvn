## 変更方式

INIの`zoom_mode`の番号は既存設定との互換性のため変更しない。

| GVN値 | 画面の方式 | 動作 |
| --- | --- | --- |
| 0 | 現在の倍率に対する割合（旧GVN） | `zoom_step`％だけ現在倍率を乗除し、100％をまたぐときは一度100％へ止まる。既存の明示値を保持する追加方式。 |
| 1 | 指定％ずつ | 100％を基準とする目盛りで上下を別設定。参照の選択肢1に相当。 |
| 2 | 段階的に（標準倍率） | 下記33段階を使う。参照の選択肢0に相当。 |

新規・欠落キーの既定は2。保存済みの0/1/2とドラッグ中の画質指定を引き継ぎ、読み込みだけではINIを書き換えない。

標準段階（％）:

`1, 2, 5, 10, 15, 20, 25, 30, 40, 50, 60, 75, 100, 125, 150, 175, 200, 250, 300, 350, 400, 500, 600, 800, 1000, 1300, 1600, 2000, 2500, 3000, 3500, 4000, 5000`

参照方式1/2は、現在の％値を正数の四捨五入で整数にしてから、指定方向に厳密に隣り合う段階を選ぶ。方式1の目盛りは`100 + n × 指定ポイント`であり、任意の現在倍率に単純加算する方式ではない。100％未満・以上の選択と100％への停止判定は丸める前の値を使う。拡大で100％未満から越える場合、縮小で100％超から下回る場合は一度100％に止まる。

例えば未満3・以上17なら7％から拡大10％／縮小4％、125％から拡大134％／縮小117％となる。標準方式では150→175→200％。入力倍率が1％未満でも、参照方式のコマンド結果は1～5000％に制限するため、0.5％から標準拡大は2％、縮小は1％になる。数値入力・フィット・旧GVNの割合方式の下限0.001％は保持する。

## 入力・画質・初期化

参照のスピン範囲は100％未満1～100、以上1～5000ポイント。GVNの未満は保存済み値を受け継ぐため1～400の追加範囲を維持し、以上を1～5000へ拡張する。方式1の時だけ上下の入力を有効にし、方式0の時だけ旧GVNの増加率を有効にする。無効な項目の値を保持する。

ページ初期化は次の9項目だけを既定に戻し、他ページの適用前の値も保持する。

| 項目 | 既定 |
| --- | --- |
| 画像切替時に倍率維持 | OFF |
| 旧GVNの増加率 | 25％ |
| 変更方式 | 段階的に（2） |
| 100％未満の幅 | 10ポイント |
| 100％以上の幅 | 25ポイント |
| 縮小時に補間 | ON |
| 拡大時に補間 | ON |
| 最近傍へ切替える倍率 | 0（閾値無効） |
| ドラッグ中は最近傍 | OFF |

メニュー、アイコン、キー、ホイールは共通のステップ計算を使う。連続したドラッグズームはマウス側の速度設定を使い、上記の段階方式とは独立するが、100％をまたぐ移動では一度100％へ止まり、次の移動で先へ進む。0.77.2以降、割合方式も100％停止に統一する。高速ホイールの1メッセージに複数段階が含まれる場合も100％で残りを消費して止め、次のホイール操作で先へ進む。数値入力・フィットの意図した倍率はそのまま適用する。ズームは表示だけを変更し、画像のRGBA・編集状態・コピー内容を変えない。

474条件の実App試験では、ダイアログからテキストを取得する境界だけを代替し、`ZoomNumber`と`ZoomIn/Out`以下の本体を通す。これとは別に[通常プロセスの検証](verification/0.31.0-zoom-processes.json)で、実際の倍率入力ダイアログを開いて入力・読取・取消を行い、同じ474条件すべてを成功させた。設定画面の試験は実際のコントロールを使い、専用自動操縦ではキー・ホイール・アイコンも操作する。
