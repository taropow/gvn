# 選択範囲の単位

0.41.0へ配布反映済み。[確認記録](verification/0.41.0-selection-related.json)を参照。

「編集 → 選択範囲の単位」には、フリー・2×2・4×4・8×8・16×16・32×32・カスタムを置く。使用中の項目に印を付ける。各プリセットとカスタム画面はキー／マウスの機能割り当てにも登録できる。既存コマンドの数値IDは変更していない。

カスタム画面では次の4項目を、それぞれ1〜999ピクセルで指定する。

| 項目 | 作用 |
| --- | --- |
| 始点・水平 | 範囲左端の単位 |
| 始点・垂直 | 範囲上端の単位 |
| サイズ・水平 | 範囲の幅の単位 |
| サイズ・垂直 | 範囲の高さの単位 |

各欄の横に1・8・16のボタンと上下ボタンを置く。数値の範囲外・空欄ではOKを無効にする。キャンセルは現在の設定を変更しない。OKで保存する。プリセットに切り替えている間も、最後に確定したカスタムの4値を保持する。

設定変更では既存の選択、画素、Undo、変更済み状態、表示中のアニメのコマを変更しない。次の範囲選択から反映する。ドラッグ中は、開始時の単位を使い続ける。

## 選択の丸め方

マウスの始点と終点は、どちらも画像上の画素を表す。終点の画素も含める。左右・上下の小さい方を取り、始点の単位で左・上へ丸める。その位置から終点画素までを覆うように、幅・高さをサイズ単位の倍数へ広げる。画像外へ出る場合は、画像内に入る完全な単位の数まで制限する。

逆向きにドラッグしても、同じ2点なら同じ範囲になる。クリックだけなら、フリーでは1×1ピクセルを選択する。単位が収まらない幅または高さは選択なしになる。

96×80ピクセルの参照画像で、MassiGra0.45の数値ダイアログから取得した例を示す。以下のサイズは幅・高さで、右・下の座標を含む形式から変換している。

| 単位（始点X/Y、サイズX/Y） | マウスの2点 | 結果（左、上、幅、高さ） |
| --- | --- | --- |
| 1、1、1、1 | 13,11 → 30,27 | 13、11、18、17 |
| 8、8、8、8 | 13,11 → 30,27 | 8、8、24、24 |
| 8、4、6、5 | 13,11 → 30,27 | 8、8、24、20 |
| 8、4、6、5 | 30,27 → 13,11 | 8、8、24、20 |
| 8、4、6、5 | 13,11 → 14,12 | 8、8、12、5 |
| 8、4、6、5 | 90,74 → 110,100 | 88、72、6、5 |
| 1、1、1、1 | 13,11 → 13,11 | 13、11、1、1 |

サイズの単位が画像より大きい例と、右下で完全な単位が入らない例では、参照アプリの切り出しメニューが無効になることも確認した。選択なしの数値ダイアログは画像全体の初期値を表示するため、その値だけで全体が選択されていると判断しない。

## 旧設定との関係

旧版の`grid`は、従来どおり共通単位として読み込む。新しい4値がない場合は、旧値を4項目の初期値にする。設定画面「全般」の共通単位も残す。共通単位を変更して適用するとカスタムを解除し、全軸へ共通値を使う。他の設定だけを変更した場合はカスタムを保持する。全般ページの初期化では、共通単位とカスタムも初期化する。保存するまでは元の設定へ反映しない。

## 確認と残項目

専用の非表示デスクトップに置いた参照アプリ・合成画像だけで9例を読み取り、追加3例のメニュー状態を照合した。ユーザーのアプリやクリップボードは使わない。参照アプリのVCL描画はPrintWindowに対応しないため、参照側は原寸に固定した画像ペインの座標と実際の数値欄・メニューから確認した。参照画像の画面比較を行ったという意味ではない。

GVNは関連単体/UI5件、本体3経路、専用02/79の122操作・3画面が成功。4値、12個の1/8/16ボタン、上下ボタンの範囲、入力エラー、保存/取消、各プリセット、旧設定、全般ページとの関係を確認した。実際のマウスメッセージによる逆ドラッグと画像端の範囲を照合し、透明・半透明・隠れたRGBを含む選択画像のクリップボードコピー、切り出し、Undoの全RGBAを確認した。既存202件の本体ケース本文は維持し、旧数値入力の試験境界だけを新しい選択単位の画面へ接続した。

数値による範囲指定（F022）も[専用の6欄](gvn-selection-rectangle.md)と現在範囲の初期表示へ補完し、参照10+2例・関連5件・本体3件・専用85操作2画面を確認した。実装済みとして管理する。[別ウィンドウのDPI引継ぎ](gvn-new-window.md)も関連確認を完了した。設定の細部、実プリンタとクリスタへの受信確認は残り、全体GOALは未完了。
