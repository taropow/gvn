# アニメ表示と保存設定の照合

## 0.53.0: GIFの現在コマの色番号とコピーを保持

[実装仕様](gvn-animation-indices.md)、[確認記録](verification/0.53.0-gif-indices-related.json)。元GIFの不変データを共有し、コピー・保存・現在コマの加工で必要な時に色番号を取り出す。全コマの追加番号バッファを再生中に保持せず、保持元データは読み込み予算へ含める。重複番号・未使用色表・透明・破棄方式・回転を保持し、同じ元番号が異なる色を表す等の不整合は現在RGBAの出力へ戻す。

新規基盤8件、実App1件、独立したPNG/BMP/GIFの12出力が成功した。実AppでPNGコピー・保存・切り抜き・Undoと元アニメ不変を確認し、DPIなしのコピーで色番号を落としていたPNG経路も修正した。影響する既存94件は段階ごとの証拠を保持し、以前のApp223件の本文は変更していない。全体テスト・起動性能測定は繰り返していない。

設定167実装済み/4部分対応、全体GOAL未完了を維持する。通常/軽量0.53.0へ反映し、配布本体の主要10経路も通過した。実クリスタ受信と物理入力等の未確認は別に残る。以下は以前の記録。

本体は0.51.0のまま。今回の参照5条件と追加App1件は[確認記録](verification/0.52.0-animated-saving-related.json)を参照する。既存222件の本文、製品ソース・本体ハッシュ、ユーザー設定と配布ZIPは維持した。

| 状態 | MassiGra 0.45での実観測 | GVN 0.51.0 |
| --- | --- | --- |
| アニメ表示ON | 上書き保存・別名保存・コピーが無効 | 選択した現在コマをRGBA/Alphaでコピー・静止保存できる |
| アニメ表示OFF | 先頭コマを表示し、保存・コピーが有効 | 設定変更で先頭コマへ再読込し、プレイヤーを隠す |
| OFFの元番号 | 同じRGBの別番号と全256色表がコピー/PNG保存後も一致 | 追加Appで番号・色表・RGBAが一致した |
| 保存ダイアログON | 形式ごとの設定画面を開く | 実Appで確定/取消を確認し、取消ではファイルを作らない |
| 保存ダイアログOFF | 上書きで設定画面を開かない | 実Appで設定画面を呼ばずに自分のPNGを上書きできた |

S079は「上書き保存でもダイアログを開く」という設定で、4形式のオプションは以前の画面・ファイル検証で確認済み。ここへ合成アニメ全コマの元番号保持という別の追加事項を混ぜて部分対応にしていたため、設定項目の判定を訂正した。パレットの未実装処理を実装済みに変更したわけではない。

合成アニメ全コマの元パレット/番号保持は引き続き未実装として記録する。GIFはコマごとに異なる色表や重ね描画を持つため、現在RGBAから番号を逆算した結果を元番号とは扱わない。常時全コマ分の番号バッファを追加する実装も行っていない。必要な設計・実装・確認は、保存ダイアログの設定とは分けて続ける。

今回の独立生成素材は不透明の2コマGIFで、番号0/1は同じRGB、未使用色も含め256項目ある。透過Alphaや実クリスタ受信の新しい証拠ではない。これらは従来の確認範囲と未確認範囲を保つ。専用デスクトップ/クリップボードで実施し、ComputerUseやグローバル入力は使用していない。
