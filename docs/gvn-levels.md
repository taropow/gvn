# レベル調整

0.58.0。「画像 → レベル調整…」で開く。[確認記録](verification/0.58.0-levels-related.json)。

入力黒点・ガンマ・入力白点、出力の黒点・白点を数値欄とスピンで変更する。黒白点は0～255、入力黒点は白点より小さくする。ガンマは0.001～10.000、小数3桁。出力黒点＞白点にすると明暗を反転できる。参照版は10を超えるガンマ文字列も受け付けるが、実出力は10に飽和した。GVNは有効範囲を明示し、不正入力で説明を表示してOKを無効にする。

入力にヒストグラム、出力に黒白点を反映したグラデーションを表示する。RGB個別をONにするとRed/Green/Blueを選べる。一括用と3色用の計4組を画面内で独立して保持し、切り替えても値を失わない。画面を開き直すと数値は0/1.000/255/0/255、RGB個別はOFFに戻る。プレビューON/OFFだけをOK時にINIへ保存し、取消では保存しない。旧設定のプレビューはON。

自動設定は現在の選択範囲、または画像全体の非透明画素から黒点・白点を求める。一括はRGB全体の最小/最大、個別は各色の最小/最大を使う。対象のガンマは1、出力黒白点は0/255へ戻す。未選択モードの4組の値は維持する。空のヒストグラムや一定値の色は無効な黒点＝白点を作らず初期値にする。

プレビューはメイン画像へ表示し、30msの入力待ちで連続変更をまとめる。OFFならOKまで計算しない。変更のないOKは計算済み候補を使い、初期値のOKは画像/Undo履歴を保持する。取消、入力不正、確保失敗、表示画像の切り替えで候補を取り下げる。表示切り替えは80msの監視でも検知し、失効後のOKは確定しない。

変換表をRGBへ適用しAlphaはそのまま。全体処理で有効なインデックス画像は未使用色/重複色を含むパレットを変換し、番号を保持する。選択範囲のみなら外側を変えずパレット番号の由来を外す。編集中は元画像を変更せず、OKで1回の編集として確定してUndoできる。アニメは編集確認後の現在コマを処理し、ヒストグラム用のコマを一度用意してプレビューへ再利用する。取消・失敗時は元の再生位置/状態を戻す。元ファイルを自動上書きせず、設定保存失敗でも画像を置き換えない。

公式0.45の隔離した実8プロセスで数値/RGBモード/自動設定/設定保持/無変更OKのUndoを観測し、全て正常終了した。参照のヒストグラム領域は無効化された描画コントロールで、ドラッグ操作とは確認していない。画面を別プロセスでPrintWindowした結果は黒画像だったため、視覚的成功とは扱わない。GVNの画面は同一プロセス内の実コントロールを再帰WM_PRINTで記録し、ヒストグラム、出力グラデーション、スピン、RGB/Preview/Auto/OK/Cancelを確認した。

参照出力12画像は普通の調整/RGB別/出力反転で差0、最大ガンマの3条件で最大1。任意画像・全パラメータの画素完全一致は証明していない。参照の試料は不透明で、完全透明画素をヒストグラムから除くことやAlpha保持はユーザー指定を満たすGVNの仕様。

基盤/実UIは5固有件。最初の4件を再利用し、80msの表示解除を待つ条件を直した1件だけ追加実行した。以前の失敗ログと同じ非表示アサーションを残し、失効後OKの禁止も確認。App3件と通常EXE2プロセスでコピー/保存/Undo、選択、設定、アニメ、遅れて返る候補を確認した。旧App228本文は不変。旧1件の「初期値でも編集扱い」は参照の無変更OKと異なったため、画像ポインター/Undoポインター/未編集状態の保持を要求するアサーションへ更新し、他のコマンドの編集/Undo/画素検査を維持した。台帳231件は今回3件/日付付き履歴228件で全件再実行ではない。
