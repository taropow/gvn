# 起動時の未描画背景（0.76.2）

メイン画面の `WM_ERASEBKGND` は背景を描かずに処理済みを返していた。初回のDirect2D描画に入る前は有効な描画面がなく、背景が露出する余地があった。修正前に、背景消去の通知を送っても検査用のマゼンタが残ることをネイティブ画素テストで再現した。

初回描画が成功するまでの背景消去で、現在の背景設定と同じ市松模様をGDIで塗る。市松のサイズ・2色・開始位置、および単色設定を維持し、DCのクリップを尊重する。最初の描画後は従来どおり描画済みの内容を保持する。リサイズ時に毎回背景を塗り直す処理、タイマー、ワーカー、画像バッファは追加しない。パターンの一時メモリとGDIブラシはその呼び出し内で解放する。

専用の非対話デスクトップと隔離されたクリップボードで確認する。ComputerUseやユーザーの画像・設定・クリップボードは使わない。画素テストとネイティブ描画を検証するものであり、実際のモニターでのDWM合成タイミングやちらつき頻度は測定していない。

修正後はUI 8件・関連アプリ6件、専用自動操縦2本46操作・5画面、配布EXE主要10経路が通過した。

[確認記録](verification/0.76.2-startup-background-related.json)。普段使い用 `G:\gvn\app\gvd.exe` は0.76.2へ更新済み。起動中のウィンドウは保持し、次の起動から新しい版を使う。
