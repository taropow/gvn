# PNGプロンプト表示（0.72.0）

ツールバーの画像情報アイコンの右に「プロンプト表示」を追加する。「その他」メニュー、狭いウィンドウのツールバーの「その他の操作」、設定で割り当てたキーからも同じ画面を開ける。画像がない時は無効。

参照仕様は [Rust Inpainter PNGプロンプト表示仕様](G:/rust_inpaint/docs/rust-inpainter-png-prompt-spec.md)。0.71.1までの変更はmainへ取り込み、この機能はcodex/prompt-viewerで実装する。

## 表示とコピー

左のツリーで、スロット・メイン・キャラ・拡張・LoRA・ADetailer・送信済み全文・生成側の記録・元JSONを選び、右側の読み取り専用欄で読む。長文は折り返しと縦スクロールに対応し、ウィンドウの大きさを変更できる。ライト／ダークの共通テーマを使う。

日本語原文と翻訳、通常とネガティブを別の欄にする。キャラタブと名前のない拡張グループは0始まりの番号に1を足して表示する。OFFのトグルはOFFと明示し、弱い文字色にする。「ONトグルのみ」の欄には、ONで本文のある項目だけを配列順に並べる。拡張項目はグループ・タイトル・重みを示し、欠落した重みは仕様どおり0とする。

「この欄をコピー」は選んだ項目の元文字列を、「正の全文をコピー」「負の全文をコピー」は保持した全文をコピーする。空欄ではコピーを無効にする。表示用の改行・ラベルとコピーする本文を区別し、重み括弧・カンマ・LoRAタグなどを削除・並べ替えない。

## 読み取り規則

- `inpainter-parts` の最初の値を採用し、JSONオブジェクト・version・既知項目の型を検証する。対応versionは1。未知のキーは無視し、欠落値は空・0・falseとする。nullや型の不一致は解析失敗として扱う。
- 対応した内訳がある場合は `final.prompt` / `final.negative` が全文。内訳を連結して再生成しない。`parameters` は生成側の記録として別に保持する。
- 内訳なし・解析失敗・未対応バージョンを区別し、元JSONを詳細に残す。未対応の内訳をスロット等へ推測分類しない。
- 通常全文は `parameters` → `prompt` / `negative_prompt` → キー名にprompt / negativeを含む値の順。空のparametersでも次の候補に進まない。A1111の正負分離は参照仕様のマーカー規則に従う。
- PNGのiTXt・tEXt・zTXt、圧縮テキスト、IDAT後のテキストを読む。iTXtと内訳の旧tEXtはUTF-8、通常のtEXt/zTXtはLatin-1として扱う。通常の同名キーは後の値を採用する。

プロンプトがなければ「プロンプト情報なし」と空欄の案内を表示する。PNG/APNG以外でもボタンは使用でき、該当情報がないことを表示する。ComfyUIグラフのノード解析は行わず、通常の元メタデータを参照できる。

## 軽さと画像との対応

画像デコードの既存入力からPNGテキストだけを取り出し、画像のメタデータとして不変の共有データに保持する。JSONの解釈と画面の生成はボタンを押した時だけ行う。表示のたびに元ファイルを読み直さず、画像送りで採用された画像、PNGデータの貼り付け、ZIP内の画像、APNGにも同じ経路で対応する。

加工とUndoは元の生成記録を共有する。加工した画像では「加工前の生成メタデータ」と明示する。これは生成時の記録の読み取り表示であり、加工後のピクセルからプロンプトを推定する機能ではない。PNG保存や画像コピーへのテキストメタデータの埋め戻しは今回の対象に含めない。

チャンクの範囲とテキストCRCを確認し、テキスト1件は展開後1MiB、合計4MiB、256チャンク、PNG走査10万チャンクまでに制限する。JSONの深さ・構造要素数・トグル／拡張の件数にも上限を設ける。破損や上限超過のテキストは表示側に状態を残し、画像の画素を変更しない。保持したテキストの容量は画像キャッシュの予算へ加算する。

JSON解析には固定コミットの[PicoJSON](https://github.com/kazuho/picojson)を使用し、外部DLLを追加しない。ソースとライセンスをthird_partyに保存し、配布物にもライセンスを含める。

## 検証

生成スクリプトと小さな合成PNG/APNG/ZIPをリポジトリへ保存する。元のユーザー画像やクリップボードには触れず、専用の非対話デスクトップ・クリップボードで確認する。

PNGテキストの各形式、全文優先、ON/OFF、番号・重み、日本語、破損・未知version・重複、加工とUndo、ファイル削除後の表示、画像送り、貼り付け・ZIP、ネイティブ画面のコピーと配置を対象にする。プロンプト6件、既存メタデータ7件、関連アプリ6件、専用1本57操作・6画面、配布EXE主要10経路が通過。最終の表示調整後にプロンプト6件・関連アプリ3件と画面操作を再確認した。追加の起動時DLLがないことと、配布ライセンスも確認した。
