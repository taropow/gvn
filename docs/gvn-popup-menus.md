# 右クリックメニュー（0.75.0）

標準の右クリックは、よく使う操作を直接選べるコンパクトメニューにする。画像コピー、貼り付け、選択範囲で貼り付け、名前を付けて保存、全体表示、100%表示、回転・反転、編集モード、編集ソフト、プロンプト、ファイル操作を固定順に並べる。表示名・実行コマンド・チェック・ショートカットは現在の設定を使う。

## 状態別の操作

- 空のキャンバス: 開く・貼り付け・新規画像。
- 選択範囲あり: コピーの表示名を「選択範囲をコピー」に変更。切り取り、解除、選択反転、トリミング、選択画素の削除を追加。
- 自由変形・トリミング中: 先頭に適用・キャンセル。右クリックを開く／閉じるだけでは選択や変形を確定・中止しない。
- GIF/APNG: 再生／一時停止、前後のコマ、ループを追加。

ファイルの削除は既定で「ファイル操作」内にまとめ、「元のファイルをごみ箱へ」など対象を明記する。「選択範囲の画素を削除」と区別する。ファイルのないクリップボード画像や編集中には、利用できない操作を無効にする。未対応の貼り付けは従来どおり何もせずに戻る。

## 設定と従来表示

設定の「操作 → 右クリック」で、コンパクト／従来の全メニュー／カスタムを選ぶ。カスタムは一覧の項目を上下移動・非表示・追加でき、区切り線も追加できる。最大64項目。項目を使用頻度で並べ替えず、指定した順序を保持する。状態別の操作と、カスタマイズ・全メニューへの入口は常に自動で補う。

変更は適用／OKで保存する。適用前のキャンセルは保存済みの設定を保持し、「このタブを初期状態に戻す」は表示方式と項目を標準へ戻す。他のマウス操作・キー割り当ては保持する。既存の通常右クリック「親メニュー」にこの表示方式を適用し、修飾キーや他ボタンのメニュー指定・コマンド指定は従来の意味を保つ。「状態に応じた右クリックメニュー」自体もキー・マウスへ割り当て可能。

## 表示と軽さ

既存のWin32メニュー・テーマ・ツールバーの小アイコンを使う。アイコンは種類・サイズ・明暗・有効状態ごとに再利用し、チェック項目はチェック印を優先する。文字と現在のショートカットを併記する。

右クリックを開く時は画像解析、クリップボードの復号、プロンプトのファイル読み直し、書き出しを行わない。「すべてのメニュー」は、その階層を開いた時だけ既存の全メニューから複製する。複製したメニューは独立して破棄し、メニューバーのハンドルを共有しない。

専用の非対話デスクトップとクリップボードで、状態保持、実コマンド、設定保存、実際のTrackPopupMenuの項目選択を確認する。ComputerUseやグローバル入力は使わない。Windows内部のMNメッセージは所有するメニューを操作する試験ドライバーだけで使い、アプリ本体には追加しない。物理デスクトップ／DWM提示の実機確認とは区別する。

設定62件・関連アプリ10件、専用自動操縦2本138操作・14画面、配布EXE主要10経路が通過した。実メニューからコピー・変形取消・コマ送りを選択し、選択／変形の保持、通知が1秒後も残り期限後に消えること、設定の適用／取消／初期化と保存を確認した。

[確認記録](verification/0.75.0-context-menu-toast-related.json)。普段使い用 `G:\gvn\app\gvd.exe` は0.75.0へ差し替え済み。既存ウィンドウは保持し、次の起動から新しい版を使う。

## 従来の全メニュー割り当ての確認記録（0.42.0）

配布0.41.0と同じ本体で、13種類の呼び出しを専用ドライバーから確認した。本体の作り替えや再配布は行っていない。[実行記録](verification/0.42.0-popup-related.json)を参照。

設定のマウス割り当てでは、全体、ファイル、編集、画像、リスト、表示、アニメーション、その他、並び順、RGB入れ替え、マスク、登録先、他アプリの各メニューを指定できる。親・子・孫のメニューを直接開ける。各入口は通常メニューと同じ現在の設定・画像を使い、選択されたコマンドを実行する。取消で画像やクリップボードを変えない。

今回のドライバーは通常のGVN.exeを専用の非表示デスクトップへ起動し、独立した設定とクリップボードを使う。右・中・X1・X2クリックとCtrl/Shiftの割り当てをINIへ登録し、実ボタンメッセージから各メニューへ入る。開いたメニューの項目と入口、所有プロセス、ネイティブのメニュー操作中の状態を確認する。

[GetMenuBarInfo](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getmenubarinfo)で実際のメニューとウィンドウを対応付ける。[GUIスレッド情報](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-guithreadinfo)と、所有ウィンドウのWS_VISIBLEも確認する。Windows内部のMN_SELECTITEM・MN_OPENHIERARCHY・MN_BUTTONDOWN/UP・MN_CANCELMENUSを所有メニューだけへ送り、実ハイライトと階層展開を確認して選択・取消を進める。選択結果のコマンドIDを代入したり、WM_COMMANDで選択を置き換えたりはしない。操作メッセージは試験専用で、GVN本体の公開API・依存関係には加えていない。内部プロトコルの確認はWindows 10.0.26200上の結果である。

13種類の入口、計15回のメニュー表示、29メッセージ、5回の選択が成功した。全体メニューから編集へ入り透過コピー、画像の階層とRGBメニューから各1回のR/G入れ替え、表示からステータスバー、並び順から逆順を選択した。コピーと加工ではAlphaが0・1・127・128・254・255の合成画像の全RGBAを照合した。入れ替え2回で元の全RGBAへ戻る。表示設定は実ステータスバーの表示状態と、開き直したメニューのチェックを照合した。逆順も再表示したチェックと一致した。残る8入口は取消でメニューが閉じ、クリップボードを保った。

最初の5段階の失敗記録とドライバーのソースも保持した。非表示デスクトップではIsWindowVisibleが偽になり、通常のWM_KEYDOWN送信ではこの環境のメニュー選択を進められなかった。また、既定で非表示のメニューバーへGetMenuを呼んでいた確認処理は、実際に開いたメニューとステータスバーの照合へ修正した。これらを本体の機能不良・成功の証拠には使わない。

ComputerUse、Sky、グローバル入力、ユーザーの画面・クリップボードは使っていない。物理キーボード、実デスクトップの前景制御、OS標準ウィンドウ移動、外部アプリへの受け渡しは別の未確認範囲である。内部操作メッセージによる確認を、物理入力の確認へ広げない。

S144を実装済みへ更新し、マウス設定全体はOS標準移動などの残りを引き続き管理する。本体・既存テストのソースとバイナリは配布0.41と同一で、全体207件・CTest・既存自動操縦の全体・性能測定は再実行していない。
