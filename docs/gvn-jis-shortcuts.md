# 無変換・変換キーのショートカット

0.35.0へ配布反映済み。現在の検査範囲は[配布記録](verification/0.35.0-daily-use.json)を参照。

「設定」→「キー」で無変換・変換を機能へ割り当てられる。入力欄では `NonConvert` / `Convert` と「無変換」/「変換」の両方を使え、Ctrl・Shift・Altとの組み合わせも通常のキーと同じ書式になる。「キーを押して入力」からも取り込める。英語名と日本語名は同じキーとして扱い、二重登録・他の機能との衝突を防ぐ。既存の最大8キー、先頭キーのメニュー表示、適用・取消・INI保存を使う。

取り込み中は通常のキー通知とIMEのキー通知を処理する。先に届く `VK_PROCESSKEY` は入力待ちを中断せず、続く具体的なキー通知を待つ。入力欄のIME関連付けは変更しないため、入力完了、Escによる中止、他の欄への移動後も元の入力コンテキストを保つ。IME通知の仮想キーは[MicrosoftのWM_IME_KEYDOWN仕様](https://learn.microsoft.com/en-us/windows/win32/intl/wm-ime-keydown)に従う。仮想キーは[VK_CONVERT / VK_NONCONVERT](https://learn.microsoft.com/en-us/windows/win32/inputdev/virtual-key-codes)を使う。

## 確認した範囲

旧0.34の専用自動操縦で、NonConvertを追加しても登録数が0のままになる現象を再現した。変更後は関連する設定53件とIME基盤6件が通過した。最終候補の専用2本183操作4画面で、英語/日本語名、修飾キー、キー押下による取り込み、IME状態保持、Esc/フォーカス移動、保存・再オープン、メニュー表示と実際の反転操作・Alpha付きコピーを確認した。既存のテスト本文は変更していない。

最初のIMEを外す方式は、戻す操作がこの環境で失敗した。関連付けを変更しない方式へ直し、一時的な診断コードを削除した。失敗記録も[証拠](verification/0.35.0-jis-shortcuts-related.json)に残す。設定・IME基盤の検査は同じ実行ファイルを保持しており、成功後に繰り返していない。

検査は専用の非表示デスクトップ、専用クリップボードと設定を使う。物理JISキーボードと各IMEによるキー変換・予約の全組み合わせは未検証。WindowsやIMEが通知しない組み合わせまで受信できるとは扱わない。全体GOALの完成を示すものではない。
