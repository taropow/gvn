# GVN 0.60.0: 選択範囲と仮置き画像

**0.61.0でUIと線の仕様を更新。** 通常起動は閲覧モードとし、鉛筆アイコンで左ツール列を開く。利用者の指定により、黒白の動く破線から初期の水色の静止線へ統一した。画面上の1px幅は維持する。選択線のタイマーは使わない。以下は0.60.0時点の記録で、現在のUI・線・旧コマンドとの関係は[0.61.0の仕様](gvn-editor-mode.md)を参照。

## 選択ツール

編集メニューの「選択ツール」から矩形選択、自由選択、折れ線選択、移動・変形を選ぶ。既存のSキーによる範囲選択モード、Shift+左ドラッグ、数値指定、選択単位も利用できる。

| 操作 | 動作 |
| --- | --- |
| 矩形 | 左ドラッグで指定。既存のグリッド・選択単位を適用 |
| 自由 | 左ボタンを押して輪郭を描き、離すと始点へ閉じる |
| 折れ線 | 頂点をクリック。ダブルクリックまたはEnterで閉じる。Escで作成を中止 |
| Shift併用 | 元の選択に追加 |
| Alt併用 | 元の選択から除外 |
| Ctrl併用 | 元の選択との共通部分を選択 |
| すべて選択 | Ctrl+A |
| 選択を解除 | Esc、Ctrl+D、編集メニュー |
| 選択範囲を反転 | Ctrl+Shift+I、編集メニュー。画像の色反転とは別 |
| 選択範囲を削除 | Delete、編集メニュー。選択した画素を透明化 |
| コピー・切り取り | Ctrl+C / Ctrl+X。非矩形の選択外は透明で切り出す |
| 選択範囲を切り出す | Ctrl+Y。非矩形では外接矩形と透明な選択外を持つ画像になる |

修飾キーは選択の開始時に決める。選択ツールを選んでいない時の従来のマウス割り当ても維持する。通常のファイル削除は選択範囲がない時の既存キー割り当てに従う。

## 選択線の表示

黒白の4pxずつの破線を80msごとに1px進める。画像座標を画面座標へ投影した後、96dpiの描画ターゲットで1pxの線を引く。表示倍率やウィンドウのDPIに線幅・破線周期を掛けない。矩形と非矩形の輪郭、作成中の線、仮置き画像の変形枠に同じ処理を使う。斜線は1px幅の階段状の描画になる。

選択線・ハンドル・市松は表示専用で、画像データ、コピー、保存に焼き込まない。選択・作成中の線・仮置きがない時と最小化中は選択線タイマーを止める。破線の更新で画像のデコードや画素編集を繰り返さない。

## 選択した画素の移動・変形

選択範囲がある状態で「移動・変形」を実行すると、選択した画素を仮置きにする。表示上は元の範囲を透明にし、元画像自体は確定まで保持する。移動ツールのまま選択範囲内を押して開始することもできる。

- 枠内をドラッグ: 移動。
- 8個のハンドル: 大きさを変更。反対側を固定し、Shiftで縦横比を維持。
- 枠外をドラッグ: 中心を基準に回転。Shiftで15度刻み。
- 矢印: 画像の1pxずつ移動。Shift+矢印で10px。
- ツールバーの「位置・サイズ・角度」: X、Y、幅、高さ、角度を入力。単位は画像のpxと時計回りの度。
- ツールバー「確定」またはEnter: 元画像へ合成。
- ツールバー「中止」またはEsc: 仮置きを取り消し、元画像・元の選択・再生状態を戻す。
- 確定後のCtrl+Z: 元画像に戻す。元がアニメーションなら元のフレームと再生状態も復元。

数値のX・Yは回転前の矩形の左上。回転の中心は矩形の中心。幅・高さは1～65535px。反転・別の基準点の指定はこの変形には含まない。キャンバス外の部分は確定時に切り落とす。

## 選択範囲でペースト

編集メニューに通常の貼り付けと別の「選択範囲でペースト」を追加する。読み取った画像を仮置きし、上記と同じ枠・確定／中止で操作する。空のウィンドウにも貼り付けられる。元画像がない時の確定で、新しい透明画像として作成する。

`GVN.Selection.v1`が正しければ、そこに含まれる元キャンバス上のX・Yに配置する。画像が既にある場合はそのキャンバスへ元の画素単位で置き、キャンバス寸法の違いによる自動拡縮はしない。空の時は位置情報にある元キャンバス寸法を使う。

位置情報がなければ画像の左上（0,0）へ配置する。クリスタの標準クリップボードから切り出し元の位置は推測しない。不正な独自ヘッダー・版・寸法・長さ・PNGなら、同じクリップボードを開いたまま標準画像形式へフォールバックし、元位置不明と表示する。対応画像のフルパスもこの明示コマンドの画像入力として読める。

選択範囲のコピーは、Alpha付きPNG・DIBV5と同時に位置付き形式を公開する。他アプリへは標準画像として貼り付けられる。独自形式だけの対応アプリ同士では位置も引き継ぐ。[プロトコル](gvn-selection-clipboard-v1.md)、[自作ペイント用のAI実装指示](ai-paint-selection-copy-instructions.md)。

## 実装と負荷

`SelectionRegion`は矩形を数値だけで保持し、自由・折れ線は走査線の区間で保持する。矩形のために画像全体のマスクを割り当てない。輪郭は範囲の確定時に作って共有し、破線の各更新では再生成しない。頂点65536個・区間100万個・輪郭100万線分に制限する。

形状の境界は画素中心で判定する硬い境界。元画像の透明・半透明をそのまま保持する。ぼかした選択境界や筆圧によるマスクは含まない。

仮置きの表示は最長辺2048pxまでのプレビューを一度作り、移動中はキャッシュを使う。確定は元の解像度で、Alphaを乗算した色で補間してから合成し、透明部分の色がにじむのを避ける。全体の再デコードを行わない。基盤は`floating_selection.cpp`、`selection_region.cpp`、プロトコルは`selection_clipboard.cpp`、表示は`Renderer::draw_ants`。

明るさ・レベル・色合い・ぼかし等の既存の画素加工でも、非矩形の選択外を戻す。色数変更やパレット全体の編集など、画像形式全体を扱う操作は従来の画像全体の処理となる。

## 検証

基盤5件で、選択形状と集合演算、透明切り出し／削除、幾何変形、Alpha補間、バイナリ形式の正常／異常を確認。実Appの追加6件と関連6件では、実際のウィンドウメッセージによる選択・変形・確定・中止・Undo、標準画像と位置情報、割当失敗、アニメの状態復元を確認する。

描画結果の25％・100％・400％で、線が黒白で移動し、上下の隣接行へ太らず1px幅であること、元RGBAとコピー内容が変わらないことを検査した。2048×1536pxでの最終測定は、破線を含む再描画平均1.78ms、四角形の走査線化平均0.40ms、仮置きの変形表示平均3.02ms。矩形のマスク割当0B、測定した非矩形の保持約62,912B。特定のPC・画像・表示サイズでの測定で、全画像の速度を保証する値ではない。

ComputerUseを使わず、専用の非表示デスクトップとクリップボードで確認する。利用者のクリップボード・起動中の画像ソフトを操作しない。配布本体の主要10経路と更新待機の確認は配布記録に含める。[記録](verification/0.60.0-selection-related.json)。

後で依頼された回転付きトリミング・リサイズ専用ボックスは、別の[計画](gvn-interactive-crop-plan.md)のまま。今回の選択・貼り付けを、その専用機能の完成とは扱わない。
