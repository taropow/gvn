# アプリアイコンと空画面タップ

## アプリのアイコン

0.76.5では選択したB案に合わせ、青い角丸パネル（#1677E8）に、大きく太い白のVと四隅のフレームを置く。VはViewerを表し、フレームは画像を見る枠を表す。フォントに依存しない幾何形状で生成し、16pxの小さな表示でも形を保つ。

固有アイコンはEXEの最初のアイコングループ（ID101）へ埋め込む。16/20/24/32/40/48/64/96/128/256pxの32bit Alpha画像を持つ。WindowsのEXE表示、タスクバー、ウィンドウの大小アイコンで同じ絵を使う。[デザイン](../src/assets/gvn-icon.png)。

元はEXEにアイコンリソースがなく、ウィンドウだけが「画面に収める」のツールバーアイコンを流用していた。`src/gvn_version.rc.in`で`src/assets/gvn.ico`を埋め込み、`src/ui.cpp`の`window_icon`はリソースから指定サイズを読む。取得した非共有ハンドルは既存の終了処理で破棄する。リソースを持たないUI試験ホストでは従来の代替表示を使う。

生成元は`tools/generate_app_icon.py`。実行時にPythonや外部画像ファイルは必要ない。ツールバーの操作アイコンは別のまま保つ。[Windowsのアイコン資源](https://learn.microsoft.com/en-us/windows/win32/menurc/about-icons)と[所有するアイコンの扱い](https://learn.microsoft.com/en-us/windows/win32/menurc/using-icons)に従う。

固定起動先を更新する際は、配布の`app.ico`をハッシュ付きの`app/icons/gvn-<hash>.ico`へ配置する。`tools/refresh_daily_icon.ps1`は、固定先のEXEと一致する**既存**のタスクバーショートカットだけを見つけ、バックアップ後にアイコンの参照を直す。他の固定項目や起動引数を変更せず、Explorerは終了しない。元のEXEパスに残るアイコンキャッシュへ依存しない参照にする。

## 空のキャンバスのタップ

画像がなく読み込み中でもない時に、キャンバスを左クリックまたはタップすると通常の貼り付けを行う。対応するクリップボード画像、Alpha、ファイル一覧、対応画像のフルパスは、Ctrl+Vと同じ実装を使う。未対応・読み取り失敗の扱いも通常の貼り付けと共通にする。

押し始めと離した時の両方で対象が空であることを確認し、指・ボタンを離した時に一度だけ実行する。ドラッグ、取消、枠外で離した場合、修飾キーや他ボタンとの併用、読み込み中、押している間に画像が開かれた場合には、この自動貼り付けを行わない。既に画像がある時のマウス割り当ては維持する。

空の時はステータスバーを1区画にし、「画像を開いてください。タップするとクリップボードの内容がペーストされます」と案内する。読み込み中は読み込みの案内を出す。画像を開いたら従来の5区画へ戻り、寸法・倍率などを表示する。キャンバス自体は従来通り市松だけにする。

## 確認範囲

0.76.5のアイコン変更では、選択したB案と生成した256px画像の一致、EXEに埋め込んだ全10サイズと元ICOの一致、Windows APIによる描画、実ウィンドウの16/32pxアイコンを確認する。配布本体の主要10経路も一度確認する。[今回の証跡](verification/0.76.5-icon-related.json)。

追加したApp2件は実ウィンドウの入力メッセージ経路、RGBA一致、フルパス、案内・情報欄の切替、ドラッグ・取消・読み込みとの競合を検査する。既存の貼り付け、バー、マウス操作4件も確認する。

製品本体で、EXEのアイコングループと全10サイズの読み込み、ウィンドウの大小アイコン、通常起動したGVNのコピー→画像を閉じる→マウスタップ→再コピーのRGBA一致を確認する。専用のデスクトップ・クリップボードを使い、ComputerUseは使わない。配布本体の主要10経路も一度確認する。[証跡](verification/0.59.0-icon-tap-related.json)。

タップはWindowsが生成する左ボタン互換の入力も受ける。実タッチパネル、モニター間DPI移動、Windowsのタスクバーの最終描画を直接目視確認した意味ではない。
