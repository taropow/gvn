# GVN 0.63.0: 表示画質を3種類へ整理

## 利用者向けの動作

| 選択 | 実際の方式 | 用途 |
| --- | --- | --- |
| 無補正 | 最近傍（Simple） | 画素をくっきり表示する。補間しない |
| 高速 | Linear | 軽い補間で表示する |
| 高画質 | Lanczos3 | 輪郭・細かい模様を高品質に拡大縮小する |

設定の通常表示・全画面それぞれの縮小／拡大、漫画の高さ合わせ、画像サイズ変更の選択肢を同じ3種類にする。表示の縮小／拡大設定は手動ズームにも使う。表示品質の変更は、元画像・PNGコピー・保存・OLEへ渡す画素に焼き込まない。画像サイズ変更は明示的な編集として選択した方式で画素を作る。

Linearは補間方式であり、無補正は最近傍に割り当てる。原寸100%では元の画素を直接表示する。

## 修正した不一致

0.62.0では、フィット時のLanczos3設定と別に、手動ズームはLinear／Simpleへ分岐していた。また選択ツールが有効な間は常にSimpleになっていた。倍率によるSimpleへの切り替えや最近傍固定スイッチも、画質の選択に優先していた。このため高画質を選んでも実際には別の方式になる場合があった。

0.63.0では、同じ選択をフィット・手動ズーム・選択ツール中の表示へ適用する。重複する「最近傍に固定」「指定倍率以上は最近傍」「手動ズーム時の補間ON/OFF」は設定画面から外す。旧INIの値は読み書きの互換性を保つが、表示画質を上書きする条件として使用しない。

「ドラッグズーム中は一時的に高速表示する」をONにした場合だけ、操作中はLinearへ一時的に切り替え、ボタンを離した時点で選んだ画質へ戻す。無補正を選んでいる場合は無補正を保つ。メニューの「無補正表示」は縮小／拡大の両方を無補正へ切り替え、もう一度押すと高画質へ戻す。

原寸表示、仮置き画像の移動・変形プレビューと変形確定の処理は、それぞれの既存の画素処理を保つ。表示領域がメモリ上限を超える場合は高速へ切り替え、状態欄に理由を表示する。極端な縮小率では従来の面積平均への切り替えを保つ。

## 旧設定・内部形式

内部の補間IDと加工APIは残す。表示・UIでは、旧ID0を無補正、1を高速、2〜13を高画質へ読み替える。画面で選び直して適用すると0／1／10を保存する。新規の通常縮小と漫画縮小の標準は高画質へ変更する。既存の明示的なLinear設定は高速として引き継ぐ。キャンセルでは保存値を変更しない。

`display_quality_index` / `display_quality_filter` が画面の0〜2と内部の0／1／10を対応させる。単純にコンボボックスの番号2を旧Integraとして保存しない。
