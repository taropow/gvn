# 貼り付け中のステータスバー白化（0.76.1）

テーマ付きのステータスバーは通常描画を独自に処理していたが、描画前の `WM_ERASEBKGND` はネイティブ標準のままだった。ダークテーマでこの段階をメモリDCへ描くと、期待する `#222428` に対して `#F0F0F0` で消去されることを旧実装で再現した。貼り付けによる表示内容・部品配置の更新の間に、明るい背景が露出する経路が残っていた。

ステータスバーの背景消去にも現在のテーマの面色を使う。通常の文字・区切り・保存名・形式・ドラッグ領域の描画は継続する。DCのクリップを尊重し、ハイコントラスト時は既存のネイティブ処理を使う。設定項目、常駐処理、タイマーは追加しない。

修正前に失敗する背景色の画素テストを保存し、同じテストでライト／ダークとクリップ外の画素を確認する。アプリ側では実際の貼り付けで空の状態から画像へ、画像から別の画像へ切り替え、ステータス更新の各段階の背景消去色、RGBAとAlpha、通知、ファイル名入力を確認する。専用の非対話デスクトップとクリップボードを使用し、ComputerUseやユーザーの画像・クリップボードは使わない。モニターへの物理的な提示やちらつき頻度の測定は行っていない。

修正後はUI 8件・関連アプリ6件、専用自動操縦2本81操作・6画面、配布EXE主要10経路が通過した。

[確認記録](verification/0.76.1-paste-status-related.json)。普段使い用 `G:\gvn\app\gvd.exe` は0.76.1へ更新済み。起動中のウィンドウは保持し、次の起動から新しい版を使う。

背景消去の仕様: [Microsoft WM_ERASEBKGND](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-erasebkgnd)。
