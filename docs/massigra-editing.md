# MassiGra 0.45 画像加工の詳細

[全体仕様](massigra-spec.md)に対応する画像加工の仕様。選択範囲、画像データとクリップボード、幾何変換、色調補正、フィルタ、マスク、色数変換を整理する。表示倍率を変えるだけのズーム・フィットと、ここで扱う画像データの加工は区別する。

## 1 加工対象と元に戻す

選択範囲を使う加工では、選択がなければ画像全体を対象にする。リサイズ等は画像全体を処理する。画像に加えた変更を戻せるのは1手順だけで、「元に戻す」を設定で無効にすると、そのためのメモリと処理を削減できる。

ダイアログに処理結果のプレビューを備えるものがある。メイン表示をプレビューにする間は、拡大縮小の画質を下げる仕様がある。プレビュー確認、確定、ファイルへの保存は別の段階であり、単に表示しただけで元ファイルを自動保存するという仕様ではない。[画像加工の基本](http://www.massigra.net/massigrahelp/currentver/edit.htm)、[編集メニュー](http://www.massigra.net/massigrahelp/currentver/m_edit.htm)

## 2 選択範囲

### 2.1 選択モード

「編集 → 選択モード」でカーソルが十字になり、左ドラッグで矩形を指定する。ステータスバーは、選択単位、始点、終点、幅・高さ、カーソル位置、その位置の画素色に切り替わる。

選択モード中のズームは低画質となり、左ダブルクリックによる全画面切り替えは無効。全画面では選択モードを利用できず、選択範囲も解除される。[選択モード](http://www.massigra.net/massigrahelp/currentver/m_edit.htm#selmode)

### 2.2 数値による指定

| 入力 | 内容 |
| --- | --- |
| 左 / 右 | 矩形の左右端 |
| 上 / 下 | 矩形の上下端 |
| 幅 / 高さ | 矩形の寸法 |
| 画像のサイズ | 現在画像の寸法表示 |

上下位置と高さのアップダウンコントロールは、例外的に上ボタンで減少、下ボタンで増加する。座標端点を含むかどうか等の厳密な矩形規則は文章では説明されていない。[選択範囲ダイアログ](http://www.massigra.net/massigrahelp/currentver/d_selection.htm)

### 2.3 選択範囲の単位

フリー、2 × 2、4 × 4、8 × 8、16 × 16、32 × 32、カスタムを選べる。フリー以外では段階的な指定となり、主にマスクのブロック単位をそろえる用途を持つ。

カスタムでは、始点の水平・垂直単位と、サイズの水平・垂直単位を別々に指定する。1、8、16を欄へ入力するボタンもある。[選択単位メニュー](http://www.massigra.net/massigrahelp/currentver/m_e_selstep.htm)、[選択単位ダイアログ](http://www.massigra.net/massigrahelp/currentver/d_selstep.htm)

## 3 クリップボードと新規画像

| 機能 | 動作 |
| --- | --- |
| 切り取り | 選択範囲をクリップボードへコピーし、元の範囲を指定色で塗り潰す |
| コピー | 選択範囲、または画像全体をコピー。巨大データはコピーできない場合あり |
| 貼り付け | クリップボード画像を選択範囲へ貼る。色タイプが異なると現在画像を24 BPP化 |
| 選択範囲を切り出す | 選択外の周囲を捨てるトリミング |
| 新規作成 | メモリ上に新たな画像を作る |
| 新規画像に貼り付け | 現在画像を閉じ、クリップボード画像を新規画像にする |
| 画像を閉じる | 表示中画像を閉じる |

選択範囲がないときの貼り付けは、標準では新規画像になる。全般設定で変更すると、現在画像全体を選択している扱いで貼り付ける。画像が開いていない場合は新規画像へ貼り付ける。

切り取り時の塗り潰し色は設定できるが、パレット画像では近似等により指定色と異なる場合がある。貼り付け時の拡縮や、クリップボード形式ごとの透明情報の扱いはヘルプだけでは確定できない。[編集メニュー](http://www.massigra.net/massigrahelp/currentver/m_edit.htm)、[全般設定](http://www.massigra.net/massigrahelp/currentver/d_prop_gene.htm)

新規作成ダイアログには、幅、高さ、背景色、BPP、名前がある。幅・高さの上限はそれぞれ65535で、予定データサイズを表示する。画像データ容量等の制限も別途適用される。[新規作成](http://www.massigra.net/massigrahelp/currentver/d_newimg.htm)

## 4 拡大縮小と解像度

### 4.1 拡大縮小ダイアログ

| 項目 | 仕様 |
| --- | --- |
| 元のサイズ | 現在の幅・高さとデータサイズ |
| 新しいサイズ | 変更後の幅・高さとデータサイズ |
| 幅 / 高さ | 最大65535 |
| 比率 | 元画像に対する割合 |
| 今の半分 / 今の2倍 | 現在入力している幅・高さを変更 |
| プリントサイズの幅 / 高さ | 画像寸法と解像度から計算する実寸 |
| プリントサイズの単位 | 長さの単位 |
| X解像度 / Y解像度 | 水平・垂直の印刷解像度 |
| 解像度の単位 | 解像度値の表記単位 |
| 画像を拡大縮小 | 外すとピクセル数を変えず、解像度だけを変更 |
| 元の縦横比を保つ | 寸法入力を連動させる |
| 縮小した後シャープ加工 | 縮小後に弱いシャープ処理。Simpleでは有効にしても行わない |
| 縮小方法 / 拡大方法 | それぞれ独立したアルゴリズム |

物理メモリ超過を許可していない場合は、その容量を超えるサイズへ変更できない。拡大後に元サイズへ縮小しても、元の画素へ完全には戻らない。[拡大縮小](http://www.massigra.net/massigrahelp/currentver/d_resize.htm)

### 4.2 補間と縮小のアルゴリズム

| 名称 | ヘルプ上の説明と特徴 |
| --- | --- |
| Simple | 最近傍法。高速で、BPPを維持して処理可能 |
| Linear | 基本は双線形補間。50%以下の縮小では作者独自の単純平均法を使用 |
| Integra | 面積平均・積分系。縮小時は高速かつ比較的良好。整数倍拡大はSimpleと同じ結果 |
| Hermite | Integraより少しぼける傾向。リンギングを避けつつ拡大したい場合の選択肢 |
| Bell | 中程度にぼかす。縮小には向かないと説明 |
| B-Spline | 強めにぼかす。縮小には向かないと説明 |
| Mitchell | シャープさとぼかしを組み合わせる。縮小には向かないと説明 |
| Cubic-0.5 | 中程度のシャープさ。写真・イラスト、拡大・縮小の汎用候補 |
| Lan2+0.25 | Lanczos2を独自に改変。Cubic-0.5よりシャープ |
| Lan2+0.50 | さらにシャープな独自改変。輪郭強調が強すぎる場合あり |
| Lanczos3 | 滑らかでシャープだがリンギングが出る場合あり。掲載方式の中では最も低速と説明 |

Simple以外で加工すると、出力は24 BPPになる。HermiteからLanczos3までの方式で100分の1より小さく縮小する場合、実際にはIntegraを使う。

MitchellからLanczos3の系統では輪郭周辺のリンギングに注意するよう説明される。白地の黒い線などでは、輪郭が二重に見える場合がある。同じ方式名でも他ソフトと同一の画素結果を保証しない。

ヘルプでは速度優先にLinear、画質優先にLanczos3、代替にCubic-0.5やLan2系を挙げる。これらは説明上の傾向であり、今回の性能測定ではない。[拡大縮小方法](http://www.massigra.net/massigrahelp/currentver/d_resize.htm#algor)

## 5 画像サイズと回転

### 5.1 画像サイズ

画素の拡大縮小ではなく、キャンバスを切り詰めたり周囲へ余白を加えたりする機能。

| 項目 | 内容 |
| --- | --- |
| 元のサイズ / 新しいサイズ | 幅・高さとデータサイズ |
| 幅 / 高さ | 最大65535ピクセル |
| 単位 | ピクセルのほか、現在解像度から算出するインチ・cm等 |
| 元の縦横比を保つ | 寸法を連動 |
| 背景色 | キャンバス拡大時に付加部分を塗る色 |
| 基準点 | どこを基準にキャンバスを変えるか。マウスで指定 |

パレット画像の背景色は指定したものと異なる場合がある。基準点はヘルプ上、キーボードでは指定できない。物理メモリ超過設定の制約も適用される。[画像サイズ](http://www.massigra.net/massigrahelp/currentver/d_imgsize.htm)

### 5.2 回転と反転

左90度、右90度、上下反転、左右反転、角度指定回転がある。角度は-360.000〜360.000度。任意角度で生じる空白の背景色を指定できる。90度の倍数以外での回転は24 BPPへ変換される。

これは画像データの加工であり、表示メニューの回転オプションやExif方向に基づく表示回転とは別の機能である。[回転メニュー](http://www.massigra.net/massigrahelp/currentver/m_i_rotate.htm)、[回転ダイアログ](http://www.massigra.net/massigrahelp/currentver/d_rotate.htm)

## 6 色調補正

### 6.1 自動補正

自動コントラストは画像のコントラストを、自動レベル調整はRGB各成分を調整する。選択範囲だけを処理する場合、8 BPP以下は24 BPPへ変換する。結果が適切でなければUndo後に手動レベル調整を行う使い方が案内される。[画像メニュー](http://www.massigra.net/massigrahelp/currentver/m_image.htm)

### 6.2 レベル調整

| 項目 | 内容 |
| --- | --- |
| 入力黒点 / 白点 | 入力ヒストグラムの範囲を指定。範囲を狭くするとコントラストが強くなる |
| 入力ガンマ | 中間調。1.000より大きいと明るく、小さいと暗い |
| 入力ヒストグラム | 三角つまみをドラッグして黒点・ガンマ・白点を変更 |
| 出力黒点 / 白点 | 出力レンジを調整。範囲を狭めるとコントラストが弱くなる |
| RGB個別 | 各チャンネル別の調整へ切り替え |
| Red / Green / Blue | 個別モードで対象を選ぶ |
| プレビュー | メイン画像に結果を表示。表示時の拡大縮小は低画質 |
| 自動設定 | 個別モードと一括モードの両方について値を自動算出 |

RGB個別モードと一括モードは、それぞれ別の調整状態を持つ。一括時のヒストグラムは輝度ヒストグラムではなく、RGB各成分をまとめたもの。見やすさのために高さを倍率表示することもある。部分処理では8 BPP以下を24 BPP化する。

出力黒点・白点による白黒反転の条件は、原文の説明と実装時の通常の解釈が一致するかを実機で照合する必要があるため、数式として固定しない。[レベル調整](http://www.massigra.net/massigrahelp/currentver/d_level.htm)

### 6.3 明るさ調整

明るさ、コントラスト、ガンマを数値とスライダーで調整する。明るさとコントラストには0へ戻すボタン、ガンマには1.000へ戻すボタンがある。

ガンマのスライダーは、最小0.400、中間1.000、最大2.500という非対称な範囲。これをガンマ入力欄全体の上下限とまでは解釈しない。プレビュー中は低画質となり、部分処理では8 BPP以下を24 BPP化する。

明るくした後に同量暗くしても元へ完全には戻らない。[明るさ調整](http://www.massigra.net/massigrahelp/currentver/d_bright.htm)

### 6.4 色合い調整

色合い、鮮やかさ、明るさを調整する。元画像と処理後画像の縮小プレビューがあり、実際の結果と異なる場合がある。各値に0へ戻すボタンがある。

| 追加設定 | 内容 |
| --- | --- |
| 色彩を統一 | 対象を同じ色彩にする。色合い0〜360、鮮やかさ0〜100の範囲に変わる |
| グレイ化の方法 | 明度値の算出方法。鮮やかさを下げる場合と色彩統一時に関係 |

いわゆるHLS調整だが、単純なHLS変換とは結果が異なると説明する。部分処理では8 BPP以下を24 BPP化し、16 BPP以上でもRGB888でなければ24 BPPへ変換する。[色合い調整](http://www.massigra.net/massigrahelp/currentver/d_tune_hsl.htm)

### 6.5 ネガポジ反転とグレイスケール

ネガポジ反転は色を反転し、部分処理では8 BPP以下を24 BPP化する。

グレイスケールは単純なRGB平均ではなく輝度で計算する。説明上の式は`round(0.299R + 0.587G + 0.114B)`で、内部では整数演算用に変形する。画像全体を処理する場合、16 BPP以上は8 BPPへ変わる。選択範囲だけを処理する場合は24 BPPになる。[画像メニュー](http://www.massigra.net/massigrahelp/currentver/m_image.htm)

## 7 シャープとぼかし

### 7.1 ワンクリックのプリセット

| コマンド | 対応するパラメータ |
| --- | --- |
| シャープ | アンシャープマスク：半径0.6、強さ100、しきい値0 |
| シャープ 強 | 半径0.8、強さ200、しきい値0 |
| シャープ 輪郭だけ | 半径0.6、強さ150、しきい値15 |
| ぼかし | ガウスぼかし：半径0.4、透明度0 |
| ぼかし 強 | 半径0.8、透明度0 |
| ぼかし ソフト | 半径5.0、透明度65 |

いずれも加工後は24 BPPになる。[シャープとぼかし](http://www.massigra.net/massigrahelp/currentver/m_i_shbl.htm)

### 7.2 アンシャープマスク

半径、強さ、しきい値を数値とスライダーで指定する。半径は計算に含める周囲の範囲、強さは効果、しきい値は色の変化が大きい部分に限定する度合い。

大きな画像はプレビュー内を左ドラッグして移動でき、ドラッグ中は元画像を表示する。出力は24 BPP。[アンシャープマスク](http://www.massigra.net/massigrahelp/currentver/d_unshmask.htm)

### 7.3 ガウスぼかし

半径と透明度を数値とスライダーで指定する。半径を大きくすると強くぼかし、透明度を高くすると効果を薄くする。プレビューのドラッグ中に元画像を表示する方式はアンシャープマスクと同じ。出力は24 BPP。[ガウスぼかし](http://www.massigra.net/massigrahelp/currentver/d_blur_gau.htm)

## 8 減色と増色

BPPを変更する。ヘルプは8〜24 BPPの選択を説明するが、全ラジオボタンの値は文章で列挙していない。現在と同じBPPは選択不可となり、ホイールでも選択を変えられる。減色時の誤差拡散を有効にできる。

「最適なBPPにする」は、使われている色を変えずに必要なBPPへ整理する処理。例として24 BPP画像が256色以内なら8 BPP化する。すでに最適な場合、または1 BPP、16 BPP、32 BPPビットフィールドの場合は何もしない。

16 BPPは表示が荒くなる場合があり、MassiGraではBMPだけに保存できる。JPEG保存時には24 BPP化するため、先に減色してもJPEG用の情報量削減としては扱えない。[減色と増色](http://www.massigra.net/massigrahelp/currentver/d_coldepth.htm)

## 9 パレットと色の入れ替え

### 9.1 パレット編集

パレット画像のみで利用可能。パレットの色番号とRGB値を数値入力、スライダー、色選択ダイアログで変更する。パレット上の左クリックで選択色を変え、選択中の色は赤い枠で示す。

カーソルが指している色の情報欄と、選択中の色の欄は別。プレビューを備え、「適用」は画面を閉じずに変更を確定する。「適用」後はキャンセルしてもその変更を取り消さない。[パレット編集](http://www.massigra.net/massigrahelp/currentver/d_palette.htm)

### 9.2 RGBの入れ替え

RとG、RとB、GとBの交換と、3成分の循環入れ替え2種類を備える。メニュー表記は`R->G->B->R`、`B<-R<-G<-B`。

部分処理では8 BPP以下を24 BPP化する。ビットフィールド画像で交換対象成分のビット数が異なる場合も24 BPPへ変換する。[色の入れ替え](http://www.massigra.net/massigrahelp/currentver/m_i_swapcol.htm)、[全メニュー](http://www.massigra.net/massigrahelp/currentver/menulist.htm)

## 10 マスク処理

### 10.1 共通の性質

ここでのマスクは画素や色の並べ替え等で画像を隠す加工を指す。多くは同じ処理をもう一度行うことで戻せる。Mekoのように正順・逆順を使い分けるものもある。情報を不可逆に除去する加工としては扱わない。

JPEGに保存する場合は処理範囲を8の倍数にそろえないと、解除時の汚れが増える場合がある。GIFへ保存する場合は自動減色により戻せなくなる場合がある。8 BPPへ先に減色し、色を変更しないガラス、Win、色反転無効のFLを使う方法が案内されている。[マスク処理](http://www.massigra.net/massigrahelp/currentver/m_i_mask.htm)

### 10.2 マスクの種類

| マスク | 動作と設定 |
| --- | --- |
| 縦ガラス | 一定間隔の縦帯ごとに左右反転。間隔と端の余りの処理を設定 |
| 横ガラス | 一定間隔の横帯ごとに上下反転。縦ガラスと同じ設定を使用 |
| ネガポジ反転 | 指定したRGB成分の色反転 |
| XOR 0x80 | 指定したRGB成分へ排他的論理和0x80を適用 |
| RGB入れ替え | 設定した成分の入れ替え |
| Q0 | 縦ガラス、横ガラス、反転、XOR、上下反転、左右反転を組み合わせる |
| Win | 幅16ドットごとの縦線を固定順序で並べ替え |
| FL | 8ドットのマスを渦巻き状に並べ替え、条件に応じて色反転 |
| CP | コードで変わる並び順で8ドットのマスを並べ替え、色反転とR・G交換 |
| Meko 正順 / 逆順 | 16ドットのマスを専用乱数に基づいて並べ替え、色反転 |
| 虹色 | ブロック単位の虹色の変換 |
| マスクオプション | 一般設定のマスクページを開く |

縦・横ガラスは、標準では端の余りを反転しない。Q0ではXOR、上下反転、左右反転が標準で無効。縦ガラスと左右反転、または横ガラスと上下反転を併用する場合は、処理範囲がガラスサイズの倍数になる。

Winの並べ替え順は、元の線番号を0〜15とすると、`12, 8, 6, 15, 9, 13, 2, 11, 1, 4, 14, 7, 0, 5, 10, 3`。WinとXORはJPEG保存に不向きと説明される。

FLは色反転を無効化でき、有効な場合は8 BPP以下を24 BPP化する。部分範囲のネガポジ反転、XOR、RGB交換も8 BPP以下を24 BPP化し、RGB交換は成分ビット数の違いによる24 BPP化も行う。[マスク処理](http://www.massigra.net/massigrahelp/currentver/m_i_mask.htm)

### 10.3 CPマスク

CPコードは半角アルファベット16文字以下で、大文字・小文字を区別しない。同じコードを使って戻す。JPEGにコード暗号を読み書きする機能はない。

部分処理では8 BPP以下を24 BPP化する。ビットフィールドでRとGのビット数が違う場合も24 BPP化する。メイン画像での低画質プレビューに対応する。[CPマスク](http://www.massigra.net/massigrahelp/currentver/d_cpmask.htm)

### 10.4 Mekoマスク

同じ処理の繰り返しでは元に戻らず、逆の順を同じ回数行う。正順2回なら逆順2回で戻す。部分処理で8 BPP以下の場合は24 BPP化する。配布データの`mekorand.dat`を使用する。[Mekoマスク](http://www.massigra.net/massigrahelp/currentver/m_i_mask.htm)、[構成ファイル](http://www.massigra.net/massigrahelp/currentver/install.htm)

### 10.5 虹色マスク

ブロックサイズは1、2、4、8、16、32から選択。出力は24 BPP。JPEGへ保存する場合は8の倍数が案内される。低画質プレビューに対応する。元画像を隠す能力や圧縮効率に限界があるとの説明もある。[虹色マスク](http://www.massigra.net/massigrahelp/currentver/d_rainbow.htm)

## 11 加工による色形式の変化

| 処理 | 明記されている変化 |
| --- | --- |
| Simpleによるリサイズ | BPPを維持可能 |
| その他のリサイズ方式 | 24 BPP |
| 90度の倍数でない回転 | 24 BPP |
| 自動コントラスト、自動レベル、レベル、明るさの部分処理 | 8 BPP以下なら24 BPP |
| 色合い | 部分処理の8 BPP以下、またはRGB888でない16 BPP以上を24 BPP化 |
| ネガポジ反転、XOR、RGB交換の部分処理 | 8 BPP以下なら24 BPP |
| 全体グレイスケール | 16 BPP以上なら8 BPP |
| 部分グレイスケール | 24 BPP |
| シャープとぼかし | 24 BPP |
| 虹色マスク | 24 BPP |
| JPEG保存 | 24 BPPへ変換 |
| GIF保存 | 16 BPP以上なら8 BPPへ減色 |

この表は明記された条件の一覧であり、それ以外のあらゆる色形式で変換が起きないという保証ではない。加工中の内部画像、表示のBPP、ファイル内のBPPを同一視しない。[画像メニュー](http://www.massigra.net/massigrahelp/currentver/m_image.htm)、[各加工ダイアログ](http://www.massigra.net/massigrahelp/currentver/dialog.htm)、[仕様と制限](http://www.massigra.net/massigrahelp/currentver/specifi.htm)
