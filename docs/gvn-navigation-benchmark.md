# MassiGraとGVNの画像切替比較

画像の「次へ」「前へ」の処理時間を、専用のネイティブ計測で比較する。RustとC++の言語ベンチマークではなく、各ビューアの読み込み・一覧・キャッシュ・UI更新を含むアプリ動作の比較である。

## 条件

- 公式配布のMassiGra 0.45、配布済みGVN 0.8.0、開発中のRelease版を使う。本体のSHA-256を記録する。
- 各1024×1024 PNG、3840×2160 JPEG、3840×2160 PNGを10枚ずつ生成し、同一ファイルを同じ順序で開く。各画像には異なる中央色を設け、寸法・容量・SHA-256を保存する。
- 各アプリ・各画像組を3つの新規プロセスで試す。アプリの試験順を交代する。OSファイルキャッシュは消去しない。
- 1080×760の外形とフィット表示を使う。既定の隣接画像先読みは有効にしたままにする。GVNの2版には同じINIのスナップショットを渡す。ユーザーのINIへ保存しない。
- 連続切替と、操作前に250ms待つ切替を分ける。それぞれ9回前進し、9回戻る。1条件・1アプリで54回の操作となる。

`tools/benchmark_navigation.py 開発版GVN.exe --trials 3`で再実行する。画像は`.cache/navigation-benchmark/assets-v1`へ固定し、再実行時は全ハッシュを検査する。初回生成のノイズはランダムなので、同じ入力で再測定するには保存した画像とmanifest.jsonを使う。

## 計時の意味と限界

計時区間は実WM_COMMANDの配送開始から、対象ファイル名へのタイトル更新とUIスレッドの応答まで。GVNは読み込み結果を採用した後にファイル名を変える。実コピーによる画像の寸法と既知の中央色を、計時の外で検証する。初期画像と、測定後に別の画像へ進めたときの画素を確認する。

MassiGraは非対話環境のPrintWindowで画像を描画しなかった。このため画面取得の所要時間を共通の指標には使わない。モニタへ画像が実際に提示されるまでの時間、DWM合成、物理キーの入力遅延は測定していない。最終描画までの体感差を、この値だけで確定しない。

連続切替の各操作間には追加の待機・コピーを入れない。開始前には初期画像のコピー検証があるため、初期画像と先読みが温まった条件である。前進と後退の内訳も生データに残す。画像切替の中央値・95パーセンタイル・最小/最大を分け、起動と設定画面の待ち時間を混同しない。

起動時間はCreateProcess開始からメインウィンドウの表示フラグとUI応答までを補助値として記録する。設定画面も同じプロセスで3回開いて、設定ウィンドウとUI応答を検出する。非対話環境、参照本体の新しいコピー、OSキャッシュ等の条件があり、ユーザー環境での体感起動時間を保証する値ではない。

ファイルを指定しない空ウィンドウの起動、大量ファイルのある実フォルダ、キーを押しっぱなしにして読み込み要求が重なる場合も、この比較と別に確認する。開発版は記録した本体ハッシュに限る結果で、未配布の変更や以後の修正版の性能を証明するものではない。

## 隔離

可視フラグのないウィンドウステーションと専用デスクトップへ、計測用コピーの子プロセスだけを起動する。全操作のHWNDを作成したPIDと照合する。試験終了時に閉じる対象も、自分で作ったプロセスハンドルだけ。普段使っているMassiGraやGVNを操作しない。入力注入、ComputerUse、通常デスクトップのクリップボードは使わない。

コピーの検証には隔離したクリップボードを使い、他のGVN試験と共通ミューテックスで直列化する。公式EXEとDLL、ユーザーINIのスナップショット、生成画像はキャッシュに置き、GVN配布物には含めない。比較の生データと確定した集計値は検証記録にリンクする。

## 2026年10月18日 修正前の比較結果

27個の専用プロセス、972回の前後移動が成功した。各条件54操作。以下はmsで、中央値 / 95パーセンタイル。入力は生成素材であり、実写真一般の保証値ではない。

### 連続切替

| 素材 | MassiGra 0.45 | GVN 0.8.0 | GVN開発版（測定時点） |
| --- | ---: | ---: | ---: |
| PNG 1024×1024 | 28.6 / 34.8 | 23.3 / 39.4 | 23.4 / 36.7 |
| JPEG 3840×2160 | 117.0 / 141.4 | 175.4 / 200.4 | 185.6 / 316.8 |
| PNG 3840×2160 | 196.3 / 295.9 | 225.9 / 387.1 | 209.2 / 248.8 |

### 250ms間隔の切替

| 素材 | MassiGra 0.45 | GVN 0.8.0 | GVN開発版（測定時点） |
| --- | ---: | ---: | ---: |
| PNG 1024×1024 | 33.7 / 52.5 | 10.3 / 20.6 | 11.4 / 23.9 |
| JPEG 3840×2160 | 127.9 / 135.2 | 99.6 / 155.7 | 102.9 / 240.5 |
| PNG 3840×2160 | 213.6 / 501.0 | 118.0 / 132.2 | 118.1 / 142.7 |

連続切替のGVN 0.8.0は、4K JPEGでMassiGraの約1.50倍、4K PNGで約1.15倍の時間がかかった。250ms間隔では3種類ともGVNが速い。開発版も連続4K JPEGは改善できていない。中央値だけで速いと判定せず、連続切替と遅い回を補完する。

補助測定の中央値は次の通り。起動は画像指定・非対話のウィンドウ表示とUI応答で、空起動やモニタ表示の値ではない。

| 対象 | 起動（9回） | 設定画面（27回） |
| --- | ---: | ---: |
| MassiGra 0.45 | 65.2 | 74.5 |
| GVN 0.8.0 | 154.5 | 2610.1 |
| GVN development | 145.2 | 59.3 |

GVN 0.8.0の起動は約2.37倍、設定画面は約35倍。開発版の設定画面は同等まで改善しているが、起動は約2.23倍で残る。開発版は未配布で、将来の修正版と区別する。

[全計測・素材ハッシュ・個別サンプル](verification/2026-10-18-navigation-baseline.json)、[計測ツールの凍結と本体/ソース照合](verification/2026-10-18-navigation-baseline-provenance.json)を参照。

比較中に、先読みと通常の単一画像要求でキャッシュの識別値が異なる条件を見つけた。漫画のパラメータが不要な通常画像にも含まれていた。0.8.0から同じソースであることを確認した。デコード回数の再現試験は修正前に失敗し、単一画像の識別値から漫画専用パラメータを外した後に成功した。4通りの漫画パラメータで同一画像を再利用し、強制再読込では再デコードすること、見開きの左右順は独立に保つことを検査する。この表は修正前の値として固定し、変更後の速度を証明する値には使わない。起動時の設定読込も別途補完したが、追加の起動比較はユーザーの指示により省略した。
