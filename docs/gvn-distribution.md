# 利用者向けの配布ZIP

Windows 10/11 x64用の`GVN-<バージョン>.zip`を配布する。利用者はフォルダーごと展開し、`GVN.exe`を起動する。ソースを取得したり、開発ツールをインストールしたりする必要はない。

## 同梱するもの

| ファイル | 用途 |
| --- | --- |
| `GVN.exe` | アプリ本体。アイコンと必要な画像ライブラリを内蔵 |
| `gvn-manual.md` | F1・操作説明から開くガイド |
| `はじめに.txt` | 展開・起動方法と設定の保存先 |
| `app.ico` | 固定ショートカットのアイコン更新用 |
| `SHA256.txt` | EXEのチェックサム |
| `licenses/` | 使用ライブラリのライセンス、著作権表示、使用版 |

現在は計16ファイル。ライセンスと説明書も含め、ZIP全体を展開して使う。

## 同梱しないもの

ソースコード、仕様書・作業リスト、検証記録・スクリーンショット、テストデータ、ビルド中間生成物、デバッグシンボル、Git管理情報、開発者の設定・画像・クリップボード履歴は含めない。開発資料とテスト用ソースはリポジトリで管理する。

個人設定の保存先は`%LOCALAPPDATA%\GVN\settings.ini`。このファイルを配布ZIPへコピーしない。

## 作成

```powershell
powershell -NoProfile -File tools/package.ps1 -BuildDirectory ./build -SkipDailyUpdate
```

`dist/GVN-<バージョン>/`と同名のZIPを生成する。`-OutputRoot`で出力先を変更できる。`-SkipDailyUpdate`は開発者の日常用EXEの更新を省く。`-DocsOnly`では既存の配布EXEとビルドEXEの一致を先に確認し、本体を変更せず説明書などを更新する。

毎回空の一時フォルダーへ許可したファイルだけをコピーし、同梱リストと実ファイルの一致を確認してZIPにする。以前の出力フォルダーに余計なファイルが残っていても引き継がない。既存の生成済みフォルダー・ZIPは出力先の`.previous/`へ退避する。一時フォルダーの削除と移動先は、指定した出力先の内部であることを確認する。

Gitへの登録からは`.cache/`、`dist/`、`app/`、`docs/verification/`、個人設定などを明示的に除外する。ビルドしたアプリの配布にはZIPを使い、GitHubのソースZIPと区別する。

## 今回の確認（0.76.5）

ZIPは16ファイル・約1.3MB。現在の普段使い用と同じ検証済みEXEを使用し、アプリ本体は再ビルド・変更していない。

Windows PowerShell 5.1でパッケージを作成し、古い出力へ残した設定・検証画像・PDBが混入しないこと、旧フォルダーとZIPの内容を保持すること、DocsOnlyで不一致EXEを拒否すること、日本語の案内が正しく保存されること、ZIPのCRCと全ファイルの一致を確認した。

最終ZIPを別フォルダーへ展開し、そのEXEで主要10経路の専用自動試験を行った。隔離デスクトップを使い、ユーザーのクリップボード・設定・普段使い用EXEを変更していない。
