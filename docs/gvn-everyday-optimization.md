# 普段使いの追加最適化（0.74.0計画）

専用ブランチ `codex/everyday-optimization` で6項目を順に実装する。0.73.0配布版・設定・ユーザーのウィンドウを保持し、専用の非対話デスクトップと自動操縦で確認する。

- [x] 選択線・ペンの部分再描画。部分更新と全更新の画面一致、画像・Alphaを確認。
- [x] GIF/APNGの次コマ時刻に合わせるタイマーと、最小化中の表示更新抑制。再生時刻、反復、一時停止、復帰を確認。
- [x] リサイズ時の配置・状態更新の重複削減。ツールバー、ステータス、スクロール、DPIと画質復帰を確認。
- [x] コピー／OLE準備の重複削減。PNG・DIBV5・選択範囲位置・Alpha、受信側が後から読む場合も維持。
- [ ] 高画質縮小の非同期化。UI受付、最新要求優先、取消・画像変更・終了時の寿命、最終画質を確認。
- [ ] APNG／PSDデコードの一時メモリ削減。全画素・透明画素内RGB、合成・破棄・遅延、色深度と読み込み上限を確認。

計測は実装の影響範囲へ絞る。ファイル読み込み・CPU計算・描画・UIの応答・メモリを区別し、実測していない速度向上は断定しない。各段階の結果を残し、完了後に普段使い用 `G:\gvn\app\gvd.exe` へ反映する。

前半の関連結果は `.cache/everyday-0.74-ui5` と `.cache/everyday-0.74-transfer1` に保存。部分描画と全描画の画素一致、最小化中の再生位置・UI更新抑制、コピー・OLE再利用と無効化を確認した。非対話デスクトップの更新領域はOSに表示されないため、Appテストでは実際のInvalidateRect引数を記録し同じ領域をDirect2Dで描く。永続DC上の全画素比較は別に行う。

UI更新・リサイズの時間は実行時の変動が大きく、現段階では高速化率を断定しない。コピーの合成試料2048×1536（PNG・DIBV5・選択位置）の一時コミット増加は約76MBから44MBへ減った。最終段階で前後の全サンプルと配布確認を追記する。
