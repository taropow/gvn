# アニメ読み込み時の一時メモリ削減

0.34.0へ配布反映。旧配布0.33.0を保持し、まずGIFをコマ単位のライブラリ呼び出しへ変更した。2026-10-20のユーザー指示により、APNGとPSDの追加最適化は後回しにし、普段の操作の仕上げと配布反映を優先する。

## GIFの実装

圧縮データ・パレット・インターレースは従来と同じlibplumが解読する。元のヘッダーと、各コマの拡張・パレット・圧縮データを分離し、同時にデコード済みで持つ入力を1コマへ限定する。既存の合成キャンバス・前のキャンバス・表示用全コマは維持する。シーク、現在コマの保存/コピー/OLE、編集・Undoが使うImage APIは変更しない。

コマ数を先に数えて既存のRGBA総量上限を確認し、入力バイトを変更せず予約破棄値の表示方式・反復回数・遅延補正を維持する。最後の拡張も最終コマの検証へ含める。静止GIFの透明度OFFは従来のWIC経路を保つ。

## 検証

変更前のデコーダーで200条件・776コマの全RGBA SHA256、遅延、反復、補正フラグ、Image保持バイトを固定し、変更後に完全一致した。透明画素内RGBもハッシュへ含む。GIF公式参照を含む関連6検査、本体189件、専用6本1,798操作27画面が通過した。既存のテスト本文とアサーションを変更していない。

1024×1024・48コマ、RGBA192MiBの同じ合成試料で旧版/候補を交互に3回測定した。最初の実行順は旧→新、次は新→旧、最後は旧→新。各回に1個/2個を起動する。すべて専用の非表示デスクトップで正常終了した。[生データ・ソース・画面](verification/0.34.0-gif-framewise-related.json)に全サンプルを保存する。

| 起動数 | 旧・各プロセスのピーク中央値 MiB | 新 MiB | 削減 |
| --- | ---: | ---: | ---: |
| 1 | 391.37 | 203.07 | 48.11% |
| 2 | 391.38 | 203.02 | 48.13% |

単独3回の新ピークは203.04〜203.11MiBで、開発目標240MiB以下を満たした。単独の内部採用中央値は1778→1450ms、描画復帰までは1857→1516msだった。固定1080×760・既定Linear・Software描画の計器であり、プロセス生成/OLE/DWMを含む総起動時間ではない。実写真や物理画面の滑らかさへ一般化しない。
