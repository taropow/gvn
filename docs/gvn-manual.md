# GVN 操作説明

GVNの操作ガイドです。アプリアイコンは青いパネルに大きな白い「V」と四隅のフレームです。記載したキー・マウス操作は新規設定の標準値です。割り当てを変更した場合は、設定画面の「キー」「マウス」で現在の内容を確認してください。

## この説明書を開く

F1、上部ツールバーの「？」、または「その他 → 操作説明」で、このMarkdownファイルを開きます。メニューバーが見えない場合はF10で表示できます。

ファイル名は `gvn-manual.md` です。`gvd.exe` または `GVN.exe` と同じフォルダーに置いてください。Markdownに関連付けられたアプリで開き、関連付けがない場合はメモ帳で開きます。説明書の表示中もGVNを使えます。

## まず画像を表示する

- Ctrl+Oでファイルを選ぶか、画像・ZIP・フォルダーをGVNへドロップします。
- 画像が開かれていないキャンバスをクリックすると、クリップボードの画像または対応ファイルのフルパスを貼り付けます。
- Ctrl+Vでも貼り付けられます。対応する内容がない場合や読み込めない場合は何もせず、表示中の画像を保ちます。
- Ctrl+Wで画像を閉じます。画像がない画面には市松模様と操作案内を表示します。

### 対応形式

PNG、APNG、GIF、JPEG、BMP、TIFF、ICO、PSDを読み込めます。GIF・APNGはアニメーション再生に対応します。ZIP内の対応画像も表示できます。

PSDは、ファイル内に保存された合成画像を表示します。8／16bitのRGB・グレースケールと透明度に対応します。合成画像のないPSD、CMYK、32bit、PSB、およびレイヤーの表示切り替え・PSD形式での保存には対応していません。16bit PSDも表示・加工時は8bit RGBAへ変換します。

## 画面の見方

| 場所 | 主な役割 |
| --- | --- |
| 上部のアイコン | 開く・保存・コピー・貼り付け・画像送り・ズーム・編集モード・設定・操作説明など |
| 左端のツール列 | 編集モード中の手のひら・ペン・文字・選択・移動・トリミングなど |
| 画像の下のプレイヤー | アニメーションの再生・一時停止・コマ送り・シーク・ループ |
| 最下部のステータスバー | 寸法・色深度・倍率・容量など。画像があればドラッグ欄・出力名・形式も表示 |
| 右上の通知 | コピー・貼り付け・保存などの受け付け・完了を通知 |

ツールバーのアイコンにマウスを置くと説明が出ます。狭いウィンドウでは「…」から補助機能を開けます。画像情報や倍率のステータス欄をクリックして、詳細表示・数値ズームを開くこともできます。

## 画像を送る・一覧を移動する

| 操作 | 標準の入力 |
| --- | --- |
| 前の画像／次の画像 | ←／→ |
| 10枚前／10枚先 | PageUp／PageDown |
| 先頭／末尾 | Home／End |
| 左ボタンを押したまま次／前へ | ホイール上／下 |
| プレビュー付きジャンプ | J |
| 親フォルダー | Backspace |
| 前／次のフォルダー | Ctrl+PageUp／Ctrl+PageDown |
| 再読み込み | F5 |
| スライドショー開始・停止 | F8 |

並び順、逆順、自然順、フォルダー末尾での動作、スライド間隔などはメニューや設定で変更できます。スライドショー中のEscは停止に使います。

## 拡大・縮小・表示移動

| 操作 | 標準の入力 |
| --- | --- |
| ウィンドウに収める | 0 |
| 原寸表示 | 1 |
| 拡大／縮小 | ホイール上／下、＋／－ |
| 画像の表示位置を動かす | 閲覧時の左ドラッグ |
| 一時的な手のひら | Spaceを押したまま左ドラッグ |
| 全画面の切り替え | F11、左ダブルクリック |
| メニューバーの表示切り替え | F10 |

ホイールのズームはマウス位置を中心に行います。Spaceを離すと元のツールへ戻ります。手のひらは画像そのものを編集せず、表示位置だけを動かします。

表示品質は「無補正（最近傍）」「高速（Linear）」「高画質（Lanczos3）」から選びます。縮小と拡大、通常表示と全画面の設定を確認してください。操作中に軽い表示へ切り替わる設定では、操作終了後に指定品質へ戻ります。

## コピー・貼り付けと透明度

Ctrl+Cで表示画像または選択部分をコピーし、Ctrl+Vで貼り付けます。透明・半透明の画像ではAlphaを保持し、透明部分の下に市松模様を表示します。市松模様や選択線はコピーする画像へ描き込みません。

- クリップボード内の画像データを、同時に含まれるファイルパスより優先します。
- 対応画像のフルパスや、エクスプローラーでコピーしたファイルも開けます。
- 貼り付けに使える内容がない場合は、エラーダイアログを出さず何もしません。
- 透明度を受け取れる画像ソフトへは、透明度付き画像として貼り付けられます。相手側の受け取り形式にも依存します。
- CLIP STUDIO PAINT由来の対応するラスターデータも読み込めます。GVN内の画像は1枚にまとめられ、元のレイヤー構造を編集するものではありません。

### 選択範囲でペースト

「選択範囲でペースト」は、貼り付ける画像をすぐに合成せず、移動・拡縮・回転できる仮置きにします。

1. 画像を開き、コピー元で貼り付けたい内容をコピーします。
2. 「選択範囲でペースト」を実行します。
3. 枠内のドラッグで移動し、ハンドルで大きさ、枠外のドラッグで角度を調整します。
4. 上部の数値欄でも位置・サイズ・角度などを調整できます。
5. 「適用」またはEnterで確定し、「キャンセル」またはEscで中止します。

対応する位置情報が含まれる場合は、その位置を初期配置へ使います。一般の画像クリップボードすべてがコピー元のキャンバス位置を含むわけではありません。

## 画像をファイルとしてドラッグする

ステータスバーの「ドラッグ」欄から、エクスプローラーのファイルと同様のOLEドラッグを開始できます。

1. 「ドラッグ」の右のファイル名欄へ名前を入力します。
2. その右の形式欄で、PNGなどの出力形式を選びます。
3. 「ドラッグ」欄を押して、受け取り先の画像編集ソフトやフォルダーへドラッグします。

開いたとき・貼り付けたときの初期名は `imageYYYYMMDD_HHMMSS` 形式です。名前を入力し直した後は、ズームや編集で勝手に戻しません。

Ctrl+Shift+D、F6、Alt+左ドラッグによるファイルドラッグも利用できます。透過を渡す場合はPNGを選んでください。JPEGは透明度を保存できません。GIF／APNGの画像コピーや編集画像のファイル出力は、現在表示中のコマが対象です。受け取り先もファイルドロップに対応している必要があります。

## 画像編集モード

上部の鉛筆アイコンで編集モードへ切り替えます。左端に編集ツールが現れ、もう一度押すと閲覧UIへ戻ります。

### 選択範囲

矩形選択、自由選択、折れ線選択を使用できます。矩形は対角のドラッグ、自由選択は輪郭をドラッグ、折れ線選択はクリックで頂点を置いて輪郭を作ります。

- 選択ツールでShiftを押して追加、Altで除外、Ctrlで交差を指定できます。
- 全選択はCtrl+Aです。選択の解除・反転・選択範囲の削除は選択関連メニューから実行できます。
- 黒白の破線は流れる表示です。拡大・縮小しても画面上の線幅は1pxです。
- 選択済みの画素内を修飾キーなしでドラッグすると、選択部分の移動・自由変形を始めます。
- 変形中は枠内で移動、ハンドルで拡縮、枠外で回転します。「適用」／Enterで確定、「キャンセル」／Escで中止します。
- Ctrl+Yは、選択範囲を切り出す操作です。

選択の削除と、元ファイルをごみ箱へ移すDeleteキーは別の操作です。必要に応じて設定の「キー」で選択範囲の削除へキーを割り当ててください。

### ペン

左のペンツールを選び、画像上をドラッグして描きます。上部で色や太さを変更できます。「詳細」を開くとフチ・ドロップシャドウの色や太さ・ずれ・ぼかし・濃さを調整できます。

### 文字入れ

左の文字ツールを選び、画像上で位置を指定します。文字欄に入力し、フォント・サイズ・色を調整します。フチとドロップシャドウも使用できます。「適用」で画像へ確定し、「キャンセル」で取り消します。

### トリミング

左のトリミングツールを選び、画像上の枠で切り抜く範囲を指定します。外側は暗く表示され、ハンドルで大きさ、ドラッグで位置を調整します。上部の数値欄でも位置・サイズ・角度・基準点・拡大率を設定できます。

「適用」またはEnterで切り抜き、「キャンセル」またはEscで元の画像へ戻ります。

### 画像サイズ・キャンバスサイズ

画像サイズ変更は画像そのものの寸法を変えます。キャンバスサイズ変更は、周囲の余白を増減します。

キャンバスの基準点は3×3のマスから選びます。青いマスが現在の基準点です。透明な余白を追加する場合は透明設定を使ってください。

### 色・明るさと各種加工

画像メニューから回転・反転、明るさ／コントラスト／ガンマ、レベル調整、色合い、グレイ化、ぼかし、シャープ、減色などを使用できます。選択範囲がある場合は、その範囲を対象にできる加工があります。

共通の色選択では、外側のリングで色相、中央の四角で彩度と明度を指定します。RGB・HSV・16進数でも入力できます。OKで反映し、キャンセルで取り消します。

### 元に戻す・やり直し

Ctrl+Zで元に戻し、Ctrl+Shift+Zでやり直します。履歴は最大32段階で、画像サイズやメモリ量により少なくなる場合があります。

初期状態では、編集後に画像を切り替える際の「保存しますか？」確認を表示しません。確認が必要な場合は設定で未保存変更の確認を有効にしてください。

## 保存とファイル操作

- Ctrl+Sで保存、Ctrl+Shift+Sで別名保存します。
- 透明・半透明をそのまま保存する場合はPNGを選びます。
- JPEGや通常のBMPは透明度をそのまま保存できず、保存時の背景色へ合成されます。
- アニメーションを加工した場合は現在のコマを静止画像として扱います。元のアニメーションを静止画像で上書きする操作は制限されます。
- PSDを読み込んでもPSD形式での保存はできません。加工結果はPNGなどへ保存してください。
- F2で名前変更、Deleteでごみ箱へ移動、Shift+Deleteで直接削除します。直接削除のキーは古い設定では未登録の場合があります。
- ファイルのコピー／移動先や外部アプリは設定で登録できます。
- Ctrl+Pで印刷画面を開きます。プリンター、用紙、倍率、余白などを確認して印刷してください。

## アニメーション

GIF／APNGを開くと下部にプレイヤーが現れます。再生・一時停止、停止して先頭へ、前後のコマ、先頭・末尾のコマ、シークバー、ループを操作できます。

[キーで前のコマ、]キーで次のコマへ移動します。Spaceの標準割り当ては手のひらです。再生キーを設定したい場合は設定の「キー」で変更してください。

ループ設定では、無限再生とファイル内の繰り返し回数に従う方式を選べます。ループOFFでは現在の周回の最後で止まります。コピー・保存・編集前に対象のコマを確認してください。

## プロンプト表示

上部ツールバーのプロンプト表示アイコン、または「その他 → プロンプト表示」で、現在の画像が持つ生成メタデータを開きます。

Rust Inpainter形式、一般的なPNGの生成パラメーターやComfyUI形式など、対応するメタデータがある画像で使用できます。全文・項目別の表示とコピーができます。画像の見た目からプロンプトを推定する機能ではありません。メタデータがない画像には生成情報を表示できません。

## 設定・右クリック・通知

設定画面はカテゴリとタブから項目を選びます。検索欄へ「ホイール」「透明」「dark」などを入力すると、該当項目へ移動できます。基本 → 全般でOS追従／ライト／ダーク、操作部の密度、通知や確認音などを変更できます。

- 「キー」でショートカットを追加・変更・解除します。現在の割り当ては、この説明書の標準値より設定画面を優先してください。
- 「マウス」でクリック・ドラッグ・ホイールや修飾キーの割り当てを変更できます。
- 操作 → 右クリックで、コンパクト／従来／カスタムを選び、項目や順序・区切りを変更できます。
- コンパクトな右クリックメニューは、空の画面、選択中、変形中、アニメーションなどの状態に応じて操作が変わります。「すべてのメニュー」から全体へ進めます。
- コピー・貼り付け・保存などの通知は右上に最低2秒表示します。確認音と通知は個別に切り替えられます。

通常の設定ファイルは `%LOCALAPPDATA%\GVN\settings.ini` にあります。アプリの更新時にも設定を引き継ぎます。

## 困ったとき

| 状態 | 確認すること |
| --- | --- |
| 貼り付けても変化しない | クリップボードに対応画像または既存の画像ファイルパスがあるか確認します。失敗時のエラーは表示しません |
| 透明部分が白くなった | 受け取り先のAlpha対応と保存形式を確認します。透明を保つ用途ではPNGを使用します |
| PSDを開けない | 合成画像を含む8／16bitのRGB・グレースケールか確認します。CMYK・32bit・PSBは未対応です |
| キーの動作が説明と違う | 設定の「キー」「マウス」で現在の割り当てを確認します。文字入力欄を編集中は入力が優先されます |
| 選択部分を動かせない | 実際に選択された画素の内側を、修飾キーなしでドラッグします |
| 編集を確定できない | 変形・トリミング・文字入れの「適用」「キャンセル」を確認します |
| 操作説明が見つからない | EXEと同じ場所に `gvn-manual.md` を配置します。配布フォルダー全体を展開してください |
| 更新後も前の動作になる | 起動中のウィンドウは前の版のままです。新しく起動して版を確認してください |
