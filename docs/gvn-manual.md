## 表示とズームのカスタマイズ

「表示」では中央/左上配置、初期フィット、フィット時の最大倍率、最近傍へ切り替える倍率を指定する。全画面中は中央配置を使う。最大倍率はフィットに適用し、原寸や手動ズームには適用しない。

通常フィットと全画面フィットは、それぞれ縮小方法と拡大方法を選べる。Simple、Linear、Integra、Hermite、Bell、B-Spline、Mitchell、Cubic-0.5、Lan2+0.25、Lan2+0.50、Lanczos3を利用できる。従来のCubic、Fant、高品質Cubicは「旧GVN」として保持する。旧設定も対応する項目へ自動移行する。[各方式の計算と制限](gvn-display-filters.md)を参照。

表示用の補間はコピーや保存のRGBAを変えない。キャッシュは見えている範囲だけを保持し、64MiBまたは寸法上限を超える場合は高速Linearに切り替え、ステータスへ表示する。原寸は補間せず表示する。

「ズーム」では手動ズームの縮小/拡大補間を別々に切り替える。補間ONはLinear。選択モードと、低画質設定ONのドラッグズーム中は最近傍を使う。ドラッグ解放や捕捉解除で元の画質へ戻る。「最近傍に固定」は手動ズームにも優先する。倍率による最近傍への切り替えは、フィット用と手動用を別々に指定し、100%未満の値では無効になる。

倍率の段階は「現在の倍率に対する割合」「一定の倍率差」「標準倍率の段階」から選ぶ。一定の倍率差では100%未満と100%以上の変更幅を独立指定し、100%をまたぐと一度100%に止まる。選んだ方式で使用しない入力欄は無効表示になる。ホイールも同じ段階を使い、マウス位置の画像座標を維持する。

「全画面表示」ではモニタ全体と作業領域の切り替え、カーソル非表示、待機カーソルも隠すかを設定する。ボタンを押している間はカーソルを表示する。通常と全画面の倍率・位置は別々に復元する。補間は生成素材に対する参照出力で照合しており、全画像の画素完全一致を保証するものではない。

長いパスは末尾側のファイル名が見えるようにする。文字は画像領域内だけに描き、コピー・保存・OLEで渡す画像へ焼き込まない。このページの「標準に戻す」はフォントと色も戻す。「適用」後のキャンセルは、その後の変更だけを破棄する。

## 画像のスクロールバー

表示 → ウィンドウ → スクロールバーで切り替える。設定 → バーでも通常表示と全画面を別々に有効化できる。画像が収まる軸では隠れ、拡大してはみ出すと現れる。横バーは画像の下、アニメーションでは再生バーの上に置く。

つまみと矢印で画像を移動できる。スクロールバーをクリックしてフォーカスがある時は方向キー、PageUp/PageDown、Home/Endでも操作する。画像のドラッグ移動や端への移動コマンドもつまみに反映する。フィットへ戻すと不要なバーが隠れる。スクロールは画像データを変更せず、コピーや保存には表示用のバーや市松を含めない。

## フォルダ移動・履歴・終端

リスト → 前／次のフォルダは、名前順で子フォルダもたどり、対応画像のない場所を飛ばす。「前隣／次隣」は同じ階層の一つ隣へ進み、空フォルダも選ぶ。親フォルダは一段上へ進む。空の隣や親へ移ると画像を閉じて市松表示へ戻り、移動先のフォルダを保持する。

設定 → 移動で、前フォルダ・前隣・親について先頭と末尾のどちらを開くかを別々に指定できる。既定は末尾。前後の探索と移動先の一覧作成・並べ替えはワーカーで行い、Escで中止できる。途中で別画像を開く、並び順や表示属性を変えるなどした場合は古い結果を採用しない。

「フォルダ移動で開いたフォルダも履歴へ追加する」は既定OFF。その場合も、別ファイルを明示して開く時と終了時には現在フォルダを記録する。全般の「最近開いたフォルダを保存する」をOFFにすると、いずれの履歴も保存しない。

「最後・最初に到達した時」は、停止、確認、同フォルダ内ループ、前後フォルダへの移動から選ぶ。途中からの大きなスキップはまず端の画像へ進み、すでに端ならこの設定を使う。確認画面では先頭／末尾、次／前フォルダ、キャンセルを選べる。この画面や自動終端から前フォルダへ進む時は、通常の前フォルダの設定に関係なく末尾を開く。音のON/OFFも独立して変更できる。

新規設定は終端確認・音OFFが既定。旧版の停止／ループ設定は引き継ぐ。漫画が右から左の場合、ツールバーの前／次だけを反転する設定があり、ボタンの絵とメニュー・キー割り当ての意味は変えない。このページの初期化は実装済みの移動項目を戻し、他ページの値を保つ。ジャンプのスクロールバー反転も、このページで変更・初期化できる。[仕様と検証範囲](gvn-folder-navigation.md)を参照。

## プレビュー付きジャンプ

Jまたは「リスト → 番号へジャンプ」で専用画面を開く。ファイル名、1から始まる順番、総数を表示し、番号入力と水平バーで画像を選ぶ。ZIP内の名前は内部パスを含む。長い名前は欄内で末尾まで確認できる。番号が範囲外ならOKは無効になる。

プレビューは既定ON、縮小画質は低・中・高の3段階で既定は中。透明部分は読み込み設定に従って市松へ重ね、アニメは先頭の静止1コマを表示する。読み込みは画面とは別に進める。プレビューをOFFにすれば、この画面での新しい画像読み込みを要求しない。OKで選択先とプレビュー/画質を確定し、キャンセルでは元の画像と設定を維持する。

「設定 → 移動 → 右から左の漫画モードでジャンプのスクロールバーを逆にする」が既定ON。漫画モードかつ右から左の場合だけ、バーの左端が末尾、右端が先頭となる。番号は1からのままで、解除すれば通常方向になる。[契約と検証範囲](gvn-jump-dialog.md)を参照。

## 透明画像と外部ソフトへの受け渡し

クリップボードはPNG、DIBV5、従来DIB、ビットマップの順に読み込む。透明度を明示したPNG/DIBV5はアルファを維持する。従来32bit DIBの未使用バイトは、透明度の指定がなければ不透明と扱う。

コピー時はPNGとDIBV5の両方を公開する。市松模様を画像へ焼き込まず、完全透明画素のRGBもPNGの往復では保持する。アニメは表示中の合成済みフレームをコピーする。選択範囲があれば、その範囲をコピーする。

選択のない貼り付けは既定で新規画像。設定 → 全般でOFFにすると、現在画像の左上へアルファ合成する。選択がある場合は、その左上へ合成し、選択の外を保持する。貼り付け元が大きい部分は選択内で切り詰める。常に新しい画像へ読み込む場合は「編集 → 新規画像として貼り付け」を使う。

OLEドラッグは次のいずれかで開始する。

1. Altを押しながら画像を左ドラッグする。
2. Ctrl+Shift+Dを押し、次に画像を左ドラッグする。
3. 編集メニューの「次の左ドラッグでファイルを渡す」を選び、画像を左ドラッグする。
4. F6、または上部の「ファイルドラッグ」アイコンを押し、画像を左ドラッグする。

未加工の静止画は元ファイルを渡す。クリップボード・加工済み・アニメの現在コマ・見開きは、アルファを保持したPNGへ書き出して渡す。コピー効果だけを許可し、ドラッグによる元ファイルの移動は許可しない。アニメを元ファイルごと渡したい場合はエクスプローラーから操作する。

一時PNGは`%TEMP%\GVN\drag`に作る。受け取ったソフトが後から読む可能性があるため、ドロップ直後や終了時には削除しない。不要になった一時PNGは、そのソフトを閉じてから整理できる。

Windows ShellのCF_HDROP、OSを通した自己ドロップ、実際に渡されたPNGの画素一致まで試験済み。CLIP STUDIO PAINTや他の編集ソフトそれぞれへの実ドロップは未確認。

倍率維持をONにすると、手動ズームだけでなく、フィット表示のその時点の倍率も画像切り替え後に維持する。通常表示と全画面の倍率・表示位置は別々に保持する。

## 対応形式と制限

| 入力 | 対応範囲 |
| --- | --- |
| PNG / JPEG / BMP | 静止画。PNGは透過。JPEGのExif方向を反映 |
| GIF | アニメ、部分フレーム、消去・復元、透明、フレーム遅延 |
| APNG | .png / .apng。OVER/SOURCE、dispose、除外する表紙。通常PNGは静止画 |
| PSD | 8/16bit RGB・グレーの保存済み合成画像。RAW/RLE/ZIP/ZIP予測 |
| TIFF / ICO | WICの標準デコーダ。先頭画像のみ |
| ZIP | 内蔵minizによる読み取り。画像データをメモリへ展開し、書庫内パスへファイルを書き出さない |

PSDのCMYK、PSB、32bit浮動小数点、合成画像のないファイル、レイヤー編集は未対応。PSDのチャンネル種別・合成透明度には実素材での追加検証が必要。カラープロファイルの厳密な色管理やメタデータを保持した再保存も未対応。

画像モデルの展開上限は256MiB。ライブラリの一時バッファ、表示用変換、GPU、Undo、キャッシュは別途メモリを使用する。アニメは上限内で全フレームを展開する。巨大アニメを無制限にストリーム再生する方式ではない。

ZIPの暗号化、未対応圧縮、書庫内書庫、書庫内の改名・削除は対象外。ZIP内の古い日本語名はCP932、UTF-8フラグ付きはUTF-8で読む。

0.39.0の画像情報は、現在のRGBA32BPPと元の色深度、DPI、印刷サイズ、ICC埋め込み有無を区別して表示する。[仕様と確認範囲](gvn-image-metadata.md)を参照。0.39.0へ配布反映済み。

0.39.0ではリサイズの実寸・DPI/解像度だけの変更、キャンバスの単位選択、DPI保存を追加した。[解像度と実寸指定](gvn-resolution.md)を参照。

## 加工と保存

画像メニューに回転、リサイズ、キャンバス、レベル、明るさ、ガンマ、色相・彩度、グレー化、シャープ、ガウスぼかし、アンシャープ、モザイク、RGB交換などを置く。色の加工やフィルタは選択範囲を指定できる。リサイズ・回転・キャンバスは全体を加工する。

0.38.0の「画像 → リサイズ」は幅/高さ/倍率、元の比率固定、半分/2倍、拡大と縮小を独立した11方式、縮小後シャープを指定できる。入力中は画像を処理せず、OK時だけ確定して設定を保存する。取消とUndo、現在コマと再生状態を保持する。[仕様と残る印刷DPI](gvn-resize.md)を参照。0.38.0へ配布反映済み。

内部はRGBA。リサイズとぼかしは透明度を考慮して色を計算し、透明画素の隠れた色が縁へにじまないようにする。0.38のキャンバスは9基準点と余白のRGB/Alphaを指定でき、初期値は透明。元画素のRGBAを合成せず移す。[仕様と残る単位対応](gvn-canvas.md)を参照。切り取り跡は既定で透明で、全般の設定で指定RGB色へ変更できる。任意角度の回転も透明な余白を生成する。

保存はPNG、JPEG、BMP、静止GIF。PNGは既定でアルファを維持する。保存画面のファイル種類を変更すると、その形式の設定が下へ表示される。PNGの圧縮/透過色、JPEGの品質/プログレッシブ、BMPの色深度/RLE、GIFの透過番号等を選べる。JPEG/BMPは指定背景色（既定は白）へ合成する。GIFはパレットへ変換するため、半透明と色の再現に制約がある。PNG以外へ透明画像を保存する前に確認を出す。

共通設定で元ファイルの日時保持、自動で付く拡張子の大文字、減色ディザを切り替えられる。保存に成功すると設定と前回形式を記憶する。キャンセルや保存失敗では以前の設定を保持する。ファイル名に別形式の拡張子を指定すると、その形式へ切り替わるので設定を確認してから再び保存を押す。[詳しい保存規則と制約](gvn-saving-options.md)を参照。

0.13.0では元パレットのあるPNG/BMP・全面の静止GIF等を読み込み、その番号を保存へ引き継ぐ。BMPの「元の色深度（自動）」は1/4/8ビットを保持し、2ビットは4ビット、RGBA画像は24ビットで保存する。元の同色別番号やPNGのパレット透過も保持する。色調加工や寸法の変わる滑らかなリサイズ等を行うとRGBAへ移り、古い番号を使わない。同じ寸法のリサイズは全RGBAと元の番号を維持する。Undoでは元の画像と番号を戻す。[保持できる操作と残る制約](gvn-indexed-palette.md)を参照。

新規画像・クリップボードから新規貼り付けした画像は未保存として扱う。新規貼り付けをUndoすると、元画像の参照先も戻る。保存後のUndoは、ディスクの画像と異なるため未保存の変更になる。

元の静止ファイルへの上書きは既定で確認付き。設定 → ファイル操作で上書き・削除前の確認を切り替えられる。アニメの加工は現在コマを静止画像へ取り出し、元アニメを上書きしない。PSDはPSD形式に保存しない。見開きと加工したアニメの画像は元ファイルへの直接保存対象から外す。

見開きの組は表示メニューから1枚進める・戻す操作ができる。横長単ページは現状では固定動作。

## ファイル読み込みの設定

設定 → ファイル読み込みで、BMP/GIF/PNG・APNGの透過、GIF/PNGの背景色、合成色、GIFの先頭コマ読み込み、JPEGのExif回転を選ぶ。隠し・システム・両属性の画像を一覧へ含めるかも独立して指定できる。

既定は「アルファを保持」がON。OFFにすると有効な透過を背景色と合成する。形式別の透過をOFFにした場合は、透過部分の元の色を不透明にする。GIFアニメ表示中はGIFの透過設定に関係なく透明情報を利用する。背景合成は元ファイルを書き換えないが、その読込結果を保存・コピーすると合成済みの画像になる。

設定の適用は未編集のファイル画像を読み直す。編集中の画像やクリップボード画像は置き換えない。クリップボードの貼り付けとコピーでは、ファイルの読み込み設定に関係なくアルファを維持できる。[適用条件と試験範囲](gvn-loading-options.md)を参照。

## 整理と設定

コピー先10件と移動先10件を別々に、外部アプリを9件登録できる。設定 → ファイル操作の下部で「コピー1〜10」「移動1〜10」を選び、直下のパス欄を編集する。「登録先へ振り分け」のメニューや割り当てたキーは、登録済みなら画面なしで処理する。未登録の番号は専用画面の該当欄を選んで開く。[登録と旧設定の引き継ぎ](gvn-destinations.md)を参照。

ファイル → コピー／移動は、フォルダを入力する基本画面を開く。「10個登録」をONにすると10個の入力欄と番号ボタンへ切り替わる。基本のコピー／移動ボタン、各番号ボタン、入力欄のEnterで処理する。「参照」は最後に選んだ欄へフォルダを設定する。ホイール上で前、下で次の欄を選ぶ。1個のフォルダのドロップでも入力できる。画像ファイルや複数のフォルダのドロップは受け付けない。相対パスは画面に示す元画像のフォルダが基準。引用符で囲まれたパスも使用できる。

基本／10件を切り替えても入力中の両方の値を保つ。決定すると基本パス、10件、モード、上書き確認をコピー用／移動用へ別々に保存する。キャンセルや閉じるでは今回の入力を捨て、空欄・存在しない送り先では画面を閉じず訂正を求める。送り先を確定した後の上書き拒否ではファイルを変更せず、確定済みの登録は保持する。[画面と検証範囲](gvn-transfer-dialog.md)を参照。

同名ファイルへの上書き確認はコピー・移動で独立する。確認ONでは許可した場合だけ、OFFでは確認を挟まず置き換える。元と先が同じファイルの場合や、書き込みができない場合はエラーになる。削除は既定で確認後にごみ箱へ送る。外部アプリへはファイルパスを引数として渡す。

設定は全般、背景、ウィンドウ、表示、ズーム、全画面表示、バー、移動、ファイル操作、ファイル読み込み、マスク、キー、マウス、マウス割当、スライド、外部アプリの16タブ。「適用」は保存して反映し、「キャンセル」は最後の適用後の変更を破棄する。「このページを標準に戻す」は、そのページの現在の項目だけを戻す。元に戻すをOFFにすると、直前画像を保持するメモリを節約する。

ファイル操作ページを標準へ戻すと、ページ内の10設定と登録先20件が初期値になる。別ページや形式別保存画面の設定は保持する。適用前ならキャンセルで初期化も取り消せる。適用後にキャンセルした場合は設定の変更を保持し、未登録番号から開いたファイル操作自体は実行しない。

各ページは最初に選んだときに生成する。開いていないページの値も保持する。タブを往復しても編集中の値は失われない。[設定画面の応答時間と回帰試験](gvn-settings-responsiveness.md)を参照。

背景全体のタイル・2色・5段階サイズ、独立した透明部分の2色とセルサイズ、タイトルのフルパス、最前面、初期フィット、ズーム増加率、スキップ枚数、履歴保存、アニメ自動再生、全画面の補間などを変更できる。16タブに元の全項目が揃った状態ではない。旧ラスタ/縦書きフォント、移動・整理の詳細、外部アプリの引数等の残りは[設定対応表](gvn-settings-matrix.md)で確認できる。

設定は`%LOCALAPPDATA%\GVN\settings.ini`へ保存する。検証などで分離する場合は`GVN.exe --settings "設定ファイルの絶対パス" "画像パス"`も使える。印刷と壁紙には確認・ダイアログを設けるが、実プリンタ出力や壁紙変更の実機試験は未実施。

MassiGraの全機能・全設定を完全再現したものではない。旧式マスク、表示専用の条件付き回転、パレットの直接編集、移動やファイル整理の設定などの残りは[対応表](gvn-feature-matrix.md)に明記する。

実装した範囲と試験方法は[実装監査](gvn-implementation-audit.md)に記載している。実機未確認の項目を、自動試験だけで完了扱いにはしていない。

## マウスの自由割り当て

設定 → マウス割当で操作、押しているボタン、修飾キー、機能を選ぶ。左・右・中・X1・X2のクリック、ダブルクリック、ドラッグ、縦横ホイール、ホバーを設定できる。「右を押しながら左クリック」などの併用も指定する。割り当て表の行を選んで編集することもできる。

未指定の条件は、修飾なし・他ボタンなしの操作を引き継ぐ。「何もしない」はその条件を明示的に無効にし、「標準操作を引き継ぐ」は個別指定を外す。ドラッグには画像移動、ズーム、範囲選択、ファイルとしてOLEドラッグ、左ボタン専用のOS標準ウィンドウ移動を指定できる。同じ併用・修飾条件で同じドラッグ機能を複数ボタンへ指定すると拒否する。

OS標準ウィンドウ移動を左ドラッグへ割り当てると、左クリックと「左を押しながら」の操作は無効になる。ウィンドウ枠上のX1/X2は、カスタマイズに関係なく前後画像へ移動する。クリックとダブルクリックの両方を設定した場合、最初のクリックが先に実行される。

設定 → マウスでは、ホイール量、ドラッグ量、ドラッグズーム速度・方向、クリックとドラッグを分ける余裕、ホバー余白・最小移動量、アクティブ化クリックの抑止、ホイールを鈍くする設定を変更できる。「マウス」と「マウス割当」の標準復元は別々に行う。

表示 → ホバースクロールで、押しボタンなしのマウス移動による画像スクロールを切り替える。余白は位置判定の上下左右へ適用し、50%では移動しない。ホイールは細かな入力を蓄積し、通常は1刻み、鈍くする設定では2刻みで1操作にする。

キー・マウスへは、上下左右・端・隅・中央へのスクロール、ランダム移動、原寸とフィットの2通りの切り替え、漫画の読み方向に合わせた前後左右、各ポップアップメニューも登録できる。

## 他のアプリで開く

ファイルメニューの「他のアプリの設定」で9枠を編集する。番号を選び、メニュー名と実行ファイル、送る内容を指定する。名前を空にするとメニューから隠れ、上下ボタンはその枠の全項目を移動する。「この番号を初期状態に戻す」は現在の番号だけを戻す。

「現在のファイル」は編集前の元ファイルを渡す。「画像をクリップボードへコピー」は現在コマ・選択範囲を透明度付きでコピーする。「表示中の画像を送る（従来のGVN）」は未加工の静止画なら元ファイル、加工/匿名/アニメ等なら表示全体のPNGを一時出力する。クリップボードへコピーする方式は、相手側で貼り付け操作を行う。

引数は`"C:\Editor\editor.exe" "($f)"`のように指定する。`($f)`は表示元ファイル、`($d)`はフォルダ。空白を含むパスは利用者が引用符で囲む。実行ファイルだけを引用符で囲んだ場合は自動で送信対象のパスを追加し、その後に引数を書いた場合は自動追加を止める。相対実行パスはGVN.exeのフォルダが基準。起動状態・アクション・区切り等の[詳細と確認範囲](gvn-external-app-options.md)を参照。



## バージョンを確認する

0.37.0では「その他 → バージョン情報」で、実行中の版番号と実行形式を確認できる。WindowsのGVN.exeのプロパティにも同じ版番号が入る。[仕様と確認範囲](gvn-about-version.md)を参照。0.37.0へ配布反映済み。

0.62.0では左ボタン＋ホイール上が次の画像、下が前の画像。選択内の素のドラッグで移動・自由変形を開始する。[詳しい操作](gvn-selection-interaction-0.62.md)。
