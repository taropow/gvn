## 参照で確認した出力

[公式0.45の実観測](verification/file-name-clipboard-reference-0.45.json)は、日本語・空白・複数のピリオドを含む生成PNG、加工後、別名保存後の3状態×5種類で15出力を確認した。ファイル名は拡張子を含み、フォルダパスに末尾の区切りを加えない。加工とコピー保存の後も元ファイルの名前を使う。ショートパスはWindowsの `GetShortPathNameW` の結果に一致し、このボリュームでは長い名前もそのまま残る。実際の8.3別名が作られる環境まで検査した意味ではない。

ファイルを持たない貼り付け画像の5出力も観測した。参照はファイル名とフルパスに仮の文書名「名称未定-1」を使い、フォルダ名とフォルダパスには直前のフォルダを使う。ショートパスを取得できない場合は、クリップボードを空にした。参照で最初に試した「開く」ダイアログ経由の移動は失敗原記録を残し、成功証拠から除外した。成功観測では、生成した日本語パスを起動引数に渡して実メニューを操作した。

## GVNの実装契約

| 操作 | 出力 |
| --- | --- |
| ファイル名 | 表示元ファイルの拡張子を含む名前 |
| フルパス | 表示元ファイルのフルパス |
| フォルダ名 | 表示元フォルダの最後の名前 |
| フォルダパス | 表示元フォルダのパス。末尾の区切りは加えない |
| ショートパス | Windowsが返す短いパス。取得できなければクリップボードを空にする |

5操作はメニューとキー・マウスの割り当てへ接続する。既存の「パスをコピー」も利用可能にする。日本語をUnicode文字列としてコピーし、コピー失敗時はエラーを返す。画像の画素、選択、変更済みの状態、Undoと読み込み要求を変更しない。通常の画像コピーはAlphaを保持する。

読み込み中は、現在表示している画像の元ファイルを使う。移動先のデコードが終わる前に、その移動先の名前をコピーしない。コピー操作で進行中の読み込みを取り消さない。

貼り付け画像のファイル名とフルパスは、GVNが表示している文書名「クリップボード画像」を使う。参照の連番付き仮名とは表示名が異なる。匿名画像への置き換えでは直前のフォルダを文字列コピー用の文脈として保ち、UndoのON/OFFと往復でも失わない。初回で元フォルダがなければ作業フォルダを使う。元ファイルを持たない画像のショートパスは取得できないため空にする。

ZIPはGVNの拡張機能であり、既存のフルパスコピーに合わせて書庫ファイルを表示元にする。ファイル名はZIPの名前、フォルダはZIPのあるフォルダを返す。通常画像・ZIPとも、画面表示中に元ファイルが消えた場合も画像を保ち、取得できないショートパスでは参照と同じ扱いにする。
