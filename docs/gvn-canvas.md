# キャンバスサイズ

0.39.0へ配布反映済み。[今回の配布確認](verification/0.39.0-daily-use.json)を参照。以下には開発時点と旧版の記録も含む。

0.39.0では[解像度と実寸指定](gvn-resolution.md)を追加し、関連確認が成功した。DPIの保存も関連確認済み。以下の0.38とメタデータ基盤の記録は当時の範囲として保持する。

0.38.0へ配布反映済み。「画像 → キャンバスサイズ」で余白を追加したり、画像の端を切り詰める。元画素を拡大・縮小する処理は行わない。[配布の確認範囲](verification/0.38.0-daily-use.json)を参照。

幅・高さをピクセルまたは元寸法に対する倍率で入力する。元の比率固定、入力中の寸法の半分/2倍、元と出力のRGBA量を表示する。各辺1～65,535px、RGBA1GiBと物理メモリ設定を確認し、不正入力ではOKを無効にする。入力中は画像処理や画素の確保を行わない。

9個の基準点を左上・上・右上・左・中央・右・左下・下・右下から選ぶ。初期値は中央。拡張時はその方向に元画像を寄せ、切り詰め時はその方向の範囲を残す。中央の奇数差分は従来と同じく、差分を2で割って0方向へ切り捨てる。マウスとキーボードで指定できる。

余白は初期値で透明RGBA(0,0,0,0)。透明をOFFにすると、赤・緑・青・Alphaを0～255で指定できる。標準の「色の設定」でもRGBを選べ、Alphaは保持する。色の設定でキャンセルすれば変更を戻す。透明ONでは色入力を無効にするが、選択内容は残す。Alpha0の色付き余白も、指定した隠れたRGBを保持する。

元画素は余白色と合成せずRGBAをそのまま転記する。透明・半透明、Alpha0の隠れたRGBやAlpha1のRGBも保つ。寸法が同じなら元パレットも維持する。寸法を変えた結果はRGBAとなる。画像処理成功時だけ、比率固定・基準点・透明ON/OFF・RGB・Alphaを保存する。取消と確保失敗では画像・Undo・選択範囲・設定を保つ。

アニメは画面を開いている間、現在コマを停止する。取消なら再生状態を復元し、確定時は確認して現在コマを静止画像にする。Undoで元のアニメとコマ・再生状態に戻す。元のアニメを直接上書きしない。
