# コピー・移動の登録先（0.14.0の基盤／0.15.0の専用画面）

0.15.0では[基本/10件の専用画面](gvn-transfer-dialog.md)を接続した。以下の0.14.0の検証は当時の記録として保持する。未登録番号からは、設定タブの代わりに専用画面の該当欄を選んで開く。設定タブの全20行は、ファイルを操作せず登録だけを編集し適用/取消する用途で引き続き使える。

MassiGraの[割り当て可能な機能](http://www.massigra.net/massigrahelp/currentver/custom.htm)と[10個登録](http://www.massigra.net/massigrahelp/currentver/d_cpymovex.htm)では、移動とコピーの送り先を別管理する。GVNの共通10件では同じ番号に別々の送り先を登録できなかったため、コピー10件・移動10件へ分離する。

## 実装する契約

1. ファイル操作タブにコピー1〜10・移動1〜10を表示し、実リストと編集欄から全20枠を編集する。選択変更、適用、OKで最後の編集中の枠も確定する。キャンセルだけなら未適用の変更を捨てる。
2. `CopyDestinations`と`MoveDestinations`の各1〜10へ保存する。旧`Destinations`は新しいキーがない場合だけ両方の初期値として読む。明示した空欄は旧パスへ戻さない。旧セクションは消さず、旧版の設定も保護する。
3. コピーと移動の同じ番号が別フォルダを指せる。各10コマンドは同じ種類の登録だけを参照し、登録済みなら画面を挟まない。相対パスは元ファイルの所在フォルダを基準にする。上書き確認はコピー・移動で独立する。
4. 登録先コマンドは進行中の読み込みを取り消し、表示していた元ファイルを処理対象に確定する。未登録の番号を実行すると、ファイル操作タブの該当行を選び、編集欄が見える状態で開く。OKで空欄でなくなった場合だけ実行する。キャンセルや空欄でのOKでは汎用フォルダ選択もファイル操作も行わない。適用後のキャンセルは設定だけを保持する。
5. 「このページを標準に戻す」はページ内の10設定と両方の登録先20件を戻す。他ページの適用済み・編集中の値や形式別の保存画面の設定は、このページのリセット対象に含めない。

## 検証する項目

設定の専用試験で旧形式からの引き継ぎ、混在形式、明示した空欄、20個の別々の値、長いUnicodeパス、初期化後の再読み込みを照合する。App統合試験は全20コマンドで別々の実ファイルを処理し、コピー元の保持・移動元の消去・各送り先の全ファイルバイト・表示RGBAを照合する。

専用自動操縦29は実設定画面で全20枠を入力し、再表示、適用、キャンセル、別ページの編集中の値、リセットを検査する。未登録のコピー10・移動10が正しい行を開くこと、キャンセルと空欄、登録後の直接実行、全20件の実ファイルを検査する。ユーザーの設定、現在のクリップボード、既存画像は使わない。

最終ソースで全25項目、54統合ケース、29本・4,626操作・103画面が成功した。専用29は460操作・4画面で全20枠を検査する。適用してからキャンセルした場合も、設定だけを保持してファイルは処理しないことを確かめた。全10設定の初期化は、未保存確認OFFへの復帰も明示的に読む[補足53操作・2画面](verification/0.14.0-file-operations-reset.json)で再照合した。[最終段階の範囲](verification/0.14.0-destinations-stage.json)と[検証記録](gvn-verification.md)を参照。

最初の全25項目・53統合ケース・29本も成功したが、その後のコード確認で読込中の未登録送り先に競合を発見した。54番目の統合ケースを加えると、編集中にAからBへ採用される失敗を修正前に再現した。登録画面より前で読み込みを取り消すよう修正し、同じ試験ソースのままコピー/移動の両方と最終回帰が成功した。[修正前の再現範囲](verification/0.14.0-before-pending-load-fix/pending-load-reproduction-scope.json)を保持する。

初期の専用試験は、設定ダイアログの生成中にタイマーが再入し、表示前の欄を「見切れ」と判定した。画面の実際の可視状態を待つ処理を加え、29の関連試験で12回、最終回帰で11回の待機を記録した。表示後の該当行、欄の完全な表示範囲、入力フォーカスの検査は維持する。登録一覧の操作名の列幅と、ダイアログ表示後の初期フォーカスも補完した。

## 残る参照画面の差

0.14.0の段階は登録データと実コマンドの分離を扱う。MassiGraの基本/10件登録を切り替える専用のコピー・移動画面、10個の実行ボタン、フォルダのドロップとホイールでの入力フォーカス移動は引き続き補完する。当時S149とGOAL全体は、この基盤だけで完了にしていない。0.15.0の専用画面の範囲は上記の別契約と最終検証記録で管理する。
