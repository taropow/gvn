# コピー・移動の専用画面（0.15.0）

参照はMassiGraの[基本画面](http://www.massigra.net/massigrahelp/currentver/d_cpymov.htm)、[10個登録](http://www.massigra.net/massigrahelp/currentver/d_cpymovex.htm)、[直接割り当て](http://www.massigra.net/massigrahelp/currentver/custom.htm)。0.14.0のコピー10件・移動10件の独立データへ、専用のネイティブ画面を接続する。

## 実装と受け入れ条件

1. 基本画面はフォルダ入力、参照、上書き確認、10個登録への切り替え、コピー/移動の決定、キャンセルを持つ。相対パスは元画像の所在フォルダを基準とする。対象ファイルと基準フォルダを表示する。
2. 登録画面は10個の入力欄と各番号の実行ボタンを持つ。参照は最後に選んだ入力欄へ反映する。ホイール上で前の欄、下で次の欄へ移動し、端では止まる。半回転等は120単位へ積算する。Enterは現在の欄を実行する。
3. 基本と登録を切り替えても双方の編集中の値を保つ。閉じる/キャンセルは未確定の値を破棄し、ファイルを操作しない。決定時は両方の入力、モード、上書き確認をコピー用/移動用へ独立して確定する。基本画面のパスも次回へ保持する。初期値は基本表示・空パス・上書き確認ONとする。
4. 未登録番号からは登録画面の該当欄を選んで開く。登録済みなら画面なしで実行する。0.14.0の進行中の読み込みの取消と対象固定を維持する。
5. Explorer互換のCF_HDROPをOLEで受け取り、1個の実在フォルダだけを欄へ設定する。旧WM_DROPFILESも受け取る。画像ファイル、複数パス、範囲外の不正ブロックは設定しない。操作の効果はCOPYだけで、ドロップ自体では画像ファイルをコピー/移動しない。
6. 画面のサイズとDPIへ追従し、10行が収まらない場合はスクロールする。フォーカスを移した入力欄を見える位置へ出す。ダイアログを閉じた後に残ったOLE参照も無効なウィンドウや所有者へ触れない。

キャンセル時の確定方式や初期値は、ヘルプ未記載のMassiGraの動作を推定した値ではなく、GVNの操作契約として明記する。設定ページでは従来の純粋な登録編集と適用/取消も維持する。

## 検証順

まず画面部品だけで基本/10件の切り替え、全番号、参照と取消、相対パス、入力検査、ホイールの境界、サイズ/DPI、ShellのIDataObjectと実IDropTarget、WM_DROPFILES、OLE参照の寿命を検査する。その後Appへ接続し、設定の往復、独立した上書き確認、実ファイル、全20の直接コマンド、読込競合を検査する。

専用自動操縦はアプリと同じ実ダイアログを開き、実ボタン・入力・フォーカス・描画・OLEターゲットを通す。Shellのフォルダ参照の回答だけを代入する場合はその境界を記録する。直接OLEターゲットの照合と、Explorerからの物理操作による外部E2Eは区別する。ComputerUse/Skyとユーザーのクリップボードへの書き込みは使わない。
