# 起動位置と新規設定の既定値

0.33.0で実装・配布した仕様。起動設定の参照結果と実装・検証の範囲を記録する。

## 新規の既定値

| 項目 | 新規の値 |
| --- | --- |
| 起動時の位置 | 前回終了時の位置とサイズ |
| 保存済み位置がない初回 | 位置0,0、幅480、高さ360 px |
| ユーザー指定欄 | X=0、Y=0、幅480、高さ360 |
| 起動時の表示状態 | 通常 |
| 前回が最大化なら最大化 | ON |
| 前回が手動全画面なら全画面 | OFF |
| スライド間隔 | 5秒 |

所有する新しいMassiGra 0.45参照コピーを使い、画像なしと合成64×48画像の指定ありをそれぞれ実際に起動・終了・再起動した。4プロセスとも通常表示480×360、位置0,0だった。設定欄・初期化・保存された設定も照合した。[参照結果](verification/window-defaults-reference-0.45.json)を参照。

前回位置の保存がない場合、GVNは最初の表示前に初回の矩形を適用する。保存済み位置はWin32の作業領域座標として`SetWindowPlacement`へ戻し、ユーザー指定は画面座標として扱う。作業領域や必要なバーの寸法による補正は既存の処理を使う。

## 旧設定の保持

保存済みの明示値を、新しい既定値で上書きしない。「Windowsに任せる」、最大化復元OFF、1080×760や640×480の指定、3秒の間隔もそのまま読み込む。キーのない項目に新規の既定を使い、関係のない項目を初期化しない。

設定値の番号は既存INIとの互換のため維持する。

| 起動位置 | MassiGraの値 | GVNの値 |
| --- | --- | --- |
| 前回終了位置 | 0 | 1 |
| ユーザー指定 | 1 | 2 |
| Windowsに任せる | — | 0（従来の追加機能） |

| 起動状態 | MassiGraの値 | GVNの値 |
| --- | --- | --- |
| 通常 | 0 | 0 |
| 最大化 | 1 | 2 |
| 全画面 | 2 | 3 |
| 最小化 | — | 1（従来の追加機能） |

「現在の位置とサイズを取り込む」ボタンとユーザー指定欄は、ユーザー指定を選んだ場合に有効になる。最大化・全画面の復元チェックは起動状態が通常の場合に有効になり、別の状態に切り替えている間も選択値を保持する。

通常起動で前回の状態を復元する場合と、起動時に最大化・全画面・最小化を明示した場合を分けて処理する。スライドの一時全画面の除外は[自動スライドの仕様](gvn-slideshow-window.md)に従う。

「このタブを初期状態に戻す」は、そのタブの項目を新規の既定へ戻す。スライド間隔を戻す場合はスライドタブで初期化する。設定欄の変更だけでは、現在のウィンドウを起動時の位置へ移動しない。

## 検証

- 変更前の本体2件と設定1件が、初回矩形・最大化復元・新規既定の差で失敗することを確認した。
- 変更後は本体176件・設定49件が通過した。従来174件の本体テスト、従来48件の設定テストの本文を保持した。
- 起動位置・サイズの初期化について、専用シナリオ10の期待値を参照由来の値へ更新し、最大化復元ONの検査を追加した。その他の既存アサーションは保持した。
- 専用自動操縦8本・965操作・40画面が通過した。新規62の78操作では、既定値、実コントロールの依存、適用・取消・初期化、3秒の明示と5秒への初期化を確認した。
- 通常のGVN.exeを54プロセス・30条件で検査した。従来のスライド24条件に、新規・疎なINI・移動後の復元・最大化復元・旧Windows方式・旧ユーザー指定の6条件を追加した。
- 所有する非表示デスクトップ、個別INI、合成画像だけを使用した。ComputerUse/Sky、グローバル入力、DLL注入、API差し替えを使わず、終了後に別の通常プロセスを起動して確認した。

[検証結果とソース](verification/0.33.0-window-defaults-related.json)に、成功・変更前の差分再現・実プロセスの記録・画面・ハッシュを保存した。設定画面のキャプチャも確認した。

その後のスライド移動・ユーザー指定の補完でも、本体189件・設定51件、専用10本1,453操作44画面と通常133プロセス75条件が通過した。従来の起動54プロセス30条件へ追加し、公式の28矩形も通常EXEの初回・再起動で全件一致した。[最新の関連検証](verification/0.33.0-custom-window-related.json)を参照する。

全49検査・専用64本11,030操作232画面の[全体回帰](verification/0.33.0-startup-slideshow-regression.json)が通過した。S020/S026を実装済みへ更新し、古い設定説明3項目も修正・照合した。通常/軽量配布本体での検査も通過した。物理画面でのDPI・モニタ移動、大画像・多数起動の性能、実編集ソフト側の受信は別途検証する。起動速度の比較は今回の範囲に含めない。

ユーザー指定の入力・最小サイズ・複数画面の配置は公式38条件66プロセスで追加照合し、[入力と起動処理](gvn-window-customization.md)へ反映した。有効な正の寸法・符号付き座標、無効入力の値保持、静止画のWindows最小サイズ、仮想デスクトップと中央配置に対応する。アニメプレイヤーの最小寸法と旧INI破損値の復旧規則は維持した。

配布本体でも起動64・スライド13・参照矩形56プロセスが通過した。[0.33.0の配布検証範囲](verification/0.33.0-startup-slideshow-stage.json)を参照。
