# 画像の元情報と解像度

0.40.0開発版では[専用の画像情報と色数](gvn-image-info.md)を追加した。配布は0.39を保持する。以下はメタデータ基盤と以前の確認記録。

0.39.0へ配布反映済み。[今回の配布確認](verification/0.39.0-daily-use.json)を参照。以下には開発時点と旧版の記録も含む。

0.39.0では[解像度と実寸指定](gvn-resolution.md)を追加し、関連確認が成功した。DPIの保存も関連確認済み。以下の0.38とメタデータ基盤の記録は当時の範囲として保持する。

0.39.0開発版の「画像情報」は、現在の寸法・RGBA32BPPと、読み込み時の寸法・元の色深度を分ける。水平/垂直DPI、現在の寸法から計算した印刷サイズmm、ICCプロファイルの埋め込み有無も表示する。ファイル容量・展開後画素容量・読み込み時間・パス・更新日時の表示は保持する。現在の配布は0.38.0。

元の色深度は、PNGの色タイプ/サンプル深度、BMPの宣言値、GIFの最初の画像のパレット深度、PSDのチャンネル数×深度、JPEG/TIFF等のWIC元画素形式から得る。PSDの16bit4チャンネルなら元は64BPP、表示中の画素はRGBA32BPPとなる。パレットPNGの4BPPと展開後の32BPPも区別する。値が取得できない画像は元の色深度を「不明」とし、現在の32BPPを元の値として代用しない。

PNG/APNGのpHYs、BMPのpixels/meter、PSDのResolutionInfo、JPEGのJFIF/EXIF、TIFFの解像度タグから物理解像度を読む。PNG等の整数pixels/meterはDPIへ変換するため、300DPI指定で保存した試料でも実際は299.9994DPIとなり、画面では小数3桁の299.999と表示する。

[MassiGraの画像情報](http://www.massigra.net/massigrahelp/currentver/d_imginfo.htm)に合わせ、未指定なら印刷サイズ計算は72DPI。片方だけ0なら他方を両軸に採用する。負値・非数・無限大は採用しない。GIFやICOに実際の物理DPIがない場合、便宜的な96DPIを元ファイル指定値とは扱わない。JPEGのEXIF回転と90度単位の画像/表示回転ではDPIの縦横も交換する。

加工・リサイズ・キャンバス・現在コマの静止化で、読み込み時の寸法/元色深度とDPI/ICC情報を保持する。Undoでは元の画像と情報へ戻る。新規作成・元情報のないクリップボード経路では、未取得の元情報は不明となる。見開き合成は最初のページの情報を基準にする。

ICCはPNG/APNGのiCCP、PSDのICCリソース、JPEGのICCマーカー、BMP V5や既存WIC色コンテキストなどから埋め込み有無を確認する。今回はICCの適用による色変換やプロファイルの保存を追加していない。画像全体を二度デコードせず、元バイト列のヘッダーと既存デコーダーの情報を利用する。JPEG/TIFFなどの色コンテキストは[MicrosoftのAPI仕様](https://learn.microsoft.com/en-us/windows/win32/api/wincodec/nf-wincodec-iwicbitmapframedecode-getcolorcontexts)、PSDのヘッダーとリソースは[Adobeのファイル形式仕様](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)も参照した。

## 確認範囲と残差分

[確認記録](verification/0.39.0-metadata-related.json)に新しい単体5件、既存の形式テスト14件、本体関連4件、実画面の専用68/72で86操作・4画面を保存した。PNG/BMP/JPEG/TIFFの色深度・DPI・ICC、EXIFの軸交換、PSD/APNGのメタデータと元の全RGBA/フレーム/時間、パレット深度、未指定72DPI、片軸0、不正な値、加工時の情報保持を確認した。画面でも元/現在の表示、回転とUndo、24BPPと32BPP、ICC有無を照合した。

最初の新規画面期待値300.000を、PNGの実際の保存値に基づく299.999へ修正した。製品本体は変更せず、Appテストだけ再ビルドし、通過済みの単体19件は繰り返さなかった。失敗した記録も上書きせず保存した。既存194件の本体ケース本文と、既存14件の形式テスト本文を保持し、本体ケースを1件追加した。

使用色数の計算UI、フォルダ内の順番などの情報、解像度の編集/画素を変更しないDPI変更、印刷サイズやインチ/cmでの入力、DPI/ICC情報の保存は次段階。機能F044とF045/F046は一部対応を維持する。全体195件・CTest全体・専用72本全体・性能測定・実編集ソフト受信は今回行っていない。
