# GVN 0.62.0: 選択線・自動移動・手のひら

0.61.0の水色静止線は、今回の指定により黒白の動く破線へ変更する。選択領域・Alpha保持・編集モードの共通モデルは継続する。

## 操作仕様

| 操作 | 動作 |
| --- | --- |
| 選択線 | 黒白各4pxの破線を80msごとに1px進める。矩形・自由・折れ線・仮置きの枠で共通 |
| 線幅 | 画像倍率・Windows DPIに依存せず画面上の1物理px。作成中の輪郭も同じ |
| 選択範囲内の素の左ドラッグ | 実際の選択画素内から、設定のドラッグ開始距離を超えた時に移動ツールへ切り替え、選択画像を仮置きして自由変形を開始 |
| 範囲内をクリックするだけ | 選択画像を移動せず、選択を保持 |
| 自由選択の外接矩形内の未選択部分 | 移動を開始しない。選択の内外は共通のマスクで判定 |
| Shift / Alt / Ctrl付き選択 | 追加 / 除外 / 交差を優先し、自動移動を開始しない。ドラッグ開始距離を超える前に修飾キーを押した場合も同じ |
| 仮置き | 内部ドラッグで移動、8ハンドルで拡縮、枠外ドラッグで回転。Enter確定・Esc中止・数値入力・Undoを継続 |
| 左ボタンを押したままホイール上 / 下 | 既定で次の画像 / 前の画像。素のホイールは上が拡大、下が縮小 |
| Spaceを押したまま左ドラッグ | 一時的な手のひら。Spaceを離すと元のツールへ戻る。編集UIを勝手に切り替えない |
| 左ツール列の手のひら | 手のひらを継続して選択する |

手のひらでは表示領域より小さい画像も移動できる。従来は画像が小さいとスクロール可能範囲がゼロとなり、移動しなかった。手のひらで移動した表示位置を維持し、画像が完全に見失われないよう各軸に最大32pxを残す。原寸・フィット・別画像の読み込みで通常の表示配置に戻る。表示移動だけでは画素・Alpha・選択・Undo・変更状態は変えない。Spaceはキーリピートで再選択せず、キーを離すかフォーカスを失った時に解除する。仮置き中のSpaceも表示だけを動かす。

## 設定と互換性

新規設定ではSpaceを手のひら、左ボタン＋ホイールを次／前へ割り当てる。以前の標準値（Spaceが再生、左ホイールが上下スクロール）の組み合わせを使用しているプロファイルだけを一度移行する。独自割り当て・割り当て解除は保持する。移行済みマーカー保存後に利用者が旧割り当てへ戻しても、再び変更しない。

Spaceの一時手のひらは、現在のSpace割り当てが「手のひら」の場合だけ動作する。再生などへカスタマイズしたSpaceは、その割り当てを実行する。再生・一時停止は従来どおり下のプレイヤーから操作できる。

`MouseBindings.DefaultsVersion=3`、`KeyBindings.DefaultsVersion=1`を使用する。コマンドIDとクリップボード位置情報プロトコルは変更しない。

## 実装との対応

- `Renderer::draw_selection_lines`: 画面投影後の1px黒白破線。8位相のストロークを再利用。
- `App::sync_ants_timer`: 80msの表示更新。選択なし・最小化で停止。画像やマスクを作り直さない。
- `App::pointer_down` / `pointer_move`: 実選択のヒット判定、ドラッグ開始距離、修飾キー優先、既存の仮置き処理への接続。
- `App::drag_action` / キー処理: 一時手のひら、キー解除・フォーカス解除、継続手のひら。
- `View::x_range` / `y_range`: 手のひらでの小画像移動と通常スクロール範囲を扱う。スクロールバーも同じ範囲を使用。
- `Settings::load` / `save` / `default_bindings` / `MouseSettings`: 新規既定値と一度だけの互換移行。

## 確認範囲

専用の非表示デスクトップ・独立クリップボードで、実入力経路と実製品EXEを確認する。ComputerUse、利用者のクリップボード、起動中の別アプリは使用しない。今回に関係する領域だけを確認し、配布前に主要10経路を一度実行する。

- 黒白の交互表示、位相による画素の変化、25%・100%・400%と閲覧／編集UIでの1px幅、画像へ線が混入しないこと。
- 矩形・非矩形からの自動移動、クリックと微小移動の無変更、マスクの穴・修飾キーの除外、確定／中止／UndoとAlpha保持。
- 小画像のSpace／ツール列の手のひら移動、元ツール復帰、フォーカス解除、仮置き中の表示移動、独自Space割り当て。
- 左ボタン＋ホイールの実ファイル移動、素のホイールのズーム、旧設定移行と独自設定保持。

結果は配布時の検証記録へ保存する。後日予定の対話式トリミングや、別途残っている全GOALの外部連携確認とは分ける。

## 設定タブの遅延への対応

0.61.0ではページを初めて選んだ時にWindowsの部品を生成するため、タブごとに初回の待ちが生じる。さらに、再表示でも同じ部品の配置・列幅・表示状態を再設定していた。

0.62.0では、ページの大きさ・DPI・スクロール位置・表示項目の条件が同じなら配置を再利用する。サイズ変更・スクロール・漫画の揃え方で表示項目が変わった場合は再配置する。設定項目やカスタマイズ性を減らさない。ページ部品は非表示で作成し、配置後に表示する。コンボボックスの選択肢追加時も再描画をまとめる。

初回のWindows部品作成は残る。瞬時の初回表示を保証する変更ではない。専用の非表示デスクトップで、初回と再訪を分けて記録する。部品生成・フォント・配置の内訳は、開発用環境変数 `GVN_PREFS_TIMING` を明示した場合だけCSVへ記録できる。通常起動ではファイルを作らない。
