# 操作通知と確認音（0.75.0）

キャンバス右上に、同時に1つのトーストを表示する。重い処理の開始時は処理中、成功を確認した後は完了に置き換える。完了時には55msの小さな「ピッ」という音を鳴らす。

| 操作 | 完了表示 |
| --- | --- |
| 画像のコピー | コピーしました・画像寸法 |
| 貼り付け／新規貼り付け | 貼り付けました・画像寸法 |
| 選択範囲で貼り付け | 貼り付けを配置中・Enterで確定 |
| クリップボード内のパス | 非同期読み込みが完了してから、画像ファイルを開きました |
| 切り取り | 選択範囲を切り取りました |
| 保存／名前を付けて保存 | ファイル名と保存しました |
| Undo／Redo | 元に戻しました／やり直しました |
| 回転・サイズ変更・画像加工など | 操作名と適用しました |
| トリミング／自由変形／文字の確定 | 適用しました。ボタンとコマンドの両方に対応 |
| 編集の中止 | 編集を中止しました |
| パス／ファイル名などのコピー | コピーした種類を表示 |
| ファイルコピー・移動・名前変更・削除 | 実際に処理できた後だけ完了表示 |
| 再読み込み・一覧更新 | 更新が完了してから通知 |
| 外部アプリ・新しいウィンドウへ渡す | 起動要求が成功してから通知。受け手の読み込み完了は示さない |
| ドラッグ待機 | ファイルをドラッグできます・Escで解除 |

貼り付けの入力が空・未対応なら完了通知と音を出さない。画像デコードを試して失敗した場合は、処理中表示を消し、表示中の画像・Alpha・Undo・未確定編集を保持する。非同期読み込みの取消・失敗も完了扱いにしない。古い読み込み結果が新しい通知を上書きしない。通常のファイルエラーや保存確認の仕様は維持する。

「全般」の設定でトーストと確認音を個別にオン／オフできる。初期状態は両方オン。表示時間は2000〜10000ms、初期値2000ms。古い設定値が2秒未満でも、読み込み・保存・実際の表示で2秒以上へ補正する。「最前面・見開き・ループなどの表示切り替えも通知する」は初期値オフ。ズーム、画像送り、パン、アニメの各コマでは通知しない。ショートカットで実行した時は設定されたキーを併記する。

## 軽さと検証方針

完了通知は最初の描画が終わってから最低2秒表示する。連続操作では最新の通知に置き換え、置き換えた時点から表示時間を数え直す。処理中表示は完了・取消まで維持し、古いタイマーでは消さない。キャンバスを描き直した後は通知領域も描き直し、表示期限は延長しない。通知をオフにした場合や明示的な取消・終了は消去する。

初回通知時だけ小さな子ウィンドウを作り、その1つを再利用する。処理開始の描画は通知領域だけに行い、メッセージループの再入は行わない。通知は入力とフォーカスを透過する。終了タイマーは完了通知の間だけ存在し、消去・破棄後に停止する。フェードや待機中の定期描画は行わない。画像の書き出し・コピーへ通知は混ざらない。

確認音は自前で生成した55ms・1500HzのPCM WAVEをEXEへ埋め込み、[PlaySoundのリソース非同期再生](https://learn.microsoft.com/en-us/windows/win32/multimedia/playing-wave-resources)を使う。音が利用できない時は代替の警告音やエラーを出さない。音のAPIは最初の再生要求時にだけ読み込むため、無通知の起動には追加の音声DLLを読み込まない。150ms以内の連打音をまとめる。自動テストでは再生要求を数え、実際のスピーカーは鳴らさない。

関連アプリ14件、設定61件、専用2本104操作・4画面、配布本体主要10経路が通過。最終候補では通知関連8件を再確認し、変更のない設定・互換性の成功結果を継承した。埋め込みWAVEが元の合成音と一致し、起動時に読み込むDLLが増えていないこともPEのインポート表で確認した。実スピーカーでの聴取は未確認。
