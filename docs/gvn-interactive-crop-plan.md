# 後日追加: バウンディングボックスによるトリミングとサイズ変更

2026年10月21日のユーザー要望。0.64.0でトリミングの枠・8ハンドル・移動・回転・数値同期・9基準位置・出力倍率・適用/取消/Undoを実装した。[現在の操作](gvn-editor-mode.md)。自由位置の基準点と、既存リサイズ画面へバウンディングボックスを追加する作業は未実装。以下には当初の広い要件を残す。

## 必須要件

| 項目 | 必要な動作 |
| --- | --- |
| 開始 | トリミング開始時、画像上へ編集可能なバウンディングボックスを表示する |
| マウス操作 | 枠の移動、大きさの変更、角度の調整ができる |
| 数値入力 | 調整ウィンドウで位置、幅、高さ、角度、拡大率、基準点を指定できる |
| 双方向の連動 | マウスでの変更は数値へ、数値の変更は枠とプレビューへ直ちに反映する |
| 基準点 | 拡縮・回転の基準点を設定できる |
| 拡大率 | 幅・高さと倍率を対応させ、倍率からも出力寸法を設定できる |
| 既存リサイズへの追加 | 既存の画像サイズ変更にもバウンディングボックスでの調整を追加する |
| 確定・取消 | 確定前に調整を確認でき、取消とUndoで元の画像へ戻せる |
| 透明度 | Alphaを保持する。透明部分の市松は表示だけに使う |

## 操作案

以下は要望を実装へ落とすための案。具体的な配置・既定値は実装時に調整する。

- 初期枠は選択範囲があればその矩形、なければ画像全体。枠外を暗く表示する。
- 四隅と各辺中央の8ハンドルで大きさを変え、枠内のドラッグで移動する。枠外の回転ハンドルで角度を設定する。
- 調整ウィンドウは枠を操作しながら使えるものとし、位置X/Y、幅/高さpx、角度°、倍率%、縦横比固定、基準点を置く。
- 基準点は中央・四隅・各辺中央の9位置から選べ、枠内のドラッグまたはX/Y入力による自由位置も指定できる。
- 基準点を変えただけでは枠や画像を動かさない。以後の拡縮・回転をその点を中心に行い、数値の位置X/Yは選択中の基準点の画像座標として扱う。
- 角度付きトリミングでは、回転した枠内の領域を切り出し、結果は通常の矩形画像にする。角度と出力倍率は独立して指定できる。
- トリミングの出力倍率は100%を基本とし、切り出す範囲と最終画像の寸法を区別して表示する。画面の表示ズームとも区別し、表示倍率だけを変えても出力寸法は変わらない。
- Enterで確定、Escまたは取消ボタンで破棄。数値欄の編集中には意図しない確定を起こさない。初期値へ戻す操作も用意する。

## 既存実装との接続

現在の「選択範囲を切り出す」は`src/viewer.cpp`の`Crop`で、軸に沿った選択矩形を即時に切り出す。新しい調整モードの入口を追加し、従来の即時切り出し操作との関係を明示する。既存ショートカットを無断で別の意味へ変えない。

画像サイズ変更は`Resize`から`ResizeDialog`を開き、幅・高さ・倍率、比率固定、拡大/縮小フィルター、解像度を指定できる。`src/resize_dialog.cpp`と`include/gvn/resize_dialog.h`へ共通の枠編集を接続する。既存の数値リサイズ、補間方式、解像度だけを変更する処理を維持する。キャンバス変更の9基準点は別の機能として扱う。

枠・ハンドル・基準点・マウス座標変換・数値との同期は共通化する。リサイズでは枠の拡縮を出力寸法・倍率へ反映し、トリミングでは切り出す領域へ反映する。リサイズ時の回転も共通UIで提供する案とし、単純なサイズ変更とは操作名と結果の寸法を区別する。

調整中は元の画素を変更せず、枠と軽量なプレビューを更新する。確定時に既存の画像容量検査・Alphaを扱う補間・編集/Undo経路を使う。画像外にかかる部分は透明にする案を基本とする。取消、確保失敗、操作中の画像切替では元画像・選択・Undoを保つ。アニメーションは既存の現在コマ編集とUndoの方針に合わせる。
