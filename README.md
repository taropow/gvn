## 開発と検証

Visual Studio Build Tools 2022（C++デスクトップ開発）、CMake、Pythonを用意する。ライブラリは`third_party`へ固定リビジョンで同梱しており、ビルド時の取得は不要。

```powershell
powershell -NoProfile -File tools/build.ps1
powershell -NoProfile -File tools/package.ps1 -BuildDirectory ./build
```

別ドライブへビルドする場合は`-BuildDirectory`を指定する。[検証記録](docs/gvn-verification.md)にテスト条件と実測を記録している。通常のビルドはCTestを実行する。
